## 읽는 법

- 테스트 칸은 `파일 › 테스트 이름`이다. 이름이 길면 90자에서 줄였다(…). `it.each`의 자리표시자(%s)는 …로 적었다.
- 흐름 테스트(`apps/FE/e2e/flow-*.spec.ts`, `pnpm test:flow`)는 화면에서 ①~⑨를 끝까지 지나며 여러 AC를 한꺼번에 본다. 그 AC의 세부 규칙은 같은 줄의 BE·FE 테스트가 본다.
- 한 AC에 Must와 Should가 섞인 경우(US-20 AC5의 '앱에서 전시 켜기' RG-10, US-25 AC2의 '자동 재조회' OP-01)는 Must 부분만 M1 범위다. 이 표는 Must 부분을 확인하는 테스트를 적었다.
- 실제 커머스API·라쿠텐·데이터랩·환율·AI CLI는 부르지 않는다. 외부 연동 AC는 fixture·가짜 서버로 확인했고, 실제 서비스로 확인하는 것은 [M1 리허설](../action/M1_리허설.md)이다.
- 만든 방법: 테스트 파일에서 테스트 이름을 모은 목록(2,318개)에 AC마다 고른 파일·이름이 실제로 있는지 대조했다(2026-10-01). 테스트 이름을 바꾸면 이 표도 고친다.
