## 1. 요약

## 5. 다시 돌리는 법

08(화면 구현) 뒤에 같은 기준으로 다시 스캔한다. 간단한 확인 명령:

```sh
# 색 하드코딩(생성물 제외) — 0건이어야 한다
/usr/bin/grep -rnE '#[0-9a-fA-F]{3,8}\b|rgba?\(' apps/FE/src --include='*.css' --include='*.tsx' \
  | /usr/bin/grep -v 'shared/styles/tokens.css'
# 토큰 밖 글자 크기
/usr/bin/grep -rnE 'font-size:\s*(1[013579]|[2-9][0-9])px' apps/FE/src --include='*.css'
```
