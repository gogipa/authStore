## 1. 원칙

- 토큰 이름·값을 **새로 만들지 않는다.** tokens.json에 있는 것만 변수가 된다.
- 변수 이름 = `--<묶음>-<tokens.json 이름>`. 이름을 바꾸거나 줄이지 않는다.
- **라이트만** 만든다(D-13). 다크 값은 tokens.json에만 남긴다.
- 화면 코드는 색 값을 쓰지 않고 변수만 쓴다. 그래야 다크 테마를 붙일 때 화면 코드를 고치지 않는다(디자인 README §8).

## 2. 계층

| 계층 | 이 프로젝트 | 설명 |
|---|---|---|
| primitive(원시 팔레트) | **없음** | tokens.json이 `blue-600` 같은 원시 이름 없이 의미 이름에 값을 바로 준다. primitive를 새로 만들면 신규 토큰이 되므로 만들지 않는다 |
| semantic(의미) | tokens.json 전부 | `--color-accent: #2447b8`처럼 값을 바로 가진다 |
| 별칭(semantic → semantic) | 2개 | tokens.json의 `{accent}`·`{ink-faint}` 참조를 `var()`로 옮긴다: `--color-running: var(--color-accent)`, `--color-idle: var(--color-ink-faint)` |
| component | tokens.json에 없음 | README 문장에만 있는 치수(표 행 40px 등)는 토큰이 아니다 → [04-2 §3](04-2_css변수.md), [04-5](04-5_토큰이탈리포트.md) |

모드 분기는 나중에 semantic 층에서만 한다(§4). 컴포넌트 CSS는 모드를 모른다.

### 3.2 글꼴·글자 (2 + 9)

| tokens.json | CSS 변수 | 값 |
|---|---|---|
| `families.sans` | `--font-sans` | `'IBM Plex Sans KR', 'Apple SD Gothic Neo', 'Malgun Gothic', system-ui, sans-serif` |
| `families.mono` | `--font-mono` | `'IBM Plex Mono', ui-monospace, SFMono-Regular, Menlo, monospace` |

글자 스타일마다 변수 4개(+ 자간)를 만든다. `--type-<이름>`은 `font` 단축 속성 값이라 `font: var(--type-body);` 한 줄로 쓴다.

| 스타일 | `--type-<이름>`(font 단축) | 따로 쓰는 변수 |
|---|---|---|
| `display` | `700 28px/36px var(--font-sans)` | `-size` · `-line-height` · `-weight` |
| `title` | `700 20px/28px var(--font-sans)` | 〃 |
| `heading` | `600 16px/24px var(--font-sans)` | 〃 |
| `body` | `400 14px/22px var(--font-sans)` | 〃 |
| `body-strong` | `600 14px/22px var(--font-sans)` | 〃 |
| `caption` | `400 12px/18px var(--font-sans)` | 〃 |
| `label` | `600 12px/16px var(--font-sans)` | 〃 + `--type-label-letter-spacing: 0.02em` |
| `num` | `500 14px/20px var(--font-mono)` | 〃 (쓸 때 `font-variant-numeric: tabular-nums` 추가) |
| `id` | `500 12px/16px var(--font-mono)` | 〃 |

주의: `font` 단축 속성에는 `letter-spacing`·`font-variant-numeric`이 없다(오히려 `font-variant-numeric`을 기본값으로 되돌린다). `label`·`num`을 쓸 때는 `font:` **다음 줄에** 그 속성을 따로 쓴다.

### 3.3 간격·모서리·그림자

| tokens.json | CSS 변수 | 값 | 용도 |
|---|---|---|---|
| `space-1` … `space-8` | `--space-1` `--space-2` `--space-3` `--space-4` `--space-6` `--space-8` | 4 · 8 · 12 · 16 · 24 · 32px | 아이콘-글자 · 칩 묶음 · 셀 좌우 · 패널 안 · 섹션 사이 · 화면 가장자리 |
| `radius-sm` / `-md` / `-lg` | `--radius-sm` `--radius-md` `--radius-lg` | 4 · 8 · 12px | 칩·입력·표 안 버튼 / 버튼·패널 / 대화상자 |

`space-5`·`space-7`은 tokens.json에 없다. 만들지 않는다.

## 4. 다크 테마(나중)

- 지금: 생성기가 `light` 값만 읽어 `:root` 하나를 만든다. `data-theme`·`prefers-color-scheme` 분기를 넣지 않는다(D-13).
- 나중: 같은 생성기가 `dark` 값으로 `:root[data-theme='dark'] { --color-…: … }` 블록을 **색·그림자에만** 더한다. 글자·간격·모서리는 모드와 무관하다.
- 별칭 2개(`running`, `idle`)는 `var()`라서 다크 블록에 따로 적지 않아도 따라간다.
- 컴포넌트 CSS는 그대로 둔다. 모드 분기가 컴포넌트에 들어가면 안 된다.

## 5. 글꼴 파일 (런타임 외부 호출 금지)

- 시안(.dc.html)은 Google Fonts에서 IBM Plex를 받는다. 앱은 **외부에서 받지 않는다**(GEN-01 허용 목록, 스캐폴딩 명세 §0).
- 지금: `--font-sans` 목록 그대로. PC에 IBM Plex가 없으면 Apple SD Gothic Neo(맥)로 그린다. 시안과 글자 폭이 조금 다를 수 있다.
- 결정 필요(Proposed: 지금 목록 유지): IBM Plex 파일(OFL)을 앱에 함께 넣을지. 넣으면 `@font-face`를 global.css에 두고 파일은 `src/shared/styles/fonts/`에 둔다. 번들 크기가 늘어난다.
