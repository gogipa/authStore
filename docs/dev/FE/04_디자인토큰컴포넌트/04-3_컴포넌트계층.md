## 1. 규칙

- 부품 하나 = 폴더 하나: `shared/ui/<Name>/<Name>.tsx` + `<Name>.module.css`. 밖에는 `shared/ui/index.ts`로 낸다.
- CSS Module은 **토큰 변수만** 쓴다. 토큰 없는 치수는 04-2 §5 방식(숫자 + 주석).
- 변형은 문자열 유니언 prop 하나 = 클래스 하나. `[styles.button, styles[variant], styles[size]]`처럼 조합한다(구현된 Button과 같다).
- 상태 prop 값은 **API 코드 그대로** 받는다(`COMPLETED`, `WAITING_INPUT` …). 화면 글자로 바꾸는 일은 부품이 한다.
- 도메인 용어(후보·단계·게이트)를 아는 부품은 `shared/ui`에 두지 않는다. 단, 게이트·상태 칩처럼 **API 코드 값만 받고 데이터를 부르지 않는 것**은 shared에 둔다(데이터 호출이 없으면 shared 허용).
- 시안에 그렸지만 M1이 아닌 부분(디자인 README §4 마지막 열)은 "M2"로 두고 만들지 않는다.

## 3. 변형 스키마 (주요 부품)

### Button (구현됨)

| prop | 값 | 클래스 | 토큰 |
|---|---|---|---|
| `variant` | `primary` | `.primary` | bg `--color-accent`, 글자 `--color-on-accent` |
|  | `secondary`(기본) | `.secondary` | 테두리 `--color-line-strong`, bg `--color-surface`, 글자 `--color-ink` |
|  | `danger` | `.danger` | 테두리·글자 `--color-failed`, bg `--color-surface` |
| `size` | `md`(기본) | `.md` | 36px, 좌우 `--space-4`, `--radius-md` |
|  | `sm` | `.sm` | 32px, 좌우 `--space-3`, `--radius-sm`, 13px(토큰 없음) |
| `disabled` | true | `:disabled` | bg `--color-surface-sunk`, 글자 `--color-ink-faint`, 테두리 없음 |

누락 조합 점검:
- `primary + sm`: 시안에 없다. 막지 않지만 쓰지 않는다(주 버튼은 화면당 하나, 36px).
- `danger + disabled`: 시안에 없다. 꺼짐 모양이 우선한다(현재 CSS 그대로).
- 꺼진 버튼의 "이유 글"은 Button이 그리지 않는다. `DisabledReason`을 옆에 둔다(README "꺼진 이유는 보이는 글로").

## 4. 오너 확인이 필요한 경계

1. 게이트·상태 칩을 `shared/ui`에 두는 것(API 코드 값을 알지만 데이터를 부르지 않음). 대안: `features/step-engine/components`.
2. 후보 머리 오른쪽 버튼: 공통부품 §F는 '후보 목록', 화면시안_명세 §3은 '여기부터 연속 실행', SCR-12 보드는 '후보 제외'다. Proposed: 단계 화면 틀은 '후보 목록'(§F가 "글자 그대로 복사" 규칙), SCR-12 목록 화면은 '후보 제외'. 그래서 오른쪽 버튼을 슬롯으로 둔다.
3. Chip tone 5가지로 묶은 것(디자인 사전에는 칩별 색만 있다).

## 5. P1-02 구현에서 정한 것 (Proposed, 2026-09-30 — 오너 검토)

1. **보드마다 모양이 다른 부품에 `look` 변형을 더했다.** 인벤토리는 '변형 없음'이었지만 보드가 세 모양을 그렸다.
   - `FilterToggleGroup look`: `chips`(기본, 떨어진 32px 버튼: Keywords '목록 거르기'·Tags) · `segmented`(붙은 36px 칸: Keywords '분야'·'수집 범위') · `soft`(회색 바탕 알약: CandidateWork '후보 거르기'·Products).
   - `Disclosure look`: `button`(기본, 테두리 32px: Approval·Thumbnail) · `link`(글자만 accent: Content 고시 표).
2. **Switch 켜짐 모양**은 보드에 없다(꺼짐만 그렸다). accent 채움 + on-accent 손잡이로 정했다. 옆에 '켜짐'·'꺼짐' 글을 늘 보인다(색만으로 상태를 알리지 않게).
3. **ProgressBar 채움 색**: 진행 중은 running(accent), 다 차면 done. 보드(Keywords)는 끝난 모습만 그렸다.
4. **TextField**: 단위는 늘 칸 안 오른쪽(화면시안_명세 §3). Judgement 보드의 쿠폰 칸은 '¥'를 왼쪽에 두었지만 명세를 따랐다. 숫자 칸은 `numeric`(mono·오른쪽 정렬).
5. **Banner 역할 기본값**: info → `role="note"`, warning·blocked → `role="status"`(보드와 같다). 방금 생긴 오류는 부르는 쪽이 `role="alert"`를 준다.
6. **안쪽 틀 `Field`**(라벨 위 + 칸 + 도움말·오류 글)를 `shared/ui/Field`에 두고 TextField·Textarea·Select가 같이 쓴다. `index.ts`로 내지 않는다.
