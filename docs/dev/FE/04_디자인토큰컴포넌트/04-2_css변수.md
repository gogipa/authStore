# 04-2. CSS 변수 (`tokens.css`)

| 항목 | 내용 |
|---|---|
| 버전 | 0.1 (2026-09-27) |
| 상태 | **Proposed** (D-11) |
| 파일 | `apps/FE/src/shared/styles/tokens.css` — **생성물.** 손으로 고치지 않는다 |
| 만드는 법 | `pnpm --filter @autostore/fe tokens:gen` (`apps/FE/scripts/gen-tokens.mjs`). CI·커밋 전 확인은 `tokens:gen -- --check`(원본과 다르면 종료 코드 1) |
| 읽는 순서 | `main.tsx`가 `tokens.css` → `global.css` 순서로 불러온다 |

## 1. 생성 규칙

| 규칙 | 내용 |
|---|---|
| 입력 | `docs/design/design-system/tokens.json`의 `light` 값만 |
| 이름 | `--color-*` · `--font-*` · `--type-*` · `--space-*` · `--radius-*` · `--shadow-*` (04-1 §3) |
| 참조 | `{accent}` 같은 값은 `var(--color-accent)`로 바꾼다. 없는 토큰을 가리키면 생성이 실패한다 |
| 주석 | tokens.json의 `usage`를 변수 옆 주석으로 옮긴다 |
| 모양 | 16진 색은 소문자, 글꼴 이름은 작은따옴표(Prettier가 다시 고치지 않게) |
| 금지 | 생성기에 값을 적어 넣지 않는다. 바꿀 값은 tokens.json(디자인)에서 바꾼다 |

## 4. `global.css`가 맡는 것 (토큰 아님)

| 규칙 | 값 | 근거 |
|---|---|---|
| `html { color-scheme: light; }` | 라이트 고정 | D-13 |
| `body` | `font: var(--type-body)` · `color: var(--color-ink)` · `background: var(--color-bg)` | 디자인 README 색·글자 |
| `a` | `color: var(--color-accent)` | 링크는 accent |
| `button, input, select, textarea` | `font: inherit` | 공통부품 §I "글꼴 상속" |
| `:focus-visible` | `outline: 2px solid var(--color-accent); outline-offset: 2px` | 디자인 README 접근성 |
| `code, kbd, samp` | `font: var(--type-id)` | ID·코드는 mono |

## 5. 토큰이 없는 치수 (component 계층 자리)

디자인 README 문장에는 있지만 tokens.json에는 없는 값이다. **새 변수로 만들지 않는다**(신규 토큰 금지). 그 값을 가진 부품의 CSS Module **한 곳에만** 숫자로 쓰고 주석을 단다. 디자인이 tokens.json에 넣으면 그때 변수로 바꾼다.

| 값 | 쓰는 곳 | 근거 문장 | 처리 |
|---|---|---|---|
| 36px 높이 | Button `md`, 내비 항목, 입력칸 | README "주요 버튼은 높이 36px" | 부품 CSS에 숫자 `/* 디자인 확인 필요: 토큰 없음 */` |
| 32px 높이 | Button `sm`, 내비 하위 항목 | README "표 안 버튼은 32px" | 〃 |
| 40px 높이 | 표 행 | README "표 행 높이는 40px" | 〃 |
| 22px 높이 | 상태 칩, 단계 번호 원 | 공통부품 §C | 〃 |
| 220px 폭 | 왼쪽 내비 | README "왼쪽 내비(폭 220px)" | 〃 |
| 260px 폭 | 단계 레일 | 디자인 README §3 | 〃 |
| 13px 글자 | 표 안 버튼, 내비 하위 항목, 명령 상자 | 공통부품 §I·§A | 글자 토큰에 없음 → [04-5](04-5_토큰이탈리포트.md) |

생성물이 아닌 이 숫자들은 04-5 스캔에 "토큰 없음"으로 계속 잡힌다. 의도한 것이다.
