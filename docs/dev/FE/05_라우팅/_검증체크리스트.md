## 해당 없음

- route group `(group)`이 URL에 끼는지 — 해당 없음: React Router는 route 객체라 그룹 폴더가 없다. 경로 없는 layout route는 URL을 바꾸지 않는다.
- `page.tsx` 전체 `'use client'` 여부 — 해당 없음: RSC가 없다.
- `error.tsx`가 클라이언트 컴포넌트인지 — 해당 없음: 대신 route `ErrorBoundary`(05-3 §3).
- `dynamic`·`revalidate`·`generateStaticParams` 세그먼트 옵션 — 해당 없음: 모두 CSR.
- 인증 열(actor) — 해당 없음: 로컬 1인, 로그인 없음. 보안은 BE 헤더 규칙(05-1 §1.2).
- Figma `get_metadata` 교차 점검 — 해당 없음: Figma가 없다. 시안 보드 13장 목록(디자인 README §4)으로 대조했다.
- Context7(React Router 8 문법) — 도구 없음. `lazy` 반환 모양·`hydrateFallbackElement`는 적용 때 확인 ⚠️.
