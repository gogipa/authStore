## 해당 없음

- `'use client'` 경계 — 해당 없음: RSC가 없는 SPA다. 대신 page 단위 lazy 분할(05-4).
- App Router·Next 15 패턴 확인 — 해당 없음: React Router 8 + Vite다.
- RSC prefetch·`HydrationBoundary` — 해당 없음: 서버 렌더링이 없다.
- 인증 토큰 흐름 — 해당 없음: 로그인이 없다. 대신 변경 요청에 `X-AutoStore-Client: 1`(client.ts 미들웨어).
- Context7 확인 — 도구가 없어 내장 지식으로 썼다. ESLint flat config 문법은 06에서 실제 lint로 확인한다 ⚠️.
