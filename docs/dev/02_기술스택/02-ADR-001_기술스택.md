## 4. 결과·감수하는 것

- 설치본마다 PostgreSQL이 필요하다. M2 배포(GEN-09)에서 설치 방법을 정한다(함께 설치하는 PostgreSQL, Docker 등). 이 결정은 오너가 D-14로 정했다.
- Prisma 7은 드라이버 어댑터(`@prisma/adapter-pg`)와 `prisma.config.ts`를 쓴다. 버전은 06 개발 환경 구축에서 실제 빌드로 확정한다.
- 버전 표는 "지금 합의"이지 "검증 완료"가 아니다. 빌드는 개발 환경 구축 단계에서 확인한다.
- **06 개발 환경 구축에서 확인한 것(2026-09-27)**: 위 버전으로 설치·타입 검사·린트·테스트(BE 단위 50 · e2e 12, FE 27)·빌드가 모두 통과했다. 바뀐 점은 넷이다. 자세한 이유는 [06-1](../06_개발환경/06-1_저장소·형상관리.md) §3에 있다.
  - Node를 24.21.0으로 올렸다. Nest CLI·jsdom 하위 의존성이 24.15 이상을 요구한다.
  - TypeScript는 7.0이 아니라 5.9.3이다. ts-jest·typescript-eslint가 7을 아직 지원하지 않는다.
  - ESLint는 10이 아니라 9다. jsx-a11y 플러그인 때문이다.
  - BE는 ESM으로 만들었다. NestJS 12 패키지가 모두 ESM 전용이다. Jest는 ESM 모드(`--experimental-vm-modules`)로 돈다.

## 5. 재검토 트리거

- 동료 셀러 설치에서 PostgreSQL 설치가 막히면(M2 종료 조건 ②-18 실패) → 함께 설치하는 PostgreSQL 또는 다른 저장소를 다시 본다.
- 동시 실행을 늘려(AI-05 이후) 작업 수가 하루 수백 건이 되면 → 전용 큐를 다시 본다.
- Prisma 8이 안정판이 되고 7의 지원이 끝나면 → 올린다.
