## 1. 리허설 전 자동 검사(저장소 루트, 테스트 DB만 쓴다)

```bash
source ~/.nvm/nvm.sh && nvm use
pnpm lint && pnpm typecheck && pnpm test && pnpm test:e2e && pnpm build
pnpm test:flow                                  # 끝까지 흐름 6건(가짜 연동) — 처음이면 pnpm --filter @autostore/fe exec playwright install chromium
pnpm --filter @autostore/be openapi:compare     # 구현 명세 ↔ 05-2 대조(남긴 차이는 05-4)
```

- 모두 통과해야 리허설을 시작한다. `test:flow`는 3100·3101·5173 포트를 쓰므로 앱(개발 서버)을 끈 뒤 돌린다.

## 3. 절차

### 3.1 키워드 경로 5건(상품마다 되풀이)

1. **① 키워드**(SCR-02): '수집'(데이터랩) 또는 '순위 붙여넣기' → 키워드 표에서 하나를 체크(G1) → '검색어로 쓰기' → 라쿠텐 검색어 확인(일본어로 고쳐도 된다) → '이 검색어로 소싱'.
2. **② 소싱**(SCR-03): 검색 결과에서 기준 상품·색상 코드로 '앵커 정하기' → 페이지 조회·재고·실질가가 끝나면(검증 행) 실질가가 가장 낮은 재고 통과 샵을 고른다. 하루 페이지 조회(110)를 본다.
3. **③ 판정**(SCR-04): '네이버쇼핑에서 찾아보기'로 국내 기준가(판매가 + 배송비)를 찾아 근거 링크와 함께 저장 → '실행' → 비용 분해·마진·면세를 확인 → '소싱 확정(G2)'.
4. **④ 카테고리**: '실행' → 리프 고르기(KC 예외면 'KC 면제 성인용 확인') → '이 카테고리로 확정'.
5. **⑤ 썸네일**(SCR-05): '실행'(원본 받기) → 신발만 나온 레퍼런스 1~3장 + '레퍼런스에 사람·얼굴 없음' → '만들기' → 대표(+추가) → 선택 전 확인 7개 → '썸네일 선택(G3)'.
6. **⑥~⑧**: ⑥ '여기부터 연속 실행' → ⑥-1 카피·⑥-2 원산지·소재(원산지를 못 찾으면 근거 URL과 함께 입력)·⑥-3 고시·HTML·⑦ 태그(경쟁 태그는 선택)·⑧ 이미지 업로드가 차례로 완료되고 G4에서 멈춘다. ⑥에서 상품명·고시를 확인한다.
7. **G4 최종 승인**(SCR-08): 전체 미리보기와 사전 검증(13줄 = 검사 15개) 모두 통과 → **차단 켬 상태로 '승인·등록'**(드라이런 — '검증완료', 등록 호출 없음) → 요청 JSON을 확인한다.
8. 차단 스위치를 **끄고**(후보가 승인대기로 돌아온다) → '승인·등록' → '등록됨'과 상품 번호. 등록 모드가 '처음 10건은 전시중지로 등록 (n/10)'인지 본다 → 차단 스위치를 **다시 켠다**.
9. **G5**: 스마트스토어센터에서 상품을 열어 전시중지 상태·이미지·상세·옵션·고시·태그를 확인한 뒤 센터에서 전시를 켠다(M1은 앱에서 켜지 않는다).

### 3.2 URL 경로 1건

1. 후보 작업(SCR-12) '키워드 없이 시작' → 'URL로 바로 후보 만들기'에 `item.rakuten.co.jp/{샵}/{상품}/` → 색상 → '이 색상으로 후보 만들기'. 레일에 '비교 안 함' 배지.
2. ③에서 국내 기준가 → 실행 → **'비교 없이 확정'** 체크 → '소싱 확정(G2)'. (URL 후보 쿠폰은 쿠폰 칸에.)
3. 이후는 3.1의 4~9와 같다. 승인 화면 '소싱 방식'이 '비교 없이 확정'인지 본다.

### 3.3 막혔을 때

- 등록 응답이 타임아웃·5xx면 '결과확인필요' — 다시 승인하지 말고 '결과 확인'(판매자관리코드 조회)을 누른다. 이미 등록됐으면 그 상품 번호가 연결된다.
- 4xx면 한국어 오류와 추적 번호가 보인다 — 원인 단계(예: ⑦ 태그)를 고친 뒤 다시 승인한다. 추적 번호와 응답을 기록하고 §2.1의 해당 줄을 고친다.
- 앱이 꺼졌다 켜지면 실행 중이던 단계는 '실패(중단됨)', 등록 중이던 후보는 '결과확인필요'(자동 조회) 또는 '승인대기'다.
- 사전 검증 실패 줄의 링크로 그 단계에 가서 고친다. 후보가 작업중이면 승인 바 아래 '승인 전에 끝낼 곳' 링크를 따른다.
