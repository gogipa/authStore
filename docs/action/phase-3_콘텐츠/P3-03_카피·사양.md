## 1. 목표

이 문서가 끝나면 ⑥-1 카피와 ⑥-2 고시 원자료 단계가 돈다. ⑥-1은 선택 AI 엔진으로 라쿠텐 상품명·설명·SKU 속성의 사실만 근거로 한국어 카피(헤드라인·셀링포인트 3~5개·본문·착화감·코디·사이즈 안내)와 근거 사실 목록을 만든다. 오너가 고친 필드는 다시 실행해도 지키고, 새 결과와 다르면 나란히 보여 준다. ⑥-2는 원산지·소재(겉감·안감·밑창)·굽높이를 속성 → 설명문 패턴 → AI(텍스트·스펙 이미지) 순으로 근거와 함께 뽑는다. 원산지를 확정하지 못하면 입력 대기로 멈추고, 오너가 국가와 근거 URL을 넣어야 끝난다. 흐름상 ④ 뒤 ⑥의 앞 두 단계이며, ⑥-3(P3-04)이 두 산출물을 읽는다.

## 4. 핵심 규칙

1. ⑥-1 시작 조건은 ② 현재 버전의 상품명(`item_name`), 설명 텍스트(`description_text`, NFKC·공백 정리), SKU 속성뿐이다. ⑥-2를 읽지 않고, 원산지·소재·굽높이 값을 카피에 쓰지 않는다. AI 엔진·모델은 입력 지문에서 뺀다. (PRD §5.3 ⑥-1 행·'카피에는 원산지…를 쓰지 않는다', D-16 R9)
2. 카피 결과 스키마는 `{headline(40자 이하), selling_points(3~5개), body, fit_and_styling, size_guide, source_facts_used[]}`이다. draft-07 공통 부분집합, `additionalProperties:false`, 모든 필드 required로 쓴다. 앱이 다시 검증한다(스키마 + 필드 속 결과 JSON·`placeholder` 같은 모양 깨짐). (PRD §8.5 카피 스키마, F-CT-05, US-14 AC1, AI-02, PRD §8.9 스키마 규칙)
   - **(D-17, 2026-10-02)** 검증에서 떨어지면(`AI_OUTPUT_INVALID`) 시작 때 고정한 같은 엔진·모델과 같은 입력으로 1회 바로 다시 부른다. 두 번째도 떨어지면 ⑥-1은 `FAILED`(`failureKind=AI`, `AI_OUTPUT_INVALID`)다.
   - 시간 초과(`AI_TIMEOUT`)·CLI 실패(`AI_CLI_FAILED`·`AGY_ERROR`, 한도 포함)·엔진 사용 불가·입력 차단·그 밖의 오류에는 다시 부르지 않는다. 두 호출 모두 `AiExecutor.run`을 지나 `call_log`에 1행씩 남는다. ⑥-1만이고 다른 AI 단계는 그대로다. (`F-CT-41`, AI-04 일부, [원천자료 09](../../prd/원천자료/09_M0결정_2026-10-02.md))
3. 프롬프트에 금지 규칙을 모두 넣는다. (F-CT-06, PRD §8.5 프롬프트 규칙, AI-08, F-BS-13)
   - 번역하지 않고 원문 사실만 근거로 새로 쓴다. 원문에 없는 기능·효능을 지어내지 않는다
   - 가격·최저가·할인·배송 문구, '공식'·'정품 100%', 다른 브랜드를 쓰지 않는다
   - 제조국과 판매국(일본)을 구분하고, 원산지·소재·굽높이 값을 쓰지 않는다
   - 가상인물이 직접 신어 본 듯한 경험 표현을 쓰지 않는다
   - 라쿠텐 텍스트는 데이터 블록으로 격리한다. 비밀정보·개인정보는 넣지 않는다
4. AI 단계 공통 규칙. (D-16 R9~R11, 05-1 표 A, F-CW-17, F-BS-75·76)
   - 시작 때 선택 엔진을 쓸 수 없으면 409 `AI_ENGINE_UNAVAILABLE`로 막는다. 실행 중에 쓸 수 없게 되면 `FAILED`(`errorCode=AI_ENGINE_UNAVAILABLE`)로 끝낸다. 다른 엔진으로 넘어가지 않는다
   - G2 전에 실행하면 경고 `PRE_G2_AI_COST`를 붙이고 막지 않는다
   - `step_run.ai_engine`·`ai_model`·`ai_cli_version`은 시작 때 고정한다. 화면 표시는 'AI 생성 · Claude Code'처럼 엔진 이름을 붙인다
5. ⑥-1 산출물은 `content_draft_copy.generated_copy`(AI 원 결과)와 `copy`(원 결과 + 필드별 오너 입력)이다. `content_draft_field`에는 오너가 고치거나 고른 `copy.*` 필드만 둔다. (ERD `content_draft_copy`·`content_draft_field` 목적)
6. 카피 편집(`owner-edits` EDIT, COPY)은 새 버전(`OWNER_EDIT`, `COMPLETED`)을 만든다. 고친 필드는 `value_source=OWNER_INPUT`, `owner_confirmed_at`을 채운다. 헤드라인 40자 초과나 셀링포인트 3~5개 위반은 422 `VALIDATION_FAILED`. `baseStepRunId`가 현재 버전이 아니면 409 `VERSION_NOT_CURRENT`. (F-CT-08, 05-1 표 B)
7. 다시 실행해도 `OWNER_INPUT` 필드는 덮어쓰지 않는다. 새 결과가 다르면 새 값을 `generated_value`에 넣고 `choice_pending=true`로 둔다. 오너는 `choose: OWNER|GENERATED`로 고른다. (F-CT-08, PRD §5.3 '다시 실행과 오너 수정', ERD `choice_pending`)
8. '그대로 유지'(KEEP_AS_IS)는 ⑥-1이 `RERUN_REQUIRED`일 때만 된다. 산출물을 그대로 복사한 새 버전에 새 지문을 남긴다. 다른 단계는 422 `KEEP_AS_IS_NOT_ALLOWED`, 재실행 필요가 아니면 409 `STEP_NOT_RERUN_REQUIRED`. (PRD §5.3 규칙 6, US-35 AC3, ERD `ck_step_run_keep_copy_only`)
9. ⑥-2 시작 조건은 ② 소싱 선택 `itemCode`, 속성, 설명 텍스트, 스펙 이미지(파일 해시), 선택 색상 원문이다. 추출 순위는 아래와 같고, 앞 순위에서 찾은 필드는 뒤 순위가 덮지 않는다. (F-CT-09, F-CT-10, PRD §8.5 CT-02 표, PRD §5.3 ⑥-2 행)
   1. SKU 속성: `原産国／製造国`, `素材`(`素材（生地・毛糸）`), `種類（アウトソール）`, `ヒール高`(`{"value":"3.5","unit":"cm"}`)
   2. 설명문 패턴: `原産国|生産国|製造国|MADE IN`, `アッパー|ライニング|ソール|素材`, `ヒール高さ?|ソール高|厚底 約`
   3. AI: 텍스트와 설명 HTML 속 스펙표 이미지(OCR)에서 `{value, evidence_quote, method}`
   4. 없음
10. 필드 키는 `fact.origin`, `fact.material_upper`, `fact.material_lining`, `fact.material_sole`, `fact.heel_height`(`{value, unit}`)다. 버전마다 fact 필드 행을 모두 둔다. 행마다 값, 일본어 원문 발췌, 출처 URL, 방법(`SKU_ATTRIBUTE`·`DESCRIPTION_PATTERN`·`AI`·`NONE`), `basis_item_code`를 채우고, OCR이면 `evidence_image_asset_id`도 채운다. 값은 한국어로 정리한다. 정리 방법(사전·AI)은 문서에 없음 → 구현 때 Proposed로 정하고 기록. (F-CT-12, US-15 AC1, ERD `content_draft_field`, `ck_cdfield_fact_method`)
11. 근거가 없으면 `value=NULL`('정보 없음'), `extraction_method=NONE`이다. AI가 값만 주고 원문 발췌를 주지 않으면 그 값을 쓰지 않는다(추측 금지). (F-CT-11, CT-02 4순위)
12. 원산지를 근거로 확정하지 못하면 ⑥-2는 `WAITING_INPUT`(`pendingInputs=[fact.origin]`)이다. `PUT /step-runs/{id}/content-fields/fact.origin`으로 받는다. 대기 입력이 다 차면 같은 실행이 완료된다. (F-CT-14, US-15 AC2, 05-2 `putContentFieldInput`, ERD `ck_cdfield_origin_url`)
    - 요청: `value`=나라 이름, `evidenceUrl` 필수(없으면 422 `EVIDENCE_URL_REQUIRED`), `evidenceQuote` 선택
    - 원산지 사전·`commerce_origin_area`에 없는 나라 422 `ORIGIN_COUNTRY_UNKNOWN`, 허용 목록 밖 키 422 `FIELD_NOT_EDITABLE`, ⑥-2 아님 422 `INVALID_STEP_CODE`, 입력 대기 아님 409 `STEP_RUN_NOT_WAITING_INPUT`
    - 저장: `value_source=OWNER_INPUT`, `owner_confirmed_at`, `basis_item_code`=현재 `itemCode`
13. 원산지 입력은 웹 화면 요청만 받는다(CLI 불가). 완료 뒤 고치기는 `owner-edits`(EDIT, NOTICE_RAW)로 하고, 이때도 원산지는 `evidenceUrl`이 필수다. (05-1 §1.2 웹 화면 전용 기록, 05-1 표 B)
14. 재확인 필요: 새 ⑥-2 버전이 이전 버전의 `OWNER_INPUT` fact 필드를 가져올 때, `basis_item_code`가 현재 `itemCode`와 다르면 `recheck_reason=ITEM_CODE_CHANGED`를 붙이고 SSE `content-field.recheck-flagged`를 보낸다. 오너가 현재 근거로 다시 확인·입력하면 `recheck_resolved_at`을 채운다. 풀리지 않은 표시가 있으면 RG-08이 막는다. ⑥-2에는 '그대로 유지'가 없다. (F-CT-15, US-35 AC4, PRD §5.3 예외(파생 필드), ERD `ck_cdfield_recheck_*`)
15. AI 추출용 스펙 이미지는 설명 HTML의 이미지를 `image_asset`(`ORIGINAL`, `source_section=DESCRIPTION_IMAGE`, 참조 전용)으로 받아 쓴다. 고르는 규칙(최대 장수·크기)은 M0 S2에서 정한다. 그 전에는 설정값으로 두고 Proposed로 기록한다. 비전 호출은 `images_seen`으로 이미지를 실제로 읽었는지 확인한다. (F-CT-10, ERD §7.3-4, PRD §8.9 비전 템플릿)

## 8. 주의

- 공통 규칙은 [README §공통 규칙](../README.md#공통-규칙)을 따른다(실행 환경, 외부 호출 금지, 비밀정보, 커밋 안 함).

- ERD `content_draft_fact`는 '규칙으로만 끝났으면 엔진 NULL'이라고 하지만, `step_run`의 `ai_*`는 INSERT 때만 쓸 수 있다(트리거). 그리고 표 A는 ⑥-2 시작 때 엔진을 검사한다. M1은 시작 때 항상 기록하는 쪽으로 Proposed 결정하고 ERD에 적는다.
- 라쿠텐 설명은 프롬프트 인젝션 통로다. 데이터 블록으로 격리하고, 결과는 스키마·길이로 다시 검증한다. 설명 안의 지시를 따르지 않게 테스트 fixture 하나에 '지시문'을 넣어 둔다.
- 설명 텍스트는 P2-02가 EUC-JP로 읽어 NFKC 정리한 값이다. 설명문 패턴은 NFKC 뒤 글자(`／`→`/`, `：`→`:`, 전각 영숫자→반각)에 맞춰 쓴다. 원문 발췌는 원문 표기를 그대로 남긴다.
- `ベトナム、インドネシア、中国`처럼 여러 나라도 '확정'이다. 입력 대기로 보내지 않는다. 코드 조합은 P3-04(M0 S3)가 정한다.
- `content_draft_copy`·`fact`·`field`는 `trg_output_frozen` 대상이다. 완료 뒤 고치기는 모두 새 버전(owner-edits)이다. 완료 뒤 재확인 해소도 새 OWNER_EDIT 버전(`recheckConfirmed`)이다. 이는 05-1 §7.4-32의 제안이다.
- ⑥ '실행'은 `stepCode=COPY` + `throughStepCode=NOTICE_HTML`로 step-engine이 ⑥-1 → ⑥-2 → ⑥-3을 잇는다. 실행기가 다음 단계를 스스로 시작하지 않는다.
- P3-04가 ⑥-2에 색상 한국어 표기(F-CT-17)와 주의 문구 AI 보완(F-CT-21)을 더한다. AI 호출은 가능하면 한 번에 묶는다(PRD §8.9). 그러니 추출기 파이프라인과 AI 스키마를 필드 추가형으로 둔다. AI-05 입력 해시 캐시는 오너가 누른 '다시 실행'에 쓰지 않는다.
