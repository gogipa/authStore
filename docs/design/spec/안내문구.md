사용 안내(D-29 1~4번)의 화면 글을 한곳에 모았다. 대시보드 '시작 준비'·'작업 흐름' 카드, '사용 안내' 화면, 화면마다 제목 옆 '?' 도움말, 빈 상태 안내가 모두 이 글을 쓴다. 5번(첫 실행 마법사·체험 모드, M2)의 글은 다음 작업에서 이 문서에 더한다.

## 0. 읽는 법·고치는 법

- `{이름}`은 화면이 채우는 자리다. 예: `{engine}` → 'Claude Code', `{time}` → '09:12'(한국 시간, 오늘이 아니면 '09-27 09:12'), `{keys}` → 'client_secret'.
- 글 속 `[버튼]`은 화면에 있는 버튼 이름이다. 버튼 이름이 바뀌면 이 글도 함께 고친다.
- '링크' 칸의 `[이름] → 주소`는 화면 안 이동 링크다. 앱 밖 주소(https)는 쓰지 않는다(FE 규칙 15).
- 글은 PRD에 있는 것만 쓴다. 없는 기능을 만들어 쓰지 않는다. M1에 없는 것은 'M2'라고 쓴다.
- 고치는 순서: ① 이 문서를 고친다 → ② 개발 에이전트가 `content.ts`에 같은 글로 옮긴다 → ③ `pnpm test`가 두 곳이 같은지 본다(다르면 실패).
- 말투: 짧은 평서문(~합니다). 화면에는 '오너' 대신 '직접'처럼 쓴다(PRD §4).
