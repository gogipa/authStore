# 화면 시안 공통 명세 (에이전트용)

앱: '신발 자동등록' — 라쿠텐(일본)에서 신발을 골라 네이버 스마트스토어에 해외구매대행으로 올리는 1인 셀러의 로컬 웹앱. 디자인 방향 '작업대': 가격표·사이즈표·단계 상태를 빠르게 훑고 멈춘 곳만 손보는 도구. 장식보다 정확한 칸, 색보다 단어.
화면 글은 모두 한국어, 셀러가 아는 쉬운 말. 버튼은 동사("실행", "다시 실행", "승인·등록"). 꺼진 버튼 옆에는 꺼진 이유를 보이는 글로 쓴다. 이모지 금지. 그라데이션·왼쪽 색 띠 카드 금지.

## 1. 파일 형식 (.dc.html) — 어기면 조용히 깨진다

```html
<!doctype html>
<html lang="ko">
<head>
<meta charset="utf-8">
<title>라쿠텐 후보 비교</title>
<script src="./support.js"></script>
</head>
<body>
<x-dc>
<helmet>
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=IBM+Plex+Sans+KR:wght@400;500;600;700&family=IBM+Plex+Mono:wght@500;600&display=swap">
<style>
body{margin:0;font-family:"IBM Plex Sans KR","Apple SD Gothic Neo","Malgun Gothic",system-ui,sans-serif;color:#15202B;background:#F3F5F7}
a{color:#2447B8}a:hover{color:#1B368C}
</style>
</helmet>
<div style="width: 1440px; height: 1024px; box-sizing: border-box; display: flex; background: #F3F5F7;">
  ... 화면 ...
</div>
</x-dc>
<script type="text/x-dc" data-dc-script data-props='{"$preview":{"width":1440,"height":1024}}'>
class Component extends DCLogic {
  renderVals() {
    return { rows: [ /* 표 데이터 */ ] };
  }
}
</script>
</body>
</html>
```

규칙:
- `<script src="./support.js"></script>` 줄은 글자 하나 바꾸지 않는다. 모든 요소를 닫고 모든 속성에 따옴표를 쓴다.
- 루트 div는 고정 크기(보드 w×h)이고 `$preview`와 같다. 화면별 높이는 아래 표를 따른다.
- 스타일은 인라인 `style="…"`로 쓴다. `<helmet><style>`에는 body 기본값과 a/a:hover만 둔다. 클래스 CSS를 새로 만들지 않는다.
- 형제 묶음은 flex/grid + gap으로 배치한다(마진으로 띄우지 않는다). 그리드는 `grid-template-columns: repeat(N, minmax(0, 1fr))` 모양.
- `{{hole}}`은 점 경로 조회만 된다(식 금지). 계산은 renderVals()에서 하고 이름으로 넘긴다.
- 반복은 `<sc-for list="{{rows}}" as="r" hint-placeholder-count="5">…{{r.name}}…</sc-for>`. 조건은 `<sc-if value="{{flag}}" hint-placeholder-val="{{ true }}">`. 반복 안에서 달라지는 색은 renderVals()에서 항목마다 미리 계산해 `style="color: {{r.color}}"`처럼 넘겨도 된다.
- 화면 UI를 스크립트로 만들지 않는다(innerHTML, appendChild 금지). 모두 마크업.
- 진짜 `<button>`, `<a href>`, `<input>` + `<label for>`를 쓴다. 아이콘만 있는 버튼은 aria-label.
- 아이콘은 인라인 선 SVG(viewBox 0 0 24 24, stroke-width 1.5, fill none, stroke currentColor, 16~20px). 이모지 금지.
- 화면 간 이동은 `<a href="Keywords.dc.html">`(내비 항목 등). `<a>` 안에 button을 넣지 않고 a 자체를 버튼처럼 꾸민다.
- 네트워크는 Google Fonts `<link>`만. iframe/object/embed 금지. 전역 keydown 금지.
- data-props는 작은따옴표로 감싼 JSON. 문구(copy)를 prop으로 만들지 않는다. 필요하면 `"$preview"`만 둔다.

## 2. 토큰 (라이트 테마 값, 인라인으로 쓴다)

## 3. 공통 부품 (모양을 그대로 따른다)

**앱 틀** — 루트는 `display:flex`. 왼쪽 내비 `width:220px; background:#FFFFFF; border-right:1px solid #D3DAE1; padding:20px 12px; display:flex; flex-direction:column; gap:4px`. 오른쪽 본문 `flex-grow:1; padding:24px 32px; display:flex; flex-direction:column; gap:24px; min-width:0`.

**내비** — 맨 위 앱 이름 "신발 자동등록"(16px 700) + 캡션 "로컬 · 오너"(12px ink-faint), 아래 16px 띄움. 항목은 `<a>`: 높이 36px, `padding:0 12px; border-radius:8px; display:flex; align-items:center; gap:10px; font-size:14px; text-decoration:none; color:#4F5B67`. 현재 화면 항목은 `background:#E3E9FB; color:#2447B8; font-weight:600`. 항목과 링크:
대시보드 → Main.dc.html · 키워드 → Keywords.dc.html · 후보 작업 → CandidateWork.dc.html · 등록 상품 → Products.dc.html · 설정 → Settings.dc.html · 시스템 상태 → System.dc.html.
'설정' 바로 아래에 하위 항목 'AI 엔진' → AiEngine.dc.html을 둔다: 아이콘 없이 `height:32px; padding:0 12px 0 40px; font-size:13px`(글자가 위 항목 이름과 줄이 맞는다). AI 엔진 화면에서는 이 하위 항목만 현재 항목 모양이고 '설정'은 보통 모양이다.
내비 맨 아래(margin-top:auto)에 작은 상태 상자: "등록 API 차단 스위치 켜짐 · 드라이런"(waiting-soft 바탕, waiting 글자 12px)과 "하루 페이지 조회 38/110"(캡션).
후보 작업 안의 단계 화면(소싱·판정·썸네일·콘텐츠·태그·최종 승인)에서는 '후보 작업' 항목이 현재 항목이다.

**화면 머리** — 제목(20px 700) + 한 줄 설명(14px ink-muted), 오른쪽에 버튼 묶음(gap 8). 머리 아래 필요하면 필터·탭 줄.

**버튼** — 주 버튼: `height:36px; padding:0 16px; border-radius:8px; background:#2447B8; color:#FFFFFF; border:none; font-size:14px; font-weight:600`. 보조: `background:#FFFFFF; color:#15202B; border:1px solid #8391A0`. 꺼짐: `background:#E9EDF1; color:#66717D; border:none` + 옆에 이유 글(12px, waiting 또는 ink-muted). 위험(삭제): 글자 #9B1C1C, 테두리 #9B1C1C. 표 안 작은 버튼은 높이 32px, radius 4. 한 화면에 주 버튼은 하나.

**상태 칩** — `display:inline-flex; align-items:center; gap:4px; height:22px; padding:0 8px; border-radius:4px; font-size:12px; font-weight:600` + 12px 아이콘.
완료(#1D7350 on #E2F3EA, 체크) · 실행중(#2447B8 on #E3E9FB, 원호) · 입력 대기(#9A5B00 on #FBEEDB, 막대 두 개) · 재실행 필요(#A94405 on #FCE9DD, 되돌림 화살표) · 실패(#9B1C1C on #FBE4E2, 느낌표 삼각형) · 미실행(#66717D on #E9EDF1, 빈 원). 다른 칩: '직접 입력'(ink-muted 글자, #E9EDF1 바탕), '재확인 필요'(waiting 계열), 'AI 생성'(`border:1px solid #8391A0; color:#4F5B67; background:transparent`), '비교 안 함'(ink-muted, 테두리), '오래됨'(waiting).

**게이트 표시** — 10px 마름모(회전한 사각형 SVG) + "G2 판정 확정" 라벨. 통과: done 색 + "통과". 대기: waiting 색 + "확인 필요". 잠김: idle 색.

**표** — 바깥 `background:#FFFFFF; border:1px solid #D3DAE1; border-radius:8px; overflow:hidden`. 머리 행 `background:#E9EDF1; height:36px; font-size:12px; font-weight:600; color:#4F5B67`. 행 `height:40px; border-top:1px solid #D3DAE1; font-size:14px`. 셀 좌우 12px. 숫자는 mono 오른쪽 정렬. 선택 행 `background:#E3E9FB`. 표는 grid로 열을 맞추거나 `<table>`을 써도 된다(table 쓰면 border-collapse:collapse).

**패널** — `background:#FFFFFF; border:1px solid #D3DAE1; border-radius:8px; padding:16px; display:flex; flex-direction:column; gap:12px`. 제목 16px 600.

**안내 띠** — `border-radius:8px; padding:12px 16px; display:flex; gap:10px; align-items:flex-start; font-size:14px` + 아이콘. 정보: accent-soft/ink. 경고: waiting-soft/ink(아이콘 waiting). 차단: failed-soft/ink(아이콘 failed).

**입력칸** — 라벨(12px 600 ink-muted) 위, 칸 `height:36px; border:1px solid #8391A0; border-radius:4px; padding:0 12px; font-size:14px; background:#FFFFFF`. 잠긴 칸 `background:#E9EDF1; border-color:#D3DAE1`. 단위(원, ¥, mm)는 칸 안 오른쪽 캡션.

**후보 머리 (후보 작업·단계 화면 공통)** — 패널 한 줄: 상품 썸네일 자리(56×56, #E9EDF1, 신발 선 아이콘) · 상품명(16px 600) · 앵커 키 ID 칩 `1201A019-108 · 크림/블랙` · 소싱 선택 `shop-a:10000123` · 게이트 표시 G2·G3·G4 · 오른쪽 '여기부터 연속 실행' 보조 버튼.

**단계 레일 (후보 작업·단계 화면 왼쪽, 폭 260px)** — 패널 안 세로 목록. 행 높이 44px: 원 번호(②~⑨, 22px 원, 14px) · 단계 이름 · 오른쪽 상태 칩. 현재 단계 행은 accent-soft 바탕. ⑥은 '⑥ 상세 콘텐츠' 아래에 들여쓴 하위 행 '⑥-1 카피', '⑥-2 원산지·소재', '⑥-3 고시·HTML'. 단계 사이에 게이트 줄: ③ 아래 '◆ G2 판정 확정', ⑦ 아래 '◆ G3 썸네일 선택', ⑧ 아래 '◆ G4 최종 승인'(12px, 게이트 상태 색). 레일 아래 버튼 '재실행 필요 단계 모두 실행'.
단계 이름: ② 소싱 · ③ 판정 · ④ 카테고리 · ⑤ 썸네일 · ⑥ 상세 콘텐츠(⑥-1·⑥-2·⑥-3) · ⑦ 태그 · ⑧ 이미지 업로드 · ⑨ 등록.
단계 본문 맨 위 상태 줄: 상태 칩 · "마지막 실행 14:08" · "입력 출처: ② 소싱 산출물" · 오른쪽 '실행'(또는 '다시 실행') 버튼. 재실행 필요면 "바뀐 입력: 판매 사이즈" 글을 같은 줄에.

## 4. 예시 데이터 (모든 화면이 같은 값을 쓴다. 실제 상품이 아니라 예시다)

- **앵커 칸**: 앵커 뒤는 보드 그대로 '型番 1201A019 · 색상 코드 108 · 라벨' + '이 후보에서는 바꿀 수 없습니다 · 다른 모델·색상은 새 후보로 만듭니다'(읽기 전용, lock 아이콘). 앵커 전(보드 없음): '검색 결과에서 고르기'·'型番+색상 코드 입력' 라디오 + 기준 상품 `Select` 또는 型番 칸 + '색상 코드(선택)' + '앵커 정하기'(primary) + 안내 '앵커(型番·색상)를 정하면 같은 상품만 모아 상품 페이지를 읽고 재고·실질가를 계산합니다. 정한 뒤에는 이 후보에서 바꿀 수 없습니다.' 앵커 전 표 묶음 머리는 '검색 결과 N · 앵커(型番·색상)를 정하면 같은 상품만 모아 비교합니다. 상품명에 아동 단어가 있는 상품은 뺐습니다.'
- **성별 확인**: 보드 그대로 '성별 확인 · 자동' + '남성 250~290mm' + '바꾸기'. 오너가 고른 성별이면 '· 직접', 판단이 다르면 '재확인 필요'(waiting 칩). 앵커 뒤 성별을 몰라 ②가 기다리면 곧바로 '남성 250~290mm'·'여성 220~260mm' 라디오 + '성별을 판단하지 못했습니다. 골라 주면 목표 사이즈 범위로 재고를 다시 봅니다.'
- **'비교표에 넣기'**: 앵커를 정한 입력 대기 비교표면 켜고 기본 선택(보드와 같다). 넣기 → 읽은 상품 → '비교표에 넣기' → "비교표에 '수동' 행으로 넣었습니다." 꺼진 이유 '② 소싱 검색·비교를 먼저 실행해 주세요'·'기준 모델·색상(앵커)을 정한 뒤 넣을 수 있습니다'·'입력을 기다리는 ② 버전에만 넣을 수 있습니다'.
