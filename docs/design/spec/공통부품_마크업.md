## I. 버튼 (글꼴 상속을 잊지 말 것: `font-family: inherit;`)

- 주 버튼: `height: 36px; padding: 0 16px; border-radius: 8px; border: none; background: #2447B8; color: #FFFFFF; font-size: 14px; font-weight: 600; font-family: inherit;` — 한 화면에 하나.
- 보조: `… border: 1px solid #8391A0; background: #FFFFFF; color: #15202B; …`
- 꺼짐: `… border: none; background: #E9EDF1; color: #66717D; …` + `disabled` + 옆이나 아래에 이유 글(12px, #9A5B00 또는 #4F5B67).
