# 원천자료 12 — 사용 안내: 처음 쓰는 사람을 위한 안내 (2026-10-03)

- 일자: 2026-10-03
- 발언자: 오너
- 채널: Claude Code 세션 대화
- 비고: 원문 그대로 보존한다(줄바꿈·띄어쓰기도 고치지 않는다). 인용은 `원천12 Q35`·`Q36`, 결정은 `D-29`로 참조한다(Q 번호는 원천자료 11의 Q34에 이어 붙인다).
- 맥락: 오너가 대시보드에 이 서비스의 사용 시나리오와 화면별 기능 설명을 두면 어떨지 묻고, 처음 쓰는 사람을 위해 무엇을 할 수 있는지 추천을 청했다(Q35).
  - Claude 답(Q35): 다섯 가지를 추천했다.
    1. **대시보드 맨 위 '시작 준비' 카드**: 앱이 확인할 수 있는 준비 항목의 실제 상태(커머스API 키, 라쿠텐 앱 키, AI 엔진 연결, 이미지 생성 도구 agy, 구매대행 프로필)와 고칠 곳 링크를 보인다. 등록 API 차단 상태(정보)와 AI 계정 학습 끄기(앱이 확인할 수 없음, D-20)는 세지 않는 참고 줄로 둔다. 센 항목이 모두 되면 카드가 접히고, 다시 펼칠 수 있다.
    2. **'작업 흐름' 카드**: ① 키워드 → ② 소싱 → ③ 판정 → ④ 카테고리 → ⑤ 썸네일 → ⑥ 콘텐츠 → ⑦ 태그 → ⑧ 이미지 업로드 → 승인 → ⑨ 등록. 단계를 누르면 하는 일 / 앱이 자동으로 하는 것 / 사람이 확인할 것(게이트 G1~G4)을 보인다. '다시 보지 않기'로 숨기고(이 브라우저에만 기억), 왼쪽 메뉴 '사용 안내'에서 다시 연다.
    3. **화면 제목 옆 '?' 도움말**: 이 화면에서 할 일 / 다음 단계 / 자주 막히는 곳.
    4. **빈 상태 안내**: 목록이 비었을 때 다음에 할 일 버튼.
    5. **(M2) 첫 실행 마법사와 체험(데모) 모드**.
  - 오너가 "좋다. 전부다 진행하자"라고 답했다(Q36).

- **기능 리스트(문서)**: [04](../04_기능리스트.md) 0.3.6. 대시보드에 `F-DB-10` 시작 준비 카드·`F-DB-11` 작업 흐름 카드(M1)를 더했다. 새 메뉴 GD '사용 안내'에 `F-GD-01` 사용 안내 화면·`F-GD-02` 화면별 '?' 도움말·`F-GD-03` 빈 상태 다음 행동(M1)과 `F-GD-04` 첫 실행 마법사·`F-GD-05` 체험 모드(M2)를 더했다. 기능 455개 → 462개(M1 287 · M2 148).

### 확인이 필요한 영향

- 안내 문구는 [안내문구](../../design/spec/안내문구.md)에서 검토·수정한다. 앱 화면의 안내 문구는 이 파일을 따른다.
- 게시된 캔버스(claude.ai 화면 시안)에는 사용 안내 보드가 없다. 명세([화면시안_명세](../../design/spec/화면시안_명세.md) §8)에만 적었다.
- '시작 준비' 카드는 앱이 확인할 수 있는 다섯 항목만 센다. 해외상품판매 권한·전자상거래업자부호·주소록·허용 IP·자격증명 만료 같은 나머지 사전 조건은 M2 사전조건 체크리스트(`F-SY-04`·`F-SY-07`)가 맡는다.
- '작업 흐름' 카드의 '다시 보지 않기'는 이 브라우저에만 기억한다. 다른 브라우저나 사이트 데이터를 지운 뒤에는 다시 보인다.
- 5번(첫 실행 마법사·체험 모드)은 다음 작업에서 세부를 정한다. 체험 모드는 실제 외부 호출과 등록을 하지 않아야 한다.
