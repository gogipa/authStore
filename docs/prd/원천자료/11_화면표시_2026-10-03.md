# 원천자료 11 — 화면 표시: 화면 번호 칩 빼기·앱 이름 바꾸기 (2026-10-03)

- 일자: 2026-10-03
- 발언자: 오너
- 채널: Claude Code 세션 대화(실행 중인 앱을 보며)
- 비고: 원문 그대로 보존한다(줄바꿈·띄어쓰기도 고치지 않는다). 인용은 `원천11 Q33`·`Q34`, 결정은 `D-27`·`D-28`로 참조한다(Q 번호는 원천자료 10의 Q32에 이어 붙인다).
- 맥락: 오너가 개발 모드(`pnpm dev`)로 앱을 보다가 화면 제목 옆 글자를 물었다.
  - Claude 답(Q33): 'SCR-01', 'SCR-12'는 설계 문서의 화면 ID다. 화면 머리(`PageHeader`)의 `screenId` 칩으로 제목 옆에 붙였다([FE 04-3](../../dev/FE/04_디자인토큰컴포넌트/04-3_컴포넌트계층.md) PageHeader). 단계 화면(②~⑧)도 제목 옆에 같은 칩을 직접 그렸다. 원래 시안 보드에는 없다.
  - 추천: 모든 화면에서 뺀다. 개발 때만 보이게 하는 방법도 있지만, 오너는 개발 모드로 앱을 쓰므로 그래도 보인다.
  - 오너가 "응 빼야지."라고 답한 뒤 앱 이름도 바꾸자고 했다(Q34).
  - Claude 답(Q34): 사용자에게 보이는 이름(내비 맨 위 앱 이름, 브라우저 탭 제목, 문서, 디자인)을 모두 '스마트스토어 정복'으로 바꾼다. 내부 이름(저장소 `autoStore`, 패키지 `@autostore/*`, DB 이름, 환경 변수)은 그대로 둔다.

## 결정

| ID | 결정 | 근거 |
|---|---|---|
| D-27 | 앱 화면 어디에도 화면 ID 칩(`SCR-01`~`SCR-13`)을 그리지 않는다. 화면 머리(`PageHeader`)의 `screenId` 칩과, 단계 화면(② 소싱 비교 칸·③ 판정·⑤ 썸네일·⑥ 상세 콘텐츠·⑦ 태그·⑧ 이미지 업로드)이 제목 옆에 직접 그리던 칩을 모두 뺀다. 개발 모드에서만 보이게 하지도 않는다. 화면 ID는 설계 문서(PRD §11, 화면 시안, FE 설계, 실행 문서)와 코드 주석·테스트 이름에만 쓴다 | Q33, 원래 시안 보드에 칩이 없음, 오너는 개발 모드로 앱을 씀 |
| D-28 | 앱 표시 이름을 **'스마트스토어 정복'**으로 한다(전에는 '신발 자동등록'). 사용자에게 보이는 곳(내비 맨 위 앱 이름, 첫 HTML 제목, 브라우저 탭 제목 `<화면 제목> · 스마트스토어 정복`)과 문서·디자인(README, 설계 문서 제목, 시안 보드 사본, 디자인 시스템 이름, API 명세 제목)을 바꾼다. 내부 이름(저장소 `autoStore`, 패키지 `@autostore/*`, DB `autostore_*`, 환경 변수, 요청 헤더 `X-AutoStore-Client`, 구현 명세 제목 `autoStore API (구현)`)은 그대로 둔다. 원천자료에 남긴 오너 원문은 고치지 않는다 | Q34와 Claude 답(맥락) |

### 바뀐 것

- **화면(D-27)**: `PageHeader`의 `screenId` 속성과 칩 CSS를 지웠다. 자리표시자(`ScreenPlaceholder`)도 `screenId`를 받지 않는다. 단계 화면 6곳의 칩과 CSS도 지웠다. 화면 ID는 코드 주석(출처 표시)에 남는다.
- **테스트(D-27·D-28)**: 경로 테스트는 화면 13개 모두에서 `SCR-` 칩 글자가 없고, 탭 제목이 `<화면 제목> · 스마트스토어 정복`인지 본다. 내비 테스트는 앱 이름을 본다. 칩이 있다고 보던 화면 테스트 6개는 없다고 보게 바꿨다.
- **앱 이름(D-28)**: 앱 이름을 `apps/FE/src/shared/lib/appName.ts` 한 곳(`APP_NAME`, `documentTitle()`)에 두었다. 내비와 모든 탭 제목이 이 값을 쓴다. `index.html` 첫 제목도 같은 글자다. BE 코드에는 앱 이름이 없었다.
- **문서·디자인(D-28)**: README, docs/design(README·디자인 시스템 README·json 2개·명세 2개·보드 사본 13장·`canvas.json`), docs/dev(README·FE README·검증 체크리스트·ERD·C4·05-1·05-2 `info.title`·06-3), 04 기능 리스트 메뉴 구조의 앱 이름을 바꿨다. 보드 사본은 앱 이름 글자만 바꿨다.
- **문서(D-27)**: FE 04-3 PageHeader 줄과 화면별 메모, 화면시안_명세 화면별 메모, 06-3 FE 스캐폴딩에서 화면 ID 칩 설명을 지우거나 'D-27로 뺐다'로 고쳤다.
- **버전**: PRD 0.4.9(머리 앱 이름, §11, §16 머리, §19 용어, 변경 이력), PRD README, 04 기능 리스트 0.3.5, 디자인 README 0.3, FE 04-3 0.3, M1 리허설 0.7, 구현기록.
