- 채널: Claude Code 세션 대화 + 질의응답(AskUserQuestion)

## 원문

> 이거는 나도 쓰지만 다른사람도 쓰게할거야.
> 전자상거래업자부호나 이런건 필요없어. 왜냐면 수동으로 이미 하고있기때문이지

| 키 | 원문 | 처리 |
|---|---|---|
| Q14 | "이거는 나도 쓰지만 다른사람도 쓰게할거야." | 1인 전용 전제(원천01 Q2, CON-10)를 바꾼다. GEN-01 범위 확대, GEN-09 신설, CON-10 개정 |
| Q15 | "전자상거래업자부호나 이런건 필요없어. 왜냐면 수동으로 이미 하고있기때문이지" | 오너는 해외구매대행을 이미 수동으로 하고 있어 사전 조건을 갖췄다. PRD §0의 오너 즉시 행동에서 뺀다(D-10) |

## 오너 결정 (질의응답)

선택지 중 오너가 고른 답과 선택지 설명을 그대로 기록한다.

| ID | 질문 | 오너 선택 | 선택지 설명(원문) |
|---|---|---|---|
| D-08 | 다른 사람은 이 앱을 어떻게 쓰게 되나요? | **각자 자기 PC에 설치** | 각자 자기 컴퓨터에서 실행하고 자기 스마트스토어·API 키·AI 구독(claude 등)을 씁니다. 지금 설계(로컬 전용)를 대부분 유지하고, 설치·초기 설정 기능을 더합니다. |
| D-09 | 다른 사람은 누구이고, 사용료를 받나요? | **지인·동료에게 무료** | 아는 셀러에게 무료로 나눠 줍니다. 약관·지원 부담이 가장 작습니다. |
| D-10 | PRD §0의 1~4번(사업자·전자상거래업자부호·해외상품판매 권한·주소록)은 이미 된 것으로 기록합니다. 5번 커머스API 앱 등록(API 호출 키·IP 등록)은 되어 있나요? | **아직 없음** | 수동 등록에는 필요 없던 것이라 개발 전에 새로 등록합니다. §0에는 이 항목만 남깁니다. |

- 고르지 않은 선택지
  - D-08: '한 서버에 여러 명 접속'(로그인·권한·데이터 분리·호스팅 필요), '한 스토어를 여러 명이 같이'(작업자 구분·동시 작업 충돌 방지 필요)
  - D-09: '유료 판매·구독', '아직 정하지 않음'
  - D-10: '이미 있음', '모르겠음'
- D-10의 '1~4번 완료'는 오너의 진술을 기록한 것이다. 앱이나 AI가 확인한 사실이 아니다.
- §0의 1~4번은 동료 셀러에게는 여전히 필요한 조건이다. 설치 안내와 온보딩 점검(GEN-05·GEN-09)에서 다룬다.
- 동료 셀러의 OS, 배포 시점, 배포할 때의 AI 약관·AI 기본법 처리는 이번에 묻지 않았다. PRD §16 ②-17·②-18·①-9에서 묻는다.
