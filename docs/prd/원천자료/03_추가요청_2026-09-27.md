## 추가 결정 — PRD §16 ②-16 답변 (2026-09-27)

같은 날 세션에서 오너가 ②-16(직접 입력 입구를 MVP에 넣을지)에 답했다. 직전에 제시한 질문과 추천은 다음과 같다: "추천: 라쿠텐 URL 입구만 첫 버전에 넣기 / (가) URL 입구와 '¥가격만 넣고 판매가 계산'을 첫 버전에 / (나) 직접 입력 기능을 모두 첫 버전에 / (다) 모두 M2로 미루기".

| ID | 질문 | 오너 답(원문) | 적용 |
|---|---|---|---|
| D-07 | 직접 입력으로 시작하는 입구를 MVP에 넣을까요? (PRD §16 ②-16) | "추천대로 하자" | 추천안. **라쿠텐 URL 입구만 MVP(M1)에 넣는다.** RK-02를 Should에서 Must로 올린다. 나머지 입구(엔화 가격, 카테고리 검색, 내 이미지, 설명 텍스트, 시드 키워드. GEN-07)는 M2 |

- 직전 질문(②-16)에 대한 답으로만 기록한다. §16의 다른 문항(①-1~①-8, ②-1~②-15)을 승인한 것으로 보지 않는다.
