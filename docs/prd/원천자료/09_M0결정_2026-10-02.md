## 결정

| ID | 결정 | 근거 |

| D-17 | ⑥-1 카피의 AI 결과가 앱 검증에서 떨어지면(`AI_OUTPUT_INVALID`: 스키마 불일치, 또는 필드 속 결과 JSON·`placeholder` 같은 모양 깨짐) 실행 시작 때 고정한 **같은 엔진·같은 모델**로 **1회 바로** 다시 부른다. 두 번째도 떨어지면 지금처럼 '실패'(`FAILED`, `AI_OUTPUT_INVALID`)로 끝낸다. 시간 초과(`AI_TIMEOUT`)·CLI 실패(`AI_CLI_FAILED`)·엔진 사용 불가(`AI_ENGINE_UNAVAILABLE`)·한도·취소에는 다시 부르지 않는다. ⑥-1만이고 다른 AI 단계는 그대로다. 두 호출 모두 일일 AI 호출 상한에 들고 호출 기록에 남는다. 요구사항 AI-04(오류 분류·재시도, M2)의 일부를 M1으로 앞당긴다 | Q22, S7 §4.5·§4.7·§8 #3 |
| D-18 | AGY를 계속 고를 수 있게 둔다. 계정 위험은 오너가 받아들인다. 오너 본인 사용의 약관 위험은 '상'에서 **'중'**으로 고친다(아래 'D-18 근거'). 동료 배포의 AGY 기본값은 M2에서 전문가 확인(E-10) 뒤 정한다. AGY '실험적' 표시는 남기지만 이유는 결과 품질뿐이다(S7: 스키마 통과 86% < 95%, 비전 3/10. S6 격리: 사용자 MCP·규칙이 호출마다 함께 뜨고 끌 수 없음) | Q23, S6 약관 G2·G3·G4·G12·G13, S7 §6, S6 격리·비전 |

Claude와 앱은 외부 계정에 로그인하거나 계정 설정을 바꾸지 않는다. 개인 플랜은 기본값이 켜짐일 수 있어서(agy `enableTelemetry` 기본 `true`, ChatGPT 기본 학습 허용) '허용 안 함'이 되려면 오너가 직접 꺼야 한다. 사용자 설정 파일을 고치지 않고 agy의 상호작용 수집을 호출 단위로 끄는 스위치가 있으면 어댑터가 그것을 쓴다(M0 S1 탐색에서 확인하고 결과를 나중에 적는다) | Q25, S6 약관 A10·A11·G10·O9 |

### D-18 근거

오너 말("인증을 탈취해서 쓰는 것도 아니고 주어진 양만큼 쓰는 건데")은 약관 문장으로 보면 G2에 해당한다. S6 약관(2026-10-01)은 G2와 G3을 나눠 보지 않고 G3을 가장 넓게 읽어 '상'을 매겼다. 이번에 나눠 다시 본다. 법률 판단이 아니라 문서 해석이다.

| 출처 | 원문 요약 | autoStore에 해당하나 |
|---|---|---|
| G2 [G1] | "Using third party software, tools, or services to access the Service (e.g. using OpenClaw with Antigravity OAuth) is a breach of this Agreement." | **해당하지 않는다.** 다른 프로그램이 Antigravity 로그인(OAuth)을 빌려 서비스에 직접 붙는 경우다. autoStore는 사용자 PC에서 수정하지 않은 공식 `agy` 바이너리를 하위 프로세스로 부른다. 로그인은 `agy`가 사용자 본인 계정으로 스스로 한다. 앱은 토큰·로그인 정보를 읽지 않는다(CON-11, PRD §8.9 R6). 쓰는 양은 플랜 한도 안이다(G11, AI-06 상한) |
| G4 [G4] | "Run Antigravity CLI non-interactively to script agent tasks ..." / "Use it whenever you need the agent's output in a program instead of a terminal UI." | Google 문서가 프로그램에서 쓰라고 안내한다. autoStore의 쓰임과 같다 |
| G3 [G1] | "You must not abuse, harm, interfere with, or disrupt the Service. This includes, but is not limited to, using the Service in connection with products not provided by us." | **남는 불확실성은 이 문장뿐이다.** 글자 그대로 읽으면 다른 앱이 공식 `agy`를 부르는 것도 들어갈 수 있다. 다만 '남용·방해' 항목 아래 있고, G4와 함께 읽으면 평범한 본인 자동화를 노린 문장으로 보기는 어렵다(해석) |
| G12 [G1][G8] | Antigravity·Gemini CLI 계정 정지. Google 서비스 약관은 중대·반복 위반이면 Google 계정 삭제까지 적었다 | 제재가 Google 계정까지 갈 수 있다. 그래서 '하'가 아니라 **'중'**이다 |
| G13 [G8] | "providing services that encourage others to violate these terms" | 오너 본인 사용과는 다르다. 동료에게 나눠 주는 일(GEN-09, M2)은 E-10(E10-d·E10-e)에서 확인한다. 배포본 AGY 기본값은 그 뒤 M2에서 정한다(K25) |

- 정리: 오너 본인 사용(오너 PC, 공식 `agy`, 본인 로그인, 플랜 한도 안)은 **중**이다. 동료 배포는 **E-10 확인 전**이라 기존 판정(상)을 고치지 않고 '확인 전'으로 둔다.
- 실무 완화: 업무 메일과 다른 Google 계정으로 `agy`에 로그인하면, Google이 잘못 판단해 계정을 막아도 업무 메일에는 영향이 가지 않는다(G12).
- 출처 번호·접속일(2026-10-01)은 [S6 약관](../../dev/07_M0스파이크/S6_AI약관.md) §3·§11에 있다.

### 확인이 필요한 영향

- **D-17 재호출의 지시문**: S7에서 3/4가 고쳐진 재호출은 지시문 끝에 '[결과 모양]' 한 줄을 더한 것이었다(S7 §4.7). 같은 지시문 그대로 다시 부른 측정은 없다. 이 줄을 재호출에 넣을지(또는 첫 호출부터 넣을지)는 구현 단계에서 정하고 기록한다. → **구현에서 정함(2026-10-02, Proposed)**: 첫 호출부터 넣고, 재호출도 같은 지시문이다([06-2 §9-230](../../dev/06_개발환경/06-2_BE스캐폴딩.md)).
- **D-19**: S1은 아직 하지 않았다. `agy` headless `generate_image`의 실제 동작(공식 문서 없음), `--dangerously-skip-permissions` 필요 여부, 크기·포맷, 콘텐츠 필터 거부율을 S1에서 잰다. → **S1(2026-10-02)에서 쟀다**([S1](../../dev/07_M0스파이크/S1_썸네일생성.md)): 권한 플래그 필요 없음, 늘 JPEG 1024×1024, 거부 0/10, 장당 최대 92.2초. 실제 상품 사람 채점은 남았다.
- **D-20**: `agy`에 호출 단위로 상호작용 수집을 끄는 스위치가 있는지 S1 탐색에서 본다. 오너가 계정 설정 3개를 끈 날짜는 [M1 리허설](../../action/M1_리허설.md) 사전 점검에 적는다. Anthropic은 학습을 꺼도 피드백·안전 검토 대상은 학습에 쓸 수 있다고 적었다(A10). → **S1 결과: 스위치를 찾지 못했다**(확인 범위: `agy --help`, `/config` 키, 바이너리 환경변수 이름). agy는 오너가 Antigravity 'Enable Telemetry'를 끈다.
- **E-10**: E10-d(G3 범위)·E10-e(배포 G13)는 그대로 남는다. D-18은 오너 본인 사용의 위험 수용이지 법률 판단이 아니다.
