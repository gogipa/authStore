## 결정

| ID | 결정 | 근거 |
|---|---|---|
| D-11 | PRD §16 오너 결정 시트의 모든 문항(①-1~①-9, ②-1~②-18, ③ 기본값)과 03-3 MoSCoW 초안을 **추천대로** 정한다. 오너는 완성본을 보고 고칠 곳을 짚는다 | Q16 |
| D-12 | 개발 전에 **기능 리스트 → 디자인** 순서로 산출물을 만든다. 개발은 그 뒤다 | Q17 |

### D-11로 바뀐 것

- ①-1: M1은 **면세 구간만** 판다. 과세 사이즈는 옵션에서 빼고, 상품 전체가 과세면 제외한다. D-03(관부가세를 판매가에 넣어 판매)은 관세사 확인(E-2) 뒤에 설정으로 켠다.
- ②-7: PR-03(환율 자동)과 CT-07(상품명 자동)을 Should에서 Must로 올린다. KW-06·RK-07은 Should 그대로다.
- ②-11: 최소 차단어 5개('반품 불가', '환불 불가', '최저가', '공식', '정품 100%')를 최종 승인 검사(RG-08)에 넣는다. 전체 문구 린터(CT-05)는 M2다.
- ②-10: 준수 제약 CON-01~15, Won't 확장 규칙, 법정·플랫폼 요건을 Must로 보는 해석을 승인한다.
- 나머지 문항은 추천이 이미 PRD의 가정이었으므로 내용이 바뀌지 않는다.
- ②-2 추천은 '셀러라이프 멤버십을 쓴다'이다. 이에 따른 TG-02 강등은 '할 수 있다'는 선택 사항이라 하지 않았다(TG-02는 Must 유지).

### D-11로 바뀌지 않는 것

- E-1~E-10(전문가 확인)은 결정이 아니라 오너가 할 일이라 그대로 남는다.
- PRD §0 5번(커머스API 앱 등록)과 6번(라쿠텐 앱 확인)도 그대로 남는다.
- 오너는 MoSCoW 검토 화면(아티팩트)을 쓰지 않았다. 그 화면은 참고용으로 남는다.
