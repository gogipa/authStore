## 1. 요약

1. "sellerlife"(셀러라이프)는 현재 **셀록홈즈(sellochomes.co.kr, 운영사 ㈜브랜뉴닷컴)** 로 이름이 바뀌었다. `sellerlife.co.kr`로 접속하면 302로 넘어간다. 이 서비스는 **중국(타오바오·1688) 구매대행 소싱**과 **네이버·쿠팡 키워드·상품 분석**에 초점이 맞춰져 있다. 공개 매뉴얼 41개 항목을 모두 살폈지만 **일본 구매대행용 관부가세·환율 마진 계산기는 없다.** 공개 API도 없고 로그인(구글/카카오)이 필수다. 따라서 **계산 엔진은 우리 앱에 직접 만들어야 한다.**
2. 세금 규칙은 이렇다. 일본에서 오는 신발은 **목록통관 대상**(배제 목록에 없음)이고, 물품가격(일본 내 送料·소비세 포함, 국제운임 제외)이 **미화 150달러 이하면 관·부가세가 면세**된다. 이를 넘으면 과세가격은 CIF 기준이 되고, **관세 13%**(기본) + **부가세 10%** 로 실효 약 **24.3%** 가 붙는다. 한-일 RCEP은 섬유 갑피 운동화(6404.11)가 **미양허**이고, 일본산이어야만 적용되므로 기본값으로 쓰기 어렵다.
3. 환율 소스는 두 가지를 쓴다. 판정용은 **관세청 주간 과세환율**(금요일 고시, 일~토 적용, UNI-PASS API012 또는 data.go.kr)이다. 원가용은 **한국수출입은행 API**(`oapi.koreaexim.go.kr`, 하루 1,000회)다. 조사 시점 과세환율은 100엔=876원, 1달러=1,358.72원이었다. 이 환율로는 **약 ¥23,266이 150달러 경계**다.
4. 스마트스토어 수수료(2025-06-02 개편)는 **판매수수료 2.73%(VAT 별도, 포함 시 3.003%)** 와 **주문관리수수료(카드 기준 1.98~3.63%, VAT 포함)** 를 더한 값이다. 보수적으로 잡으면 약 **6.6%** 다. ⚠️정정됨(검증 결과 참조) 라쿠텐 포인트는 **다음 달 15일에 지급**되고 라쿠텐 안에서만 쓸 수 있다. 그래서 판정할 때는 원가에서 빼지 않는다.
5. 예시를 보자. 라쿠텐 ¥12,000(送料 무료, 포인트 10%)이면 원가는 약 107,748원, 배대지 비용은 약 15,000원이고 관부가세는 면세다. **목표 마진 10%의 최소 판매가는 약 154,300원**이다. 네이버 기준가가 이보다 충분히 높을 때만 "판매 후보"로 판정한다.

**자동화 가능성**
- 셀러라이프는 API가 없고 OAuth 로그인이 필수이며 약관은 미확인이다. 브라우저 자동화(Playwright로 오너 크롬 프로필 재사용)는 **기술적으로는 가능하다.** 다만 약관·계정 제재 위험이 있다.
- 권장안: (1) 마진 계산은 **자체 엔진**으로 만든다. (2) 국내가 조회는 **네이버 쇼핑 검색 Open API**(공식)로 한다. (3) 셀러라이프는 오너가 수동으로 참조하거나, 약관을 확인한 뒤 "사람이 연 화면에서 읽기" 반자동으로만 쓴다(R05의 manuTag 반자동 방식과 같은 원칙).

### 2.6 "국내판매가격"의 정의 후보

네이버 쇼핑 검색 Open API(공식):
- `GET https://openapi.naver.com/v1/search/shop.json`
- 파라미터: `display` ≤100, `start` ≤1000, `sort=sim|date|asc|dsc`, `filter=naverpay`, **`exclude=used:rental:cbshop`**(`cbshop`=해외직구·구매대행)
- 응답 필드: `lprice`(최저가. **가격비교 데이터가 없으면 그 상품의 가격**), `hprice`, `mallName`, `productId`, `productType`(1=가격비교 상품, 2=가격비교 비매칭 일반상품, 3=가격비교 매칭 일반상품, 4~6=중고, 7~9=단종, 10~12=판매예정), `brand`, `maker`, `category1~4`
- 검색 API 한도: **하루 25,000회**
- 출처: [공식] developers.naver.com(curl로 확인)

| 후보 | 산출 방법 | 장점 | 단점 |
|---|---|---|---|
| P1. 네이버 전체 최저가(구매대행 포함) | `sort=asc`, `exclude=used:rental`, 모델번호로 같은 상품만 추려 `lprice` 최솟값 | 소비자가 실제로 비교하는 가격이라 경쟁력 판정에 가장 현실적 | 다른 구매대행 셀러와 최저가 경쟁. 모델·사이즈 매칭 오류 위험 |
| P2. 국내 정식유통 최저가 | P1 + `exclude=…:cbshop` | "국내보다 싸다"를 해외구매 가치로 설명할 때 적합 | 구매대행 경쟁가를 무시하게 됨 |
| P3. 가격비교 카탈로그 최저가 | `productType=1` 항목의 `lprice` | 네이버가 묶은 같은 상품이라 매칭 신뢰도가 높음 | 카탈로그가 없는 모델이 많음 |
| P4. 브랜드 공식/정가 | 수동 입력 또는 R01·R03 수집값 | 할인율 표기에 유용 | 자동화 어려움 |
| (참고) 셀러라이프 셀라파인더/확장 가격 | 오너가 수동으로 조회 | 오너 습관과 맞음 | API 없음, 자동화 약관 미확인 |

- 권장: 판정 기본값은 **P1(전체 최저가)**, 보조 표시는 **P2**다. 신발은 **모델번호(品番, 예: 브랜드 스타일코드)** 로 매칭하고 **사이즈별 재고와 가격 차이**를 따로 다뤄야 한다(R03 라쿠텐 수집과 연결).

### 2.7 판매가·마진 계산식

**기호**

| 기호 | 의미 | 기본값/출처 |
|---|---|---|
| `Y_item` | 라쿠텐 판매가(税込, 쿠폰 적용 후, ¥) | R03 수집 |
| `Y_ship` | 라쿠텐 送料(배대지 주소까지, ¥) | R03 수집(3,980엔 이상 대부분 0) |
| `FX_base` | 기준환율(원/¥) | 수출입은행 `deal_bas_r`/100 |
| `k_card` | 카드 스프레드+해외결제수수료 가산율 | 2.5%(설정) |
| `FX_cJPY`, `FX_cUSD` | 관세청 과세환율(원/¥, 원/$) | 관세청 API |
| `W` | 청구무게 = max(실무게, 가로×세로×높이/계수) | 배대지 규정 |
| `C_fwd` | 배대지 비용(요금표(W) + 검수·포장 등) | 배대지 요금표(설정) |
| `t` | 관세율 | 13%(기본) / RCEP / 간이세율 모드 18% |
| `r_sale`, `r_order` | 판매수수료, 주문관리수수료(VAT 포함) | 3.003%, 3.63% ⚠️정정됨(검증 결과 참조) |
| `C_misc` | 포장·반품/교환 적립·CS 등 | 설정 |
| `pt_mult`, `ρ` | 포인트 배율(%), 포인트 실현율(0~1) | 판정 시 ρ=0 |
| `m`, `Π_min` | 목표 마진율, 최소 이익 | 오너 설정 |
| `δ` | 국내가 대비 가격 우위(%) | 오너 설정 |

**계산 순서**

```
1) 상품원가        C_goods = (Y_item + Y_ship) × FX_base × (1 + k_card)

2) 면세 판정       V_usd = (Y_item + Y_ship) × FX_cJPY / FX_cUSD
                   면세 = V_usd ≤ (150 − 안전버퍼$) AND 배제품목 아님 AND 합산과세 대상 아님

3) 관부가세        면세면 C_tax = 0
                   과세면 CV = (Y_item + Y_ship) × FX_cJPY + 국제운임(원)          # CIF
                          [일반] C_tax = CV × t + (CV + CV × t) × 10%              # t=13% → 실효 24.3%
                          [간이세율 모드] C_tax = CV × 18%                          # [미확인] 적용 여부 ⚠️정정됨(검증 결과 참조)
                   관부가세 정책이 '고객 부담'이면 원가에 넣지 않고 상세페이지에 고지

4) 마켓 수수료     C_mkt = P × r_sale + (P + 고객배송비) × r_order

5) 셀러 부가세     [모드 A: 구매대행 수수료 과세] VAT_s = (P − C_goods − C_fwd − C_tax) / 11 − C_mkt / 11(매입세액)
                   [모드 B: 총액 과세]            VAT_s = P / 11 − 공제 가능 매입세액
                   [모드 C: 미반영(참고)]         VAT_s = 0

6) 포인트 효과     pts = floor(floor(Y_item / 1.1) / 100) × pt_mult
                   B = pts × FX_base × ρ                                    # 판정 기본 ρ = 0

7) 순이익·마진율   Π = P − C_goods − C_fwd − C_tax − C_mkt − VAT_s − C_misc + B
                   마진율 = Π / P

8) 최소 판매가     P_min = Π ≥ max(m × P, Π_min)를 만족하는 최소 P, 100원 단위 올림
                   (모드 A, 매입세액 공제 생략 시 닫힌 식)
                   P_min = (C_base + C_misc − B − C_base/11) / (1 − r − 1/11 − m),  C_base = C_goods + C_fwd + C_tax,  r = r_sale + r_order

9) 판매 판정       P_ref = 국내 기준가(2.6의 P1 기본)
                   판매 후보  ⇔  P_min ≤ P_ref × (1 − δ)
                   권장 판매가 = min(P_ref × (1 − δ), 오너 상한)을 100원 단위로 내림 (≥ P_min 보장)
```

**예시 계산**

아래 숫자는 모두 가정이다. 환율은 2026-09-20~26 과세환율 게시값을 근사로 썼다.

| 입력 | 값 |
|---|---|
| 라쿠텐 가격 `Y_item` | ¥12,000(税込), 쿠폰 없음 |
| 送料 `Y_ship` | ¥0(3,980엔 무료 라인) |
| 포인트 | 10배 → floor(10,909/100)×10 = **1,090pt**(≈9,548원) |
| 환율 | `FX_base` = 8.76원/¥, `k_card` = 2.5% → **8.979원/¥**, `FX_cUSD` = 1,358.72원/$ |
| 배대지 `C_fwd` | 15,000원(청구 2kg, 검수·포장 포함 가정. 저가 배대지면 8,350~10,211원) |
| 기타 `C_misc` | 3,000원(포장·반품 적립 가정) |
| 수수료 | `r_sale` 3.003% + `r_order` 3.63% = 6.633% ⚠️정정됨(검증 결과 참조) |

| ④~⑦ 목표 마진 10%, 모드 A, ρ=0 | P_min 산식 | **P_min = 154,300원** |

|---|---|---|---|

### 계산식·요구사항 반영 메모

- `r_sale` 기본값은 3.003%가 아니라 **3.0%** 로 둔다. 마케팅·광고 유입은 **1.0%** 다. `r_order`는 등급표(2025-10-01 요율)를 설정값으로 두고, 기본값은 **3.63%** (개인판매회원·신규 사업자 가정)로 둔다.
- 과세환율은 매매기준율 계열이다. `FX_cJPY`·`FX_cUSD` 대체값이 필요하면 수출입은행 `kftc_deal_bas_r`(서울외국환중개 매매기준율)의 전주 월~금 평균으로 근사한다. `tts`는 쓰지 않는다.
- 간이세율 모드(18%) 표시는 "법적 근거 있음(관세법 제81조①4호), 실무 적용 여부는 관세청 확인 필요"로 바꾼다. 기본값 24.3%는 그대로 둔다.
- 관세율은 HS 4단위별로 설정한다(6401 = 8%, 6402~6405 = 13%).

### 누락 주제 (PRD에 반영 필요)

1. **전자상거래물품 특별통관 제도 개편**: 관세법 제254조(전문개정 2024.12.31)에 따라 통신판매업자(국내 사이버몰 입점 판매자 포함)가 간소 통관을 적용받으려면 관세청에 전자상거래업자로 등록해야 한다. 「전자상거래물품의 특별통관에 관한 고시」(관세청고시 2026-51, 2026-08-24 시행)가 새 절차를 정한다. 등록 조항은 등록시스템 개통일부터, 검증 조항은 통관플랫폼 개통일부터 시행된다.
   - 주문 단계에서 수입화주의 개인통관고유부호·성명·연락처·주소를 관세정보시스템에 검증 요청해야 한다.
   - 정보가 일치하면 화주에게 일회용 인증번호가 나온다. 이 번호를 화주에게서 받아 통관목록에 함께 제출해야 한다.
   - 통관목록에 공급망 정보가 들어간다. 전자상거래유형이 B(구매대행)이면 구매대행업자부호·명이 필수이고, 주문 사이트 URL도 필수다.
   - 주문 처리 흐름과 데이터 모델에 이 항목들을 반영해야 한다.
2. **구매대행업자 연대납세의무**: 셀러가 관부가세 상당액을 판매가에 넣어 받으면 관세법 제19조⑤1호다목에 따라 연대납세의무를 진다. 제270조①에 따라 관세포탈죄의 주체도 된다. Q6(관부가세 포함 여부) 선택지 설명에 넣는다.
3. **판매자 유형별 스마트스토어 수수료**: 개인판매회원·신규 사업자는 Npay 수수료 3.63%다(신규 사업자는 등급 반영 뒤 소급 환급). 판매자 마케팅 수수료(1%)는 광고·마케팅 링크로 유입될 때만 적용되고 유입 조건이 있다. 유입경로별 수수료를 가격 산정에 반영한다.
4. **HS별 관세율 차이와 FTA**: 6401 방수 신발은 8%다. FTA(한-베트남·한-아세안 0%, 한-중 9.1%)는 원산지 증빙이 필요하고, 신청하면 특송 간이신고가 배제된다. 일본을 거친 구매에는 사실상 적용이 어렵다는 점을 PRD에 명시한다.
5. **라쿠텐 쿠폰·포인트의 과세가격 인정 범위**: 해외판매자가 부담하는 무조건 쿠폰만 인정된다. 라쿠텐 플랫폼 쿠폰, 조건부 쿠폰, 포인트 사용분은 150불 판정에서 불리하게 작용할 수 있다.
6. **배대지 청구무게 규칙**: 조이포스트 일본은 대부분 실무게로 청구하고, 부피무게(/5000)는 그 값이 45kg 이상일 때만 적용한다. 2.3 #5의 부피무게 가정은 배대지마다 다르다. 요금표에 '부피무게 적용 조건' 필드를 둔다.
7. **셀러라이프 배대지 쿠폰의 원가 반영**: 1장 약 2,000원이고 파트너별 월 2장(17곳, 월 34장)이다. 해당 배대지 비용을 월 2건까지 깎는 방식으로 반영할 수 있다.
8. **수출입은행 API 키 만료**: 2년이 지나면 개인정보 파기로 `RESULT 3`이 나온다. 이를 모니터링하고 키 재발급 절차를 둔다.
