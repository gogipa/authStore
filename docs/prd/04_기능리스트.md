- M1 기능이 많은 이유: 안전장치(아동화 차단, 최종 승인, 중복 등록 방지 등), 단계 실행 규칙(상태·버전·재실행 필요), 법정 표시(구매대행 고지·상품정보제공고시)가 Must이고, 하나의 요구사항이 여러 개의 작은 기능으로 나뉘기 때문이다. Must 요구사항 수(45)와는 세는 단위가 다르다.
- 화면이 없는 기능(공통 기반 BS 등)은 화면 시안에는 나오지 않지만, 개발에서는 먼저 만들어야 하는 것이 많다.
- 사용 안내(GD 메뉴, `F-DB-10`·`F-DB-11`)는 D-29로 더했다([원천자료 12](원천자료/12_사용안내_2026-10-03.md)). 온보딩(GEN-05, Should)의 일부를 M1으로 앞당긴 것이라 요구사항 분류는 그대로다.

## 2. 메뉴 구조(IA)

왼쪽 내비게이션 순서: 대시보드 → 키워드 → 후보 작업 → 등록 상품 → 설정(하위 항목 AI 엔진) → 시스템 상태 → 사용 안내. 단계 화면(② ~ ⑨)은 후보 작업 안에서 단계 레일로 연다. AI 엔진(SCR-13)은 설정 아래 별도 페이지로 왼쪽 내비게이션에 따로 보인다(D-16). 사용 안내(SCR-14, `/guide`)는 맨 아래 '시스템 상태' 다음에 둔다(D-29).

```
스마트스토어 정복
├─ 대시보드 (SCR-01)            DB  시작 준비 카드 · 작업 흐름 카드 (M1, D-29)
├─ 키워드 (SCR-02)              KW
├─ 후보 작업 (SCR-12)           CW  후보 목록 · 후보 머리 · 단계 레일 · 연속 실행
│   ├─ ② 소싱 (SCR-03)          SO  라쿠텐 검색 · URL 붙여넣기 · 비교표
│   ├─ ③ 판정 (SCR-04)          PJ  국내 기준가 · 사이즈별 판정 · 판매가 · [G2]
│   ├─ ④ 카테고리 (SCR-04)      CA
│   ├─ ⑤ 썸네일 (SCR-05)        TH  레퍼런스 · 생성 · 선택 · [G3]
│   ├─ ⑥ 상세 콘텐츠 (SCR-06)   CT  ⑥-1 카피 · ⑥-2 고시 원자료 · ⑥-3 고시·고지·HTML·상품명
│   ├─ ⑦ 태그 (SCR-07)          TG
│   └─ ⑧⑨ 최종 승인·등록 (SCR-08) AP  사전 검증 · [G4] · 업로드 · 등록
├─ 등록 상품 (SCR-09)           PM  (M2부터)
├─ 설정 (SCR-10)                ST  M1은 구매대행 프로필·요금표·환율 입력만. 나머지 설정 화면은 M2(M1은 설정 파일)
│   └─ AI 엔진 (SCR-13)         ST  /settings/ai-engine · 엔진 3개(claude·agy·codex) 감지·연결 테스트·모델 선택·저장 · 저장 공간 (M1)
├─ 시스템 상태 (SCR-11)         SY  M1은 키 입력·인증 상태·메타 동기화·AI CLI 상태·첫 실행 AI 엔진 고르기. 사전 조건·첫 실행 안내는 M2
└─ 사용 안내 (SCR-14)           GD  /guide · 작업 흐름 다시 보기 · 하루 사용 순서 · 안전장치 뜻 · AI 계정 학습 끄는 곳 · 화면 목록 (M1). 첫 실행 마법사·체험 모드는 M2
   공통 기반(화면 없음)           BS  보안 · AI 실행 · 외부 연동 · 저장
   배포                           DP  동료 셀러 설치본
```

화면 제목 옆 '?' 도움말(`F-GD-02`)은 모든 화면에, 빈 상태 안내(`F-GD-03`)는 목록·표가 있는 화면에 붙는다(D-29). 화면에 보이는 안내 문구는 [안내문구](../design/spec/안내문구.md) 한 곳에 모으고, 화면 명세는 [화면시안_명세](../design/spec/화면시안_명세.md) §8에 있다.
