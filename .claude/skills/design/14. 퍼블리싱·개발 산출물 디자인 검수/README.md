# design-impl-review

개발이 코드로 빌드한 **실제 화면이 확정 시안과 픽셀·간격·컬러·타이포·반응형 거동까지 일치하는지**
검수하는 디자인 시리즈 14단계 **구현물 visual QA** 스킬. Playwright로 빌드 화면을 일관 조건으로 캡처 →
Figma 시안 원본·04 토큰·12 baseline과 **시안-토큰-구현 3자 대조** → 이탈 심각도별 리포트 → 수정 요청 →
재검수 루프. 핸드오프(13)와 (미빌드) 오픈 후 개선(15) 사이.

## 설치
`SKILL.md`를 `~/.claude/skills/design-impl-review/SKILL.md`로 복사.

- `<기획루트>` = `<기획 산출물 루트>/<주제>` (10 화면설계서·12 기능명세·06 정책 — 읽기 전용)

## 빌드 전제 — 11·12와 degrade 모델이 정반대 (핵심)
14의 검수 대상은 **빌드된 화면(스테이징/로컬 URL)**이고 Playwright 빌드 캡처가 **검수 입력의 1급 원천**이다.
11·12의 "Playwright 미연결→정적 분석으로 손실 없이 완성"을 **절대 계승하지 않는다**(정반대). **빌드 URL이
없으면 단계 자체가 성립 불가** — 시안만으로 "구현이 시안대로 됐나"를 판정할 수 없다. **빌드 부재(dry-run·
미배포 포함)→중단이 아니라 명세까지 degrade**(검수 매핑표·캡처 조건 명세·기대 토큰값 표까지만·실 검수 미발동).
⚠️ **시안만으로 가상 비교는 가짜 캡처·가짜 이탈을 낳으므로 절대 금지.** 빌드는 있으나 Playwright 미연결이면
수동 캡처 가이드+조건 명세만(사람이 캡처를 채워야 비교 발동).

## 12와 분리 (왜 별도 스킬인가)
**12=시안 자체 검수(Figma 안) / 14=빌드 구현물 검수(브라우저).** 같은 '검수'지만 대상이 다르다. 12가 baseline을
'14 후보 라벨'로 인계했고, 14는 12 baseline·13 핸드오프 패키지를 **비교 기준으로 소비**해 **시안-토큰-구현
3자 대조**로 책임을 가린다: (a) 구현이 토큰 안 씀=개발 수정요청(14 본업) / (b) 시안이 토큰 안 씀=**12로 환류**
(시안 결함은 12 소관) / (c) 04 토큰 공백=04 환류 후보(기재만).

## design-review 비호출 (이탈 분류 규율만 내장)
원본이 "design-review로 이탈 분류"라 하지만 **호출하지 않고 규율만 내장**(07·12·13 선례). design-review =
출력 기획 폴더 `13_디자인리뷰` 고정·대조 축이 시안↔기획(시안↔구현물 아님)·이중 게이트 + **토큰 미준수 지적을
'월권'으로 배제**(14 핵심 토큰 수치 대조 무력화). 계승=검출=후보·수정요청/질문/제안·심각도·근거 인용·약관/결제
[사람 직접 검수]. **계승 제외**=토큰 월권 규율.

## BMD · 토큰 3자 대조 · 도구 사실
색·간격·폰트·터치타깃 진실 = **04/08 tokens.css·color.json SSOT**. 본문·산출물에 임의 hex/px 리터럴 재기재
금지(터치타깃은 WCAG 2.5.5 인용). 3자 대조 = 04 정의 ↔ 시안 적용(get_design_context·get_variable_defs
보조) ↔ 빌드 computed style. **빌드 computed style은 `browser_evaluate(getComputedStyle)`로 추출**
(`browser_snapshot`은 접근성 트리·CSS computed style 미반환 — 원본 오기 정정). hex 정규화 비교·폰트 폴백 검출.

## 스크린샷 한계 · 검출=후보 · 시각 품질 사람
렌더링 엔진·안티에일리어싱·서브픽셀로 1~2px 차이는 진짜 이탈 vs 렌더링 차이 섞임 → 캡처 단독 판정 금지·
`get_design_context` 스펙값+computed style 병행. 검출=후보(의도적 조정=로딩 스켈레톤·접근성 대비 강화 오검출
가능·게이트2 사람 재분류 전엔 후보). 미감·위계·균형은 디자이너 영역.

## Playwright 안전 (운영 금지)
대상 URL 확인(staging/test/dev 아닌 운영/결제 의심 도메인 경고·기본 차단·게이트 사람 확인 후만 캡처)·테스트/
스테이징 계정 한정·운영 데이터 조작 금지·비밀번호 런타임 입력(평문 금지)·스크린샷 입력칸/세션/실고객 정보
마스킹. 미연결 시: `claude mcp add playwright npx '@playwright/mcp@latest'`. (SKILL 본문은 mcp add
하드코딩하지 않음 — README 전용.)

## Figma MCP · Notion MCP
Figma read(get_screenshot 시안 원본·get_metadata 매핑표·get_variable_defs 보조·get_design_context 스펙값)·
write 전면 금지(시안 read 검수). 미연결 시: `claude mcp add --transport http figma https://mcp.figma.com/mcp`.
Notion은 리포트 공유·재검수 추적(옵트인·게이트2 후·민감정보 더미). 미연결 시:
`claude mcp add --transport http notion https://mcp.notion.com/mcp`. 미사용→마크다운 SSOT.

## 동적·상태 화면 · 캡처 조건 고정 · 시안 부재
정상 플로우 + 5종 상태(로딩/빈데이터/에러/권한없음/입력검증)를 에러 mock·데이터 0건 계정·긴 텍스트로 강제
캡처(상태 분모 12-2/06-3). 캡처 조건(뷰포트·로그인·애니메이션 종료·스크롤·동적 콘텐츠 더미) 고정·기록→재검수
동일 조건. **시안 부재 브레이크포인트는 11-1 규칙으로만 판정·AI 추정 금지·"시안 부재" 명시.** 브레이크포인트
(레이아웃 분기점·04 SSOT·360/768/1280)와 캡처 뷰포트(디바이스 실폭·375 등)는 다른 축.
