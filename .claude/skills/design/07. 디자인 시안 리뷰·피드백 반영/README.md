# design-consistency-review

06 완성 UI 시안을 개발 핸드오프(13) 전에 **디자인 팀 내부**가 자기검증하는 디자인 시리즈 7단계 **읽기
전용 검증 스킬**. ①기획 정합성(시안↔10/12/06) ②**디자인 일관성(토큰 이탈·컴포넌트 미사용·WCAG 접근성을
1급)**을 점검해 디자인 리뷰 리포트와 용어집을 만든다. UI 시안(06)과 컴포넌트화(08) 사이.

## 설치
`SKILL.md`를 `~/.claude/skills/design-consistency-review/SKILL.md`로 복사.

## 일반경로 치환 포인트 (`<!-- 변경 포인트 -->`)
- `<기획루트>` = `<기획 산출물 루트>/<주제>` (10 화면설계서·12 기능명세·06 정책)
- `<디자인입력>` = `<디자인 산출물 루트>/<주제>` (06 시안·04 토큰·05-2 상태)
- `<출력루트>` = `<디자인 산출물 루트>/<주제>/07_시안리뷰`

⚠️ 원본 가이드의 `디자인/디자인 리뷰 리포트_*.md`·`디자인/용어집.md` 평면경로는 정규화 폐기
(`산출물/`은 스킬 배포 폴더 전용) → 출력은 `07_시안리뷰/`.

## design-review와 왜 다른가 (별도 스킬인 이유)
design-review(기획 시리즈)는 "기획↔시안 정합성"만 보고 **토큰을 '월권'으로 배제**한다. 본 스킬은 그 반대로
**②디자인 일관성(토큰 이탈·컴포넌트 미사용·접근성)을 1급**으로 끌어올린다 — 이게 분리 근거다. **design-review를
호출하지 않는다**(출력경로가 기획 폴더 고정·자체 게이트 보유·Skill 서브에이전트라 인계 제어점 없음) →
05(design-wireframe-review)처럼 규율만 내장 계승한다.

## 입력 전제
- **핵심·필수**: 시안 = (a) Figma 링크 OR (b) `06_UI시안/06-2_시안초안/*.html`. 부재면 중단.
- **준필수(②축 기준)**: `04_디자인시스템/`(tokens.css·color.json). 부재면 ②디자인 일관성 축 비활성+⚠️.
- **정합성 필수**: `10_화면설계서/`. 부재면 ②축만. (시안+04 둘 다 없으면 중단.)
- 권장: `06-3`·`06-4`(시안 분기판정·06 기계검출 경계) · `05-2`(상태 분모) · `12`·`06`(메시지·정책 근거).

## 읽기 전용 (Figma READ만)
시안은 읽기만 한다 — `get_design_context`·`get_screenshot`·`get_metadata`·`get_variable_defs`를 호출하며
**`use_figma`·`create_new_file` 등 write는 금지**(수정은 디자이너가 리포트를 보고 직접). 미연결 시: `claude mcp
add --transport http figma https://mcp.figma.com/mcp` 후 `/mcp` 인증(열람 권한 계정). 미인증·dry-run이면 06-2
HTML DOM 파싱으로 진행. (SKILL 본문은 mcp add를 하드코딩하지 않는다 — README 전용.)

## 토큰 진실은 04 (재계산 아님)
WCAG 대비비는 `04/scripts/out/color.json`의 `wcag_combos` 표가 SSOT다. 07은 시안이 쓴 색조합을 활성 테마
(06-3 확정) 행과 **대조**할 뿐 재계산하지 않는다(수록분 한정·미수록 조합은 `[확인필요]`). 토큰 하드코딩은 06이
이미 기계검출했으므로 07은 06-4 `[확인 필요]` 항목을 04/06 환류 후보로 라우팅한다. **04 공백은 07-3에 환류
후보로 기재만** 하고 04 파일은 직접 편집하지 않는다(읽기전용 정합).

## 06 자기검증과 경계
06(design-mockup)의 Stage6 자가점검은 **기계검출만**(토큰 하드코딩·요소 누락·컴포넌트 일관). 07은 그 위에
**사람 합의 + 정책 문구 정합성 + 용어 통일 + 접근성 + 의도적 변경 분류**를 더한다(중복 회피).

## Notion (옵트인)
리뷰 항목 추적(완료/보류/반려)은 옵트인이다. 마크다운이 SSOT, Notion은 체크박스 토글 미러. 미인증이면
스킵+`/mcp`. parent는 `notion-search`로 확인. 민감정보는 더미.

## 출력물
`07-1_정합성체크` · `07-2_상태커버리지·QA` · `07-3_디자인일관성`(★고유: 토큰·컴포넌트·접근성·04 환류 후보) ·
`07-4_용어집`(★1급) · `07-5_디자인리뷰리포트`(최종 통합) · `_검증체크리스트`.

## 다음 소비자 계약
**용어집(07-4)이 디자인 08(컴포넌트 네이밍)·12(디자인 QA)·13(개발자 핸드오프)의 SSOT**가 된다(기획 시리즈
