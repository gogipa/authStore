# 오픈 후 디자인 개선·고도화 (Design Improvement)

오픈은 끝이 아니라 디자인 사이클의 재시작점이다. 14단계까지가 "기획서대로 잘 만들어졌나"(안쪽)였다면 15는
**"현실에서 의도대로 동작하나"를 실제 사용자 데이터로 측정하고, 그 근거 위에서 무엇을 고칠지 판단**한다.
입력은 두 종류 — **정량**(GA4/Amplitude export CSV의 퍼널 이탈·전환율 = "어디서") + **정성**(Clarity/Hotjar
마찰 시그널·히트맵 + 앱리뷰·CS VOC = "왜"). 둘을 같은 화면 키로 묶은 **정량×정성 교차표**가 이 단계의 중심이다.
산출물 = 개선 가설 백로그(RICE) · A/B 변형 시안·설계서 · 결과 결론. **디자인 시리즈 15/15(마지막)이자 순환의
분기점** — 다음 단계는 없고, 검증된 방향은 design-reference-research(02)·design-requirements(01)로 **회귀**한다.

## 두 기획 스킬(improvement-planning·metrics-analytics)을 호출하지 않는 이유 (규율만 내장·1급)

원본이 Step별로 "`improvement-planning` 스킬로", "`metrics-analytics` 스킬로"라 하지만 **Skill로 호출하지 않고
규율만 내장**한다(디자인07·12·13·14가 동명이역 design-review/qa-test-design/dev-handoff를 비호출 처리한 선례). 비호출 4사유:

1. **출력경로 기획 폴더 고정** — improvement-planning은 `기획/리서치/<주제>/18_개선고도화/`, metrics-analytics는 `…/17_지표분석/`에 쓴다(디자인15 산출물이 기획 폴더로 떨어져 **볼트 폴더 제약 정면 위반**).
2. **write-back 기획 폴더 한정** — 두 스킬의 환류가 모두 기획 폴더 한정.
3. **이중 게이트** — 각자 게이트1·2를 따로 보유(흐름 충돌).
4. **입력 계약 불일치·동명이역 [[15]] 충돌** — metrics-analytics 입력 필수는 04·08 **기획** 산출물(디자인15 입력과 불일치해 호출 시 게이트에서 중단). 번호 [[15]]도 기획15(qa-test-design)와 충돌.

→ **계승(내장)**: 아래 「핵심 원칙」의 인과 절제·VOC dedup·표본 stdout·RICE 초안·17 가드레일 상속·게이트·degrade.
원본의 "~스킬으로" 문구는 **"내장 규율로"**로 읽는다. 기획18 백로그·기획17 지표정의서는 **읽기 전용 참조**(병합·근거)일 뿐 그 스킬을 호출하거나 그 폴더에 쓰지 않는다.

## 핵심 원칙

- **인과 절제 = 가설은 검증 대상이지 단정 아님.** 관측 사실(수치)만 단정하고 **원인·인과는 가설**(사람·A/B 검증)로 분리. 가설 형식 = "**[근거ID] 때문에 [변경]을 하면 [지표]가 [방향]으로 변할 것이다**". 상관≠인과(이탈 높은 화면=그 화면이 나쁜 것 아닐 수 있음·앞 단계 기대·가격 원인 가능). **교차표·RICE는 "잘 정리된 가설 보드이지 검증된 결론이 아님"** 워터마크.
- **가설↔근거 양방향 차집합 ✓**(python3): (가설 출처 ID − distinct 근거 풀)=∅(날조 0) AND (근거 풀 − 인용)=누락 목록. 둘 다 인쇄해야 ✓·출처 셀 빈 가설은 `[근거 미상·확인 필요]` 강등. **산문 근거는 출처 칼럼 등재 전까지 인정 안 됨.**
- **VOC 규율**: ①**소스 dedup 선행**(상류 흡수 관계 cross-ref → distinct 차집합 python3 인쇄·중복 계상 0) ②**VOC 빈도 ≠ 우선순위**(리뷰=극단 경험 편향·정량과 1:1 교차 강제·정량 근거 없는 VOC는 "VOC 신호"로만) ③**표본미달 가드**(총 분류 N ≥ `[[임계값:합의]]`일 때만 결론·미달은 `[참고용·결론 제외]`) ④**인용 verbatim만**(다듬기·창작=환각) ⑤**출처 2분기**(실수집 텍스트=카테고리·감성·심각도·원문 행번호 / 내부 프록시=안정 ID·감성·대표인용 N/A·"발화 아님" 워터마크).
- **정량×정성 교차표(★1급 산출물)** = `[화면 S-ID | 정량 근거ID | 정성 근거ID | 둘 다 충족? | Confidence]`. **Confidence는 "둘 다 충족" 컬럼에서 기계 파생**(자유 입력 금지·둘 다=상향·한쪽만=`[신뢰도 낮음]`·1순위 후보 자동 제외). 13 용어집 기준 사용자 표현↔UI 용어 어긋남 별도 표기.
- **히트맵·마찰 "시안 위 겹침"의 좌표계 한계**(고유작업 가드): Clarity 마찰 export는 DOM 셀렉터/실측 픽셀 좌표(라이브 빌드), `get_screenshot`은 Figma 시안 프레임 좌표 → **원점·스케일이 달라 1:1 매핑이 없다.** AI가 히트맵 이미지에서 좌표를 어림해 시안 요소에 겹쳐 그리면 **환각**(LLM은 이미지 수치를 자주 오독). 규율: ①지목의 **진실 = 마찰 시그널 CSV(텍스트)** 이지 히트맵 이미지가 아님 ②매핑은 좌표 어림이 아니라 **셀렉터/영역 라벨 ↔ 시안 명명 요소(컴포넌트명·S-ID·`get_design_context` 레이어명) 텍스트 매핑표** `[셀렉터 | 마찰유형·건수 | 대응 시안 요소 | 매핑 신뢰도]`·모호=`[확인 필요]` ③dead click "눌릴 것 같은데 안 눌리는" 후보는 **가설**(검출=후보·단정 금지) ④**세션 리플레이 영상은 AI가 못 본다** — 마찰 시그널로 후보만 좁히고 5~10개 시청은 사람.
- **BMD: 색·간격·타이포·터치 타깃 값의 진실 = 04/08 `tokens.css`·`scripts/out/color.json`(SSOT).** SKILL 본문·산출물에 임의 hex/고정 px 리터럴 재기재 금지(예시 라벨 '강조 색'·'체크 아이콘'만·실값 금지). 터치 타깃 최소 크기는 04 인용 또는 WCAG 2.5.5 출처 인용(원본 "44x44pt" silent 계승 금지).
- **A/B 표본 계산 = python3 스크립트(stdout이 진실).** 암산·채팅추정·재반올림 금지·복붙 실행 시 동일 stdout 재현(아래 「도구 정확성」 공식). 일트래픽·baseline·MDE는 외부 파라미터(`[[일트래픽:합의]]`·`[[baseline:합의]]`·`[[MDE:합의]]`)·미입력 시 **"A/B 가부 미정([데이터 확인 필요])"** degrade. 본문·산출물에 표본 수치 리터럴 재기재 금지(stdout 인용만).
- **use_figma WRITE(개선 시안 생성)의 안전 조건**(시리즈 최초 WRITE·가장 위험): ①변형 색/간격/타이포는 04/08 토큰 인용으로만(임의 hex/px 0건) ②호출 직전 `get_variable_defs`로 토큰 바인딩 확인(**보조**·진실 아님·하드코딩 거짓통과 가능·SSOT는 04/08) ③**A↔B diff 표**`[변경요소 | A값(토큰) | B값(토큰) | 검증변수? Y/N]`에서 **Y 행이 정확히 1개**여야 ✓(2개 이상=효과 분리 불가→변형 분할 경고)·부수 변경(접근성 보강 등)은 A·B 양쪽 동일 적용해 검증 변수 격리 ④`/figma-use` 스킬 선독 후 호출 ⑤**게이트2 사람 WRITE 승인**·운영 디자인 시스템 파일 오염 방지 ⑥**dry-run에서 전면 생략**(변형 명세표까지만·프레임 미생성).
- **🔴 PII·측정 윤리(게이트 블로킹)**: VOC/마찰 CSV 적재 전 PII 컬럼(이름·연락처·결제·URL 파라미터) 비식별/더미 확인·user_id 비식별만·미확인 시 정성 분석 차단. 세션 리플레이 입력 필드·Clarity 민감영역 마스킹 점검은 사람. Notion 공유본은 실 도메인·금액·고객정보 더미·게이트2 후·옵트인.

### 번호 혼동·단일 키 (family 동명이역 그물)
