# design-improvement

오픈 후 **실제 사용자 데이터(정량 GA4/Amplitude + 정성 Clarity 마찰·VOC)로 디자인을 어떻게 고칠지 판단하고,
정량×정성 교차표·개선 가설 백로그(RICE)·A/B 변형 시안까지 만들어 검증된 방향을 다음 디자인 사이클로 회귀**시키는
디자인 시리즈 **15단계(마지막)** 스킬. 14단계까지가 "기획서대로 잘 만들어졌나"(안쪽)였다면 15는 "현실에서 의도대로
동작하나"(바깥)를 측정한다. 디자인 시리즈의 **종착이자 순환의 분기점**(다음 단계 없음).

## 설치
`SKILL.md`를 `~/.claude/skills/design-improvement/SKILL.md`로 복사.

- `<디자인입력>` = `<디자인 산출물 루트>/<주제>` (04/08 토큰·06 시안·11·12/14 결함·13 용어집 — 읽기)
- `<기획루트>` = `<기획 산출물 루트>/<주제>` (17-1 지표정의서·가드레일·18-2 개선 백로그 — **읽기 전용 참조**)
- `<출력루트>` = `<디자인 산출물 루트>/<주제>/15_개선고도화`

⚠️ 원본 평면경로(`산출물/개선백로그_*.md`·`산출물/AB_*.md`·`산출물/데이터/*.csv`)는 정규화 폐기
(`산출물/`은 스킬 배포 폴더 전용) → 전 산출물 `15_개선고도화/` 하위·파일 prefix **15-**(17-/18- 충돌 방지).
실 CSV는 `15_개선고도화/data/`에 사람이 넣은 것만 읽음(디자인 폴더 안에서만).

## 두 기획 스킬을 호출하지 않는다 (비호출 + 규율 내장 — 핵심)
원본은 `improvement-planning`(기획18)·`metrics-analytics`(기획17)를 명시적으로 호출하라 하지만 **Skill로 호출하지
않고 규율만 내장**한다(디자인07/12/13/14 선례). 비호출 4사유: ①두 스킬 출력이 **기획 폴더에 하드코딩**
(`기획/…/18_개선고도화`·`…/17_지표분석`)이라 호출 시 디자인 산출물이 기획 폴더로 떨어져 **볼트 폴더 제약 정면
위반** ②write-back도 기획 폴더 한정 ③각자 게이트1·2 보유(이중 게이트) ④metrics-analytics 입력 필수가 04·08
**기획** 산출물이라 디자인15 입력과 불일치(호출 시 게이트 중단)·번호 [[15]]도 기획15(qa-test-design)와 충돌.
→ 그 대가로 **A/B 표본 계산·VOC dedup·인과 절제·RICE 초안·17 가드레일 상속·게이트·degrade**를 본문에 직접 흡수.
기획18 백로그·기획17 지표정의서는 **읽기 전용 참조**(병합·가드레일 근거)일 뿐 호출·쓰기 안 함.

## 정량×정성 교차표가 중심 (★1급 산출물)
GA4의 "플랜 선택 35% 이탈"은 위치만, Clarity의 "이 카드 dead click 다발"은 증상만 알려준다. 둘을 같은 화면 키
(S-ID)로 묶은 **교차표**`[화면S-ID|정량근거ID|정성근거ID|둘 다 충족?|Confidence]`에서 비로소 "무엇을 어떻게
고칠지"가 가설이 된다. **Confidence는 "둘 다 충족" 컬럼에서 기계 파생**(둘 다=1순위 후보 / 한쪽만=`[신뢰도 낮음]`·
후보 제외). 교차표·RICE는 **"잘 정리된 가설 보드이지 검증된 결론이 아님"** — 검증은 A/B가, 판단은 사람이 한다.

## 히트맵·마찰 "시안 위 겹침"의 좌표계 가드
Clarity 마찰 export는 DOM 셀렉터/실측 좌표(라이브 빌드), `get_screenshot`은 Figma 시안 프레임 좌표 → 원점·스케일이
달라 **1:1 매핑이 없다**. AI가 히트맵 이미지에서 좌표를 어림해 겹쳐 그리면 환각. 그래서 ①지목의 진실 = 마찰 시그널
**CSV(텍스트)** ②매핑은 좌표 어림이 아니라 **셀렉터↔시안 명명요소(컴포넌트명·S-ID·레이어명) 텍스트 매핑표**
③dead click 후보는 **가설** ④세션 리플레이 영상은 **AI가 못 봄**(마찰 시그널로 후보만 좁히고 사람이 시청).

## A/B 표본 계산 = python3 스크립트 (stdout이 진실)
표본 수·기간은 반드시 계산해서 정한다(감으로 "2주 돌리죠"는 검정력 부족 = 결론 못 냄). python3.9 stdlib(`math`)·
2비율 정규근사·z 정확값(z(0.025)=1.959964, 검정력0.8 z=0.841621)·`mode=absolute|relative` 필수 인자·자가 sanity
(p1=10%·MDE 2%p→그룹당 3841 = Evan Miller 일치)·일트래픽/baseline/MDE 외부 파라미터·미입력 시 "가부 미정" degrade.
**암산·채팅추정·재반올림 금지·복붙 실행 시 동일 stdout 재현**·Evan Miller 웹 교차. 본문 수치 리터럴 금지(stdout 인용).
조기 종료(peeking) 금지·표본 미달=전후비교 degrade(인과 단정 금지·관측 변화만 기록).

## use_figma WRITE = 시리즈 최초의 쓰기 (조건부 격상)
디자인15 고유 본업이 A/B B안 변형 시안 **생성(WRITE)**이다(14까지는 READ 전용). 가장 위험한 호출이므로 6중 가드:
①변형 색/간격/타이포는 04/08 토큰 인용만(임의 hex/px 0건·터치타깃은 04/WCAG 2.5.5 인용) ②호출 직전
`get_variable_defs`로 토큰 바인딩 확인(**보조**·진실 아님·SSOT는 04/08) ③**A↔B diff 표에서 검증 변수 정확히 1개**
(2개 이상=효과 분리 불가→변형 분할·부수 변경은 양쪽 동일 적용) ④`/figma-use` 스킬 선독 ⑤**게이트2 사람 WRITE
승인**·운영 디자인 시스템 파일 오염 방지 ⑥**dry-run 전면 생략**(변형 명세표까지만·프레임 미생성).

## 회귀(루프 마감)는 자기 폴더 핸드오프 카드로만
검증된 방향은 design-reference-research(02)·design-requirements(01)로 회귀한다. 단 두 스킬은 15 회귀 입력 슬롯이
없고 "기획·디자인01은 읽기만, 쓰기는 자기 출력 루트 안에서만"을 명시하므로, **01/02 폴더에 직접 쓰지 않고**
`15_개선고도화/15-7_결과회귀카드.md`에 ①02 입력 카드(검증된 UX 패턴·다음 레퍼런스 영역) ②01 입력 카드(신규/변경
요구사항 후보)를 둔다. 다음 사이클 실행자가 `<주제>-v2` 슬러그로 능동 수령. **검증된 학습만 회귀**(기각/보류/표본미달
회귀 금지)·회귀 카드 신규 항목 ID는 디자인15 네임스페이스 **DI-**만 발번. KPT 회고는 "백로그 우선순위·다음 사이클
진입 합의 자리". 기획18 백로그와 한 RICE 보드 병합(출처 컬럼 디자인/기획·기획 폴더는 읽기 전용 참조).

## dry-run 분기 (시리즈 최고 위험)
외부 실호출이 가장 많고 use_figma가 WRITE라 dry-run에서 Figma `whoami`/`get_*`/`use_figma`(WRITE)·Notion·실 CSV
분석·Clarity 스크래핑을 **전부 생략·실호출 금지**. 로컬 04/08·17/06/12/13/14 Read만 1급. 표준 배너로 "실데이터
분석·시안 생성 미수행(가상 분석·가짜 시안 금지)" 명시. 실데이터 부재면 골격까지가 산출물(빈손 미완 아님).

## 자체 2게이트 + degrade 매트릭스
비호출이라 두 기획 스킬의 게이트가 안 따라오므로 자기완결. 게이트1=근거 소스·분류체계·옵트인·정본 주제명·빌드/Figma
URL. 게이트2=가설↔근거 차집합 ✓·RICE 순위 잠정·리플레이 시청 체크박스·use_figma WRITE 승인·Notion·PII 더미.
degrade 매트릭스(입력상태×산출물): GA4+VOC=완전 / GA4만→정성 [확인필요] / VOC만→정량 [확인필요] / 둘 다 없음→골격만
(dry-run 동형) / A/B 표본미달→전후비교. 게이트 블로킹: 차집합 미검증·PII 미확인·WRITE 미승인 시 외부 액션 차단.

## 🔴 PII·측정 윤리
