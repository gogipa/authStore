# 디자인 QA (Design QA)

06 시안·08 토큰이 확정되면 **개발 핸드오프 직전에 시안 자체의 내부 품질**을 정밀 검수한다. 관심사는
"시안이 기획서와 맞는가"(그건 07이 한다)가 아니라 **시안 안에서 디자인이 일관되고·접근 가능하고·모든
상태가 빠짐없이 그려져 있는가**다. 4검사: ①디자인 시스템 토큰 이탈(임의 hex·비-스케일 간격) ②간격·정렬
오류 ③접근성(WCAG 대비·터치 타깃·색상 의존·동적 접근성) ④상태 누락(empty/error/loading/disabled/권한).
산출 = 심각도별 QA 리포트 + 누락 상태 화면 추가 작업 목록 + 시각회귀 baseline. **검증·검수 스킬(읽기 전용).**

## 07과의 위상 분리 (왜 별도 스킬인가 · 1급)

`design-consistency-review`(07)는 **리뷰 단계의 정적 1차 거름**(토큰 이탈·정적 WCAG·시안↔기획 정합)이고,
12는 **핸드오프 직전 최종 전수 정밀 QA**다. 같은 토큰 이탈·정적 WCAG를 **재실행하지 않는다**:

- **07 결과를 입력으로 수령**(`07-3_디자인일관성`·`07-5_리포트`) → 07 검수 **이후 변경분(diff)·07 `[확인 필요]` 잔존·07 미커버 프레임만** 전수 마감.
- **07 산출물 부재 시에만** 12가 직접 전수(degrade·중복 감수·⚠️).
- ⚠️ **07이 거의 다 닫은 경우(수정요청 0·토큰 이탈 0)도 정상** — diff가 0이어도 12 고유 1급은 남는다: **①미수록 WCAG 핸드오프 직전 최종 승격 ②동적 접근성 수령 ③상태 커버리지 최종 재확인 ④터치 타깃 실측 후보**. 12-1이 07 재기재가 되지 않게 이 4종에 집중.
- 12 고유 1급 = **①동적 접근성 수령**(07이 명시 위임) **②상태 커버리지 핸드오프 직전 최종 매핑** **③시각회귀 baseline 확보**.
- ⚠️ **12는 시안↔기획 정합성을 다루지 않는다**(07 소관). `design-prototype↔prototype-design`, `design-consistency-review↔design-review` 분리 선례 동형.

## design-review·qa-test-design을 호출하지 않는 이유 (규율만 내장 계승)

원본 가이드가 "design-review로 점검·qa-test-design으로 상태 체크리스트"라 하지만 **둘 다 Skill로 호출하지 않고 규율만 내장**한다(07·10 선례).

- **design-review 비호출 3사유**: ①출력경로가 기획 폴더 `13_디자인리뷰` 고정 ②자체 게이트 2개로 이중 게이트 ③서브에이전트라 인계 제어점 부재. + 결정적으로 **design-review는 토큰을 '월권'으로 배제**하므로 토큰 이탈을 design-review로 돌릴 수 없다(원본의 "시안 내부 품질 점검 모드"는 비실재 표현). 계승 = 검출=후보·수정요청/질문/제안 분리·근거 인용·심각도(상/중/하)·약관/결제/법적고지 `[사람 직접 검수]` 플래그·심각도 하 묶음·AI 자동 칭찬 금지.
- **qa-test-design 비호출 3사유**: ①출력경로가 기획 폴더 `15_QA테스트` 고정 ②이중 게이트 ③인계 제어점 부재. 계승 = 5종 상태 분모·상태≠화면 주석·기능ID 1:1 근거 매핑·환각 항목 금지·확정 판정만 단정·명세 누락 환류. **계승 제외** = TC 시트·E2E·버그 리포트·결과 집계(기획 family). 워크플로우의 "qa-test-design 스킬로" 문구는 **"내장 상태 커버리지 규율로"**로 읽는다.

## 핵심 원칙 (어기면 QA가 거짓이 된다)

- **토큰 이탈 진실 = 04/08 `tokens.css`(SSOT) + 시안 HTML `var()` 바인딩·HEX/px grep.** `get_variable_defs`는 **보조**(selection 한계·하드코딩 거짓통과·미바인딩 후보는 디자이너 인스펙터 확인 플래그) — 원본의 "get_variable_defs=토큰 이탈 판정 기준"은 교정. Figma 모드는 `get_design_context` 실제값을 04/08 토큰셋과 자리별 대조.
- **토큰 이탈 grep `:root` 화이트리스트**(06·11·10 연속 함정): `:root`/토큰 정의 블록의 인라인 인용 HEX/px는 **거짓양성 제외**, `body`·인라인 `style=`·`var()` 미사용 raw값만 이탈 판정. `1px` border-width·`min-height`·캔버스/뷰포트 치수는 space 토큰 대상 제외(04/06 환류 후보로만 기재). 비-스케일 간격은 04 스페이싱 스케일(4px 그리드·half-step 2 허용) 기준 **4-미배수만** 위반. macOS grep `-P` 미지원 → python3 정규식.
- **WCAG 대비 진실 = 04 `scripts/out/color.json`의 `wcag_combos`(SSOT·재계산 금지·LLM 암산 금지).** 시안 alias → 활성 테마 resolve 후 해당 theme 행 wcag_combos 대조. **미수록 핵심조합**(본문 text-muted·에러배너 등)은 07-3을 입력으로 dedup하고 `[확인 필요: 미수록→디자이너 수동확인]`, 핵심조합이면 **심각도 상 승격(핸드오프 직전 마감)**. ⚠️ **07이 이미 미수록으로 라우팅·04 환류(FB-n)한 조합은 재판정/중복 환류 금지** — 07 환류를 승계하고 **심각도만 상으로 올린다**. 07 미라우팅 신규 미수록만 04 환류 후보로 신규 등록. 반투명·그라데이션·이미지 위 텍스트는 단일 hex 대비 불가 → `get_screenshot`+사람.
- **BMD: 토큰값(hex·간격 px)·터치 타깃/뷰포트 치수는 04 인용만.** SKILL 본문·산출물에 임의 hex·고정 px 리터럴 재기재 금지(검출 결과에만 04 인용으로 현재값 기록).
- **검출 = 후보이지 판정 아님.** 의도적 예외(프로모션 배너 브랜드 컬러 등)를 "이탈"로 오검출할 수 있다. 게이트2에서 사람 재분류 전엔 '후보'로만 기록·그대로 던지기 금지.
- **시각 품질은 사람 몫.** 위계·여백·균형·심미성은 스크린샷 평가 불신뢰·디자이너 영역. AI는 토큰/대비/상태/정렬 정량까지. `get_screenshot`은 사람에게 보여주는 시각 확인 보조이지 AI 시각 판정 입력 아님.
- **시안 vs 구현물(14) 경계.** 12 = 시안 결함을 처음 찾는 자리 / 14 = 코드가 시안을 따랐는가(구현물 검수). 섞으면 책임 소재가 흐려진다. Playwright는 baseline 보조이지 구현물 테스트가 아니다.
- **읽기 전용 QA.** `use_figma`·`create_new_file` 등 Figma write 전면 금지(수정은 디자이너). 환류는 기재만.

## 동적 접근성 수령 (07 위임 · 2분기)

07이 *"스크린리더·포커스 순서·키보드 내비·실디바이스 등 동적 접근성은 디자인12로 위임"*했다. 시안 경계를 깨지 않고 받는다:

- **(a) 시안에서 정량 검출 가능분** = 터치 타깃 최소 크기(⚠️ HTML/dry-run 모드에선 padding 토큰 기반 **후보 추정만**·실측 렌더 크기는 (b) 재위임)·색-단독 상태표시·DOM/레이어 순서 기반 **포커스 후보**·대체텍스트 자리 → **'검출=후보'**로 12-1에 기록.
- **(b) 실제 키보드 조작·스크린리더 발화·실기기 터치·실측 렌더 크기** = **시안 판정 불가** → `12-3_접근성검수요청.md`에 `[접근성 검수 요청 항목]`으로 명세화해 **14/구현·사람 실기기로 재위임**. (시안 HTML의 aria/role 부재는 12가 결함 후보로 잡되 구현 확정은 14.)

### Stage 3 — 상태 커버리지 → `12-2`

### Stage 4 — (옵트인) 시각회귀 baseline

PNG 부재이고 사용자 선택 시에만 Playwright 신규(소스 = 10 `prototype/index.html` 또는 06-2 HTML·뷰포트 px는 04 breakpoint 토큰값 인용 리터럴·`@media`엔 `var()` 불가(11 함정 계승)·원본 375/1440 등 silent 계승 금지). **baseline = 14 회귀자산 후보 라벨**(13·14 미빌드→자동 인계 금지). Figma Make는 자동 캡처 불가(수동 export 시만). **dry-run·미연결·11 PNG 0건 → baseline 생략·인덱스 언급만.**

- 간격·정렬 이상치(동일 역할 요소 마진/패딩 분포 이상치·정량 사실만·위계/여백/균형 제외·HTML 모드는 computed style 추정·`[확인 필요]`). **용어 정합**(시안 텍스트 ↔ 07-4 용어집·불일치=수정 요청·07-4 부재 시 degrade).
