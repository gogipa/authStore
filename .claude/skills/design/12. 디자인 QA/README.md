# design-qa

06 시안·08 토큰이 확정된 뒤 **개발 핸드오프 직전에 시안 자체의 내부 품질을 최종 전수 정밀 QA**하는
디자인 시리즈 12단계 검증·검수 스킬(읽기 전용). 토큰 이탈·간격/정렬·접근성(WCAG·동적)·상태 누락을
심각도별 리포트로 검출하고 추가 작업 목록·시각회귀 baseline을 남긴다. 반응형(11)과 핸드오프 사이.

## 설치
`SKILL.md`를 `~/.claude/skills/design-qa/SKILL.md`로 복사.

- `<기획루트>` = `<기획 산출물 루트>/<주제>` (12 기능명세=상태 정의 — 읽기 전용)

## 07과의 위상 분리 (핵심 — 왜 별도 스킬인가)
`design-consistency-review`(07)는 **리뷰 단계의 정적 1차 거름**(토큰 이탈·정적 WCAG·시안↔기획 정합),
12는 **핸드오프 직전 최종 전수 정밀 QA**. 같은 토큰 이탈·정적 WCAG를 **재실행하지 않고** 07 결과
(`07-3`·`07-5`)를 입력으로 받아 **07 이후 변경분(diff)·07 `[확인 필요]` 잔존·07 미커버 프레임만** 마감.
07 산출물 부재 시에만 12가 직접 전수(degrade·중복 감수). 12는 시안↔기획 정합성을 다루지 않는다(07 소관).
12 고유 = ①동적 접근성 수령 ②상태 커버리지 최종 매핑 ③시각회귀 baseline.

## design-review·qa-test-design 비호출 (규율만 내장)
원본이 "design-review로 점검·qa-test-design으로 상태 체크리스트"라 하지만 **둘 다 호출하지 않고 규율만
내장**한다(07·10 선례). design-review = 출력 기획 폴더 `13_디자인리뷰` 고정·이중 게이트·인계 제어점 부재 +
**토큰을 '월권'으로 배제**하므로 토큰 이탈을 못 돌림("점검 모드"는 비실재 표현). qa-test-design(기획15) =
출력 기획 폴더 `15_QA테스트` 고정 → 상태 커버리지 규율만 계승(TC 시트·E2E·버그·집계는 계승 제외).

## 동명이역 주의 (qa-test-design)
`qa-test-design`은 **기획 시리즈 QA**(기능 테스트케이스·입력 기획12·출력 기획15). 디자인12는 **디자인 QA**
(시안 자체 품질). 슬러그 `design-qa`·description 차별자로 분리. "디자인 QA"·"시안 검수"는 본 스킬,
"기능 테스트케이스·TC"는 qa-test-design, "기획↔시안 대조"는 design-review.

## 동적 접근성 2분기 (07 위임 수령)
07이 "스크린리더·포커스 순서·키보드 내비·실디바이스 등 동적 접근성은 디자인12로 위임"했다. 시안 경계를
깨지 않고: **(a) 시안 정량 검출 가능분**(터치 타깃·색-단독 상태표시·DOM 포커스 후보·alt 자리)=검출 후보 /
**(b) 실 키보드·스크린리더·실기기 터치**=시안 판정 불가→`12-3_접근성검수요청`으로 14·사람 실기기 재위임.

## 토큰·WCAG 진실 (BMD)
토큰 이탈 진실 = **04/08 tokens.css(SSOT) + 시안 HTML `var()` 바인딩·HEX/px grep**(`:root` 화이트리스트로
인라인 인용값 거짓양성 제외·06·11·10 연속 함정). `get_variable_defs`는 보조(selection 한계·하드코딩
거짓통과). WCAG 대비 진실 = **04 `scripts/out/color.json`의 `wcag_combos` 대조**(재계산·LLM 암산 금지).
미수록 핵심조합은 심각도 상 승격 + 04 환류 후보. 토큰값·뷰포트 px는 본문·산출물 리터럴 재기재 금지(04 인용).

## Figma MCP (READ 전용 · write 금지)
읽기 전용 QA라 `use_figma`·`create_new_file` 등 write 전면 금지(수정은 디자이너). 호출 순서
`whoami→get_metadata→get_design_context→get_screenshot→get_variable_defs`·nodeId 필수
(`^\d+[:-]\d+$`). 미연결 시: `claude mcp add --transport http figma https://mcp.figma.com/mcp` 후
`/mcp` 인증(열람 권한 계정). (SKILL 본문은 mcp add 하드코딩하지 않음 — README 전용.)

## Playwright MCP (선택 · baseline 보조)
시각회귀 기준 스냅샷(baseline) 확보 보조 — **구현물 테스트 아님**(구현물 검수는 14). **11 캡처 세트
(`11-2/shots`) 1차 재사용**·부재 시에만 신규(뷰포트 04 breakpoint 파생). baseline = 14 회귀자산 후보 라벨
(13·14 미빌드→자동 인계 금지). 미연결 시: `claude mcp add playwright npx '@playwright/mcp@latest'`.
dry-run 생략.

## Notion MCP (선택 · 공유)
리포트 공유·반영 추적. 옵트인·게이트2 후·민감정보 더미(실고객 정보·내부 정책·식별 도메인·실 결제 금액).
미연결 시: `claude mcp add --transport http notion https://mcp.notion.com/mcp`. 미사용→마크다운 SSOT.

## HITL 경계 (사람 몫)
시각 품질(위계·여백·균형·심미성)은 디자이너 영역·스크린샷 평가 불신뢰 / 검출=후보(의도적 예외는 게이트2
재분류) / 동적 접근성 실조작은 실기기·사람 / 토큰값=실제값이어도 미바인딩 가능→인스펙터 재확인 / 약관·결제·
해지·자동갱신·법정고지 화면 `[사람 직접 검수]`. 시안 검수지 구현물 검수(14) 아님.
