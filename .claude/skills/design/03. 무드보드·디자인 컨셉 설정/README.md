# design-moodboard

레퍼런스 더미를 **아트 디렉션 하나로 수렴**시키는 디자인 시리즈 3단계 스킬. 톤앤매너 키워드 발산→수렴, 컨셉 비주얼 프롬프트·컬러 무드, FigJam 무드보드 합의, 디자인 컨셉 정의서(★04 입력) 확정. **핵심은 디자인이 아니라 합의** — 무드보드는 의사결정 도구. **멋 ≠ 맞음**(가치제안 연결 약하면 기각).

## 설치
`SKILL.md`를 `~/.claude/skills/design-moodboard/SKILL.md`로 복사.

## 일반경로 치환 포인트 (`<!-- 변경 포인트 -->`)
`SKILL.md` 상단 경로 정의 3줄을 본인 환경에 맞게. 입력은 기획 04·디자인 02 산출물에서 읽고, 출력은 디자인 03 폴더에 쓴다(기획·이전 단계에 쓰지 않음).

- `<기획입력>` = 기획 상위기획 폴더 (예: `planning-output/<주제>/04_상위기획`)
- `<디자인02>` = `design-reference-research-output/<주제>/02_레퍼런스리서치`
- `<출력루트>` = `design-moodboard-output/<주제>/03_무드보드`

## 입력 전제
- **필수**: 기획 04 원페이저·가치제안캔버스(수렴/기각 기준) + 디자인 02-3 트렌드요약 핸드오프 키워드(발산 재료). 04 원페이저·캔버스 둘 다 없으면 중단.
- **권장/선택**: 02-7 레퍼런스보드(썸네일), 02-8 매핑표.

## Figma (이 시리즈 첫 Figma 쓰기 · 옵트인)
FigJam 무드보드는 **WRITE 작업**이다. 처음 쓰는 사용자는 Figma MCP 연결이 필요하다(미연결 시): `claude mcp add --transport http figma https://mcp.figma.com/mcp` 후 `/mcp`로 인증. 스킬은 `whoami`로 인증을 확인하고, **게이트3에서 "회사 워크스페이스에 무드보드를 생성할지" 동의를 받은 뒤에만** 쓴다(`/figma-use` mandatory 절차 선행). 미동의·미인증·view-only면 **mermaid/텍스트 무드보드로 degrade**한다. (SKILL 본문은 mcp add를 하드코딩하지 않는다 — 이 안내는 README 전용.)

## 이미지 생성 (human-in-the-loop)
컨셉 비주얼은 AI가 **영문 프롬프트만** 만들고, 후보 이미지는 사람이 Figma Make/v0/Stitch에 넣어 뽑는다. 비주얼은 방향 탐색용 러프이므로 비교가 끝나면 버리고 정의서(언어)만 남긴다.

## 출력물
`03-1_시각컨셉발산` · `03-2_아트디렉션수렴`(키워드 맵 포함) · `03-3_컨셉비주얼·컬러무드`(hex 후보+`확정 아님` 라벨) · `03-4_디자인컨셉정의서`(★04 입력, 컬러는 온도·채도 방향만) · `_검증체크리스트`.

## 다음 소비자 계약
`03-4_디자인컨셉정의서`의 **톤앤매너 ~하다/~하지않다 쌍**과 **컬러 무드 방향(온도·채도)**이 04(디자인 시스템·컬러·타이포)의 직접 입력이 된다. 04에서 토큰·접근성·다크모드로 정밀화한다.
