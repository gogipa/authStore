# UI 디자인 (시안 작업) (Hi-Fi Mockup)

회색 박스였던 와이어프레임(05)에 04 디자인 시스템의 컬러·타이포·간격·컴포넌트를 입혀 **화면 단위
고충실도 UI 시안**을 Figma 프레임으로 만든다. design-moodboard(FigJam)·design-system(Variables)에
이은 **세 번째 Figma WRITE 스킬.** 단일 핵심원칙은 하나다: **04 토큰을 단 하나도 새로 만들지 않고
시안을 완성한다.** Step1(토큰 고정)과 Step6(자기검증)이 이 원칙의 입·출력 게이트다.

## 핵심 원칙 (어기면 08에서 정리 비용이 폭발한다)

- **04 토큰만 쓴다 — 새 색·새 간격은 만들지 않는다.** UI 시안 품질을 무너뜨리는 가장 흔한 원인은
  "비슷한 색을 새로 만드는 것". Stage 1에서 쓸 수 있는 토큰의 폐쇄 목록을 고정하고 "이 안에서만
  골라"라고 제약한다. **화면은 semantic alias만 쓴다**(CSS 변수 `--action-primary`를 쓰고
  `--color-primary-600`을 직접 쓰지 않는다 — 04 규칙 계승). ⚠️ **semantic alias가 커버 못 하는 자리**
  (에러배경·surface 단계·border·disabled 등 04에 alias가 없는 경우)는 **primitive 직접 사용을 허용하되
  04에 'alias 신설 필요' 환류**(기존 primitive를 쓰는 것이지 새 값 생성이 아니다 — '새 색 금지'와 구분).
- **토큰 값의 진실은 04 산출물이다(BMD 계승).** 색·타이포·간격 값은 `04/scripts/out/*.json`·
  `tokens.css`가 진실이고, **SKILL 본문·산출물에 구체 HEX/px를 재기재하지 않는다**(인용만 — 04 재실행
  시 드리프트 방지). `get_variable_defs`(Figma)는 **교차검증·드리프트 탐지 보조**이지 진실 1순위가
  아니다(SSOT→Variables 파생 방향).
- **1급 산출물은 degrade에 따라 달라진다(03/04 계승).** use_figma 동의·인증·非dry-run이면 **Figma
  프레임이 1급**, 미동의·미인증·dry-run이면 **frontend-design HTML 시안이 1급으로 승격**(중단 아님).
  토큰 적용 매핑(06-3)은 항상 1급.
- **AI 시안은 초안(80%)이지 최종이 아니다.** 위계·여백·정렬·브랜드 마감 20%는 사람. 그대로 핸드오프
  금지 — publish·핸드오프 확정은 07/08로 넘긴다.
- **카피는 실제 한국어로.** "Lorem ipsum"·영어 더미는 한국어 길이와 달라 레이아웃을 왜곡한다. 카피
  진실 우선순위 = **06 정책확정본(확정 *문구*가 있을 때만) > 12 메시지 > 05-2 dedup > 10 디스크립션**.
  ⚠️ 06이 '처리방안 A/B' 같은 정책 *결정*만 담고 UI 문구가 없으면 **10 화면설계서가 카피 1급일 수 있다**.
  미해소면 `[카피 확인필요]` placeholder(임의 한국어 생성 금지).
- **외부 생성 도구는 탐색 전용.** Figma Make/v0.dev/Google Stitch는 우리 토큰을 모른다 → 방향 탐색에만
  쓰고 직접 채택 금지, 확정안은 use_figma로 우리 컴포넌트 위에 다시 짓는다.
- **경쟁사 모방 경계.** "펫프렌즈처럼" 류 프롬프트는 베끼게 만든다. 레퍼런스는 02·03이 정한 우리
  컨셉으로 한정하고 차별화를 명시 지시.
- **컨텍스트 분할.** 한 번에 다 만들면 뒷부분 품질이 떨어진다 → 플로우(화면 3~5장) 단위로 끊고 화면마다
  토큰 적용을 확인한 뒤 다음으로.

### ID·화면 식별 (리터럴 단정 금지)
- **화면ID** = `S\d+`(무하이픈). **09-1 화면목록의 행에서만 확정한다**(05 계승). 다른 문서의 동일 꼴
  라벨을 화면ID로 줍지 않는다.
- **정책 케이스ID** = `(RF|SB|RX|DS|PI)-?\d+`(실제 쓰인 prefix 감지). `R\d+`는 06 케이스ID·07 요구ID
  양쪽이라 혼합 셀은 출처 문맥으로 분리, 모호하면 `[확인 필요]`.
- **프레임명 sanitize**: 09-1 화면명에서 **공백·`·`·괄호·하이픈 제거(어절 구분 없이 한글만 연결), join
  키는 항상 `S\d+`만, 상태 접미사는 `_loading`·`_empty`·`_error` 영문 고정**(예 S6 '첫 구독·간편결제'→
  `S6_첫구독간편결제`, S12 '해지 완료·환불 안내 (R10-결과)'→`S12_해지완료환불안내`). LLM 재명명 드리프트 방지.

### Stage 1 — 토큰 팔레트 고정 → `06-1`
- **토큰 소스 우선순위**: 04가 Figma Variables를 publish했고 라이브러리 URL이 있으면 `get_variable_defs`로
  읽되 **04 산출물 json/css와 교차검증**. **URL 부재(tokens.css에 `Figma 생략` 배너가 있는 주제의 기본값)면
  04 산출물 json/css/md가 진실로 자동 채택.** 두 소스 불일치 시 **04 SSOT 채택 + 'Figma 재publish 필요'
  확인필요 승격**.
- `06-1` = 허용 토큰 폐쇄 목록 + **semantic alias 우선 규칙**(화면은 `action/primary`, `primary-600`
  직접 금지). 구체 값은 04 json/css **인용**(재기재 금지).
