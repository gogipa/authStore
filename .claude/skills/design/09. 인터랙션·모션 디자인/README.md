# design-motion

06이 만든 정적 UI 시안에 **시간(트리거+duration+easing+속성)**을 입혀 개발 구현 기준이 되는 **모션 사양**을
만드는 디자인 시리즈 9단계 생성·명세 스킬. 모션 사양표 + frontend-design 타이밍 비교 프로토타입 + Lottie/Rive
분리 판단. 컴포넌트화(08)와 (장차 빌드될) 프로토타입 단계 사이.

## 설치
`SKILL.md`를 `~/.claude/skills/design-motion/SKILL.md`로 복사.

- `<디자인입력>` = `<디자인 산출물 루트>/<주제>` (06 시안·04 토큰·08 컴포넌트)

## 번호 혼동 주의 (기획 08 vs 디자인 08)
모션 원천은 **기획 시리즈 08(유저플로우)** — 화면 전환·상태 분기가 여기 있다. 동일 번호 **디자인 08(컴포넌트
토큰)**은 모션 **대상(컴포넌트·state)+환류 대상**이다. 둘 다 입력이며 역할이 다르므로 Stage 0에서 두 경로를 각각
명시 로드하고 가시화한다.

## 형제 경계
- **design-mockup**(06)=정적 시안 생성 / 09=그 시안에 시간 추가(재생성 아님).
- **프로토타입 단계**=플로우를 클릭으로 연결한 통합 프로토타입. ⚠️ 현재 설치된 `prototype-design`은 **기획 시리즈
  스킬**(입력 10_화면설계서·출력 기획11)이지 디자인 프로토타입이 아니다 → **09는 자기완결 1급**, "09→프로토타입 통합"
  계약은 디자인 프로토타입 스킬이 빌드될 때 확정한다.
- **frontend-design**=09가 Stage 2에서 내장 invoke + 스코프락(transform/opacity·grayscale·06 토큰 폐쇄목록·하이파이
  함정 가드)으로 호출.
- **design-componentize**(08)=정적 토큰/배리언트 / 09=모션 토큰 신설(04 부재)·08이 위임한 state 전이 모션 정의.

## 값은 초안·확정은 사람 (재생을 봐야 한다)
duration/easing 값은 "초안"이고, 디자이너가 09-2 HTML을 브라우저에서 재생해 고른다. AI는 모션 품질을 평가하지
않는다(스크린샷으로 모션 판정 불가). 자가점검 grep은 규약 위반(transform/opacity 외 속성·prefers-reduced-motion
블록 부재·placeholder 잔존)만 잡는다. spring/물리 모션은 사양표의 cubic-bezier 값이 기준이다.

## Figma (use_figma WRITE 스마트 애니메이트 · 선택 · /figma-use mandatory)
화면 전환을 Figma 스마트 애니메이트로 명세하는 건 옵트인이다(게이트3). use_figma WRITE 전 **`/figma-use`를 먼저
읽는다**(mandatory). 미연결 시: `claude mcp add --transport http figma https://mcp.figma.com/mcp` 후 `/mcp` 인증.
⚠️ Figma 전환은 핸드오프 레퍼런스지 구현과 1:1이 아니다(spring·물리는 cubic-bezier가 기준). 04 Variables 미publish
주제는 동의해도 베이스 프레임이 없어 HTML+사양표가 사실상 1급이다. (SKILL 본문은 mcp add를 하드코딩하지 않는다 —
README 전용.)

## Lottie / Rive (에셋 제작은 디자이너)
복잡 모션(캐릭터·일러스트·상태머신)은 Lottie(단방향 타임라인)/Rive(입력 반응 상태머신)로 분리한다. 단순
fade·slide·scale는 에셋화하지 않는다(CSS로 충분). Claude는 **분리 판단(4갈래표) + 통합 스니펫(lottie-web/@rive-app/
canvas·CDN placeholder·reduced-motion 분기)**만 만들고 `.json`/`.riv` 에셋 자체는 디자이너가 만든다(못 만든 걸
만들었다고 하지 않는다).

## 모션 토큰 (SSOT=04 · 환류 기재만)
04에 duration/easing 토큰이 없으면 09가 신설하되, SSOT는 04(Primitive)·08은 Component 모션 alias만이다. **04/08
파일은 직접 편집하지 않고 09-5에 환류안만 기재**하며, 사용자 확인 후 사람이 04/08을 재실행한다(07/08 선례). 모션은
테마 독립(다크 무관).

## 입력 전제
- **필수(모션 원천)**: `08_유저플로우/`(기획) **OR** `06_UI시안/06-2_시안초안/*.html`. 둘 다 없으면 중단.
- **강권장**(degrade 우선순위 06>04>디자인08): `06_UI시안`(정적 베이스) · `04_디자인시스템`(모션토큰 위치) ·
  `08_컴포넌트토큰`(state 축·환류).

## 출력물
`09-1_모션사양표`(상시 1급·3분류·관련 케이스ID 열) · `09-2_모션프로토타입/index.html`(타이밍 비교) ·
`09-3_자가점검`(grep) · `09-4_에셋통합가이드`(Lottie/Rive 4갈래) · `09-5_모션토큰`(선택·환류안) · `_검증체크리스트`.
