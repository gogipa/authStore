# design-reference-research

시각/UI 레퍼런스·UI 패턴·디자인 트렌드를 **수집·분류·구조화**해 **우리 화면 ↔ 패턴 매핑표**(★1급 산출물)를 만드는 디자인 시리즈 2단계 스킬. 시안 착수 전, 03(무드보드)·04(디자인 시스템)의 입력을 만든다. **취향·예쁨 판단은 안 함** — 사람이 큐레이션, AI가 구조화. **수집은 진척이 아니다, 매핑이 결과물.**

## 설치
`SKILL.md`를 `~/.claude/skills/design-reference-research/SKILL.md`로 복사.

## 일반경로 치환 포인트 (`<!-- 변경 포인트 -->`)
`SKILL.md` 상단 경로 정의 3줄을 본인 환경에 맞게. **입력은 기획·디자인 01 산출물에서 읽고, 출력은 디자인 02 폴더에 쓴다(기획·01에 쓰지 않음).**

- `<기획입력>` = 기획 산출물 주제 폴더 (예: `planning-output/<주제>`)
- `<디자인01>` = `design-requirements-output/<주제>/01_디자인요구사항` (1단계 산출물)
- `<출력루트>` = `design-reference-research-output/<주제>/02_레퍼런스리서치`

본 볼트 설치본은 `스터디/AI 스터디/자동화/{기획,디자인}/리서치/<주제-슬러그>/...`로 고정.

## 입력 전제

- **우리 화면 목록(필수)**: 09 와이어프레임 화면목록(`09-1`)이 1급 분모, 디자인 01-1 화면개요는 우선순위·상태변형 오버레이. 둘 다 없으면 중단.
- **경쟁사(선택·약한 가중치)**: market-research 산출물이 없으면 05-2 경쟁사가격정책·04-4 가치제안캔버스로 폴백하되, 검색 기반 가설·UI 강점 신호 아님을 ⚠️ 전파. 셋 다 없으면 degrade.
- **사람 큐레이션 캡처(human-in-the-loop, 입력 전제 1급)**: Mobbin·Dribbble은 AI가 크롤링하지 못한다. 사람이 화면을 캡처해 `<출력루트>/레퍼런스/`에 넣고 "어떤 앱의 어떤 화면, 왜 골랐는지" 설명 md를 동반해야 Stage 4·5가 동작한다. 미제공 칸은 `[캡처 대기]`로 표기되고, 매핑표가 전부 미해소면 완료 보고가 차단된다.

## degrade / 중단
- 중단: 화면목록 둘 다 부재 / 슬러그 0개.
- degrade: 경쟁사 폴백 부재(가중치 없이) / deep-research 실패(중단 아님 — 핵심은 매핑표) / Figma 미인증(Stage 4 스킵) / NotebookLM 미인증·레거시(Stage 5 2단 degrade).

## 도구 안내 (probe)
- **deep-research** = 번들 스킬. 비용·시간(토큰·5~15분) 경고 후 게이트1 동의.
- **Figma MCP**: 커뮤니티 원본은 권한 문제 → 본인 드래프트 복제링크(node-id 포함) 사용. 미인증 스킵.
- **NotebookLM**: 2서버 분기 probe. **`claude mcp add`를 SKILL 본문에 박지 않는다**(이미 연결 시 중복). 미인증 스킵.
- **Notion**(옵트인): 로컬 이미지 자동 업로드 안 됨 → 경로+출처만 미러. 민감정보 더미.
