# be-security-audit — 보안 점검 자동화 스킬

배포 직전 포밋 백엔드(07 인증·08 로직·09 API·11 외부연동)를 공격자 시점으로 전수 점검해, OWASP Top 10 점검표 → 입력검증·권한 누락 목록 → 의존성·시크릿 스캔 해석 → 고위험 경로 리뷰 → 심각도별 통합 리포트를 만드는 Claude Code 스킬입니다.

> BE 프로세스 15단계 "보안 점검"을 자동화합니다.
> 역할 분담: AI는 1차 스캔·체크리스트·CVE 분류, **침투 테스트·위협 모델링 최종 판단·릴리즈 승인은 보안 전문가·법무**. AI의 "문제 없음"은 합격증이 아니라 검토 대상 목록입니다.

## 무엇을 만들어 주나

`backend-output/<주제>/15_보안점검/`에 생성:

| 파일 | 내용 |
|---|---|
| `15-1_OWASP점검표.md` | OWASP Top 10(2021) 항목별 의심지점 + 근거(파일:라인) + 위험 이유 + 권고, "확인 필요" 태그 |
| `15-2_의존성시크릿스캔.md` | CVE 분류(심각도·사용경로·업그레이드 영향) + gitleaks 검출 분류(진짜/더미/오탐)·회수조치 |
| `15-3_고위험경로리뷰.md` | 결제(Payment)·개인정보(Member/Pet/Chat 등 도메인 실제 엔티티) 경로 정밀 리뷰 + 스킬↔체크리스트 교차 비교 |
| `15_보안점검리포트.md` | 심각도별 요약·항목수 + 배포 차단 목록 + "전문가 확인 필요" 섹션 |
| `_검증체크리스트.md` | 사람이 확인할 항목 |

## 준비물 (입력)

1. **필수** — 점검 대상 백엔드 소스(`src/main/java` 등) 또는 상위 산출물 `07_인증인가`·`09_API개발`·`11_외부연동`. 둘 다 없으면 위치를 묻고 중단.
2. **(연결·권장)** — 의존성 스캔 리포트(`build/reports/dependency-check-report.html` 또는 Snyk 출력)·시크릿 스캔 리포트(`gitleaks-report.json`). 없으면 실행 명령 안내 후 해석 단계만 degrade.
3. **(연결)** — `14_관측성`(보안 이벤트 로깅이 A09 점검·사후 탐지 기반).

## 사용법

점검 대상 소스(또는 07/09/11 산출물)와 스캐너 리포트를 준비한 뒤:

```
포밋 백엔드 배포 전 보안 점검해줘
```

1. **🔴 게이트** — AI 점검의 위상(1차 스캔·검토 대상 목록) 동의 + 배포 차단 기준 + 고위험 경로 범위 확정 (사람 개입, 필수)
2. OWASP Top 10 항목별 점검 → 입력검증·권한 누락 일괄 점검
3. `/security-review`·`/code-review` 교차 스캔 + 결제·개인정보 고위험 경로 정밀 리뷰
4. 의존성 CVE·gitleaks 결과 해석·분류
5. 심각도별 통합 리포트 + 검증 체크리스트

**Critical/High 항목을 닫고 사람이 확인하기 전에는 배포(16단계)로 넘어가지 않습니다.**

발동 키워드: `보안 점검`, `OWASP`, `취약점 스캔`, `의존성 스캔`, `시크릿 스캔`, `CVE 분류`, `security audit`, `vulnerability scan`, `gitleaks`

## 주의

- **AI의 "문제 없음"은 합격증이 아닙니다.** 학습 시점 이후 공격 기법·조합형 취약점·비즈니스 로직 결함은 놓칩니다. 침투 테스트·전문가 검토를 보완할 뿐 대체하지 않습니다.
- **환각으로 없는 취약점을 만들거나 있는 걸 놓칩니다.** 정상 QueryDSL을 인젝션으로, 진짜 구멍을 정상으로 오판할 수 있어 "확인 필요"는 반드시 사람이 원문 대조.
- **시크릿은 이력에서 지우면 끝이 아닙니다.** 커밋된 키는 노출된 것 — 폐기·재발급을 사람이 즉시 실행.
- **스캔만 돌리고 끝내지 마세요.** 각 항목을 분류·조치하고 Critical/High를 닫기 전엔 배포 금지.
- **의존성 업그레이드는 무검증 적용 금지** — Spring Boot 3.3 BOM 충돌 위험, 13단계 테스트 회귀 확인 후 반영.
- **스캐너 리포트 외부 전송 전 마스킹**(`--redact`)·민감 라인 필터링.
