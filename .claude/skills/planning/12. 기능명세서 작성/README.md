# 기능명세서 (Functional Spec) 스킬

화면설계서에 **동작 정의를 입히는** 단계. 10 화면설계서 + 06 정책 + 03 요구사항 + 08-2 예외표를
받아 **기능 단위 목록 · 입력값/유효성/예외처리 표 · 상태(state) 정의+Mermaid · API 초안**을 만든다.
개발자가 "이 경우엔 어떻게 되나요?"라고 묻기 전에 답이 문서에 있게 하는 게 목표.

## 1. 무엇을 만드나
- `12-1_기능목록.md` — 기능 목록(기능ID·화면·요구사항·MoSCoW(P0)·담당·진행상태) + 추정 기능 분리 + 커버리지
- `기능명세/<기능ID>_<기능명>.md` — 입력값표 / 예외처리표(6종) / 정책근거표(추정 ⚠️·민감 🔴)
- `12-2_상태정의.md` — 상태 목록 + Mermaid stateDiagram-v2 + dead-end/unreachable 머신검증 + 충돌 케이스 ≥5
- `12-3_API초안.md` — API 표(논의용 고지)
- `_검증체크리스트.md` / (옵트인) Notion DB

> **마크다운 = SSOT.** Notion DB화는 옵트인(외부발행). 도구 0개로도 명세서는 완성됩니다.

## 2. 설치
```bash
mkdir -p ~/.claude/skills/functional-spec-design
cp SKILL.md ~/.claude/skills/functional-spec-design/SKILL.md
```
설치 후 `기능명세서 작성해줘` / `상태 다이어그램 만들어줘`로 트리거된다.

## 3. 입력 준비 (입력 소스 3분기)
- **필수** — 10 화면설계서(`화면설계서/*.md` **+ `10-예외처리_점검.md`** — 둘 다, 한쪽만 읽으면 누락).
- **권장** — 06-3 매트릭스 + 06-운영정책 / 03(R-ID·MoSCoW) / 08-2 예외표 / 09-1 화면목록(커버리지 분모) / 11 검증결과 / 07-1.
- 10이 HTML/마크다운/Figma 어느 형태든 **1차 소스는 10 마크다운**. Figma면 read로 보강(write 금지).

## 4. 사람 개입 게이트 (2곳, 스킵 불가)
1. **기능 목록 + ID 체계 + 템플릿 + 추정 기능 채택/보류** — 기본은 03 스타일 감지·계승.
2. **⚠️ 추정 규칙 + 상태 충돌 + 민감 카테고리 전수 확정** — 상태 설계 뒤에 둔다. 해소 전 API/Notion 차단.

## 5. 변경 포인트
| 무엇 | 어디 | 바꾸는 법 |
|---|---|---|
| **Notion 스키마/select** | 변경포인트 1 / Stage 5 | 속성·상태값 교체. 미사용이면 Stage 5 스킵(SSOT 손실 0) |
| **ID 접두/패딩** | 변경포인트 2 / ID 체계 | 기본은 03 스타일 감지(F/FEAT). 원하는 규칙으로 수정 |
| **입출력 경로** | 변경포인트 3 / `## 입력`·`## 출력 위치` | `<루트>` 및 `functional-spec-design-output/<주제>`를 본인 폴더로 |
| **외부발행 경고** | 변경포인트 4 | Notion/Figma/Context7 외부 경계 — 민감정보 더미 치환 |
| **선행 산출물 부재** | 변경포인트 5 / degrade | 06/03/08-2/11/09-1 없으면 degrade(중단 아님) |

## 6. degrade / 중단 / 게이트 블로킹
- **중단** — 10 부재(입력물).
- **degrade** — 06 부재→정책근거·게이트2 전 항목 ⚠️ 잠금 / 11 부재→⚠️플로우검증 미반영 / 09-1 부재→커버리지 분모 경고 / Notion 미사용→마크다운 SSOT / mermaid-cli 없음→정적 체크리스트.
- **게이트 블로킹** — ⚠️/[확인 필요]/민감 카테고리 미해소.

## 7. 주의
- **AI 추정 유효성을 그대로 확정 금지** — 특히 개인정보·결제·보안(🔴)은 전부 사람.
- **다층 충돌은 확정 상태로 판정** — 디스크립션이 단언해도 06-3 ⚠️미정이면 ⚠️ 유지.
- **환각 기능/API** — 화면설계서·기능목록에 없는 것을 끼워 넣지 마라(역추적 검증).
- **상태 다이어그램** — dead-end/unreachable을 머신검증으로 잡는다(글로 쓰면 안 보인다).
- **Notion 전 마크다운 검토 완료** — .md가 원본, Notion이 공유본. DB 대량 수정은 번거롭다.
- 화면ID·구성요소 번호·기능ID는 **참조 키** — 함부로 바꾸지 마라.
