# 디자인 협업·리뷰 (Design Review) 스킬

디자이너 시안을 기획 문서와 **대조**하는 단계. "예쁜가"가 아니라 **"기획과 일치하는가"**를 검증한다.
시안(Figma 또는 HTML)을 10 화면설계서 + 12 기능명세 + 06 정책과 자동 대조해 **디자인 리뷰
리포트**(수정요청/질문/제안) + QA 체크리스트 + 용어집을 만든다. **생성이 아니라 대조 스킬.**

## 1. 무엇을 만드나
- `13-1_정합성체크.md` — 누락/추가/문구불일치 + 확인필요 분리
- `13-2_QA체크리스트.md` — 필요 상태화면(로딩/빈/에러/권한/검증) 프레임 존재 ✅/❌ + 디자인 요청 목록 + 커버리지
- `13-3_용어집.md` — 개념·기획서 용어·시안 용어·권장안 → 확정 후 14/15 재사용
- `13-4_디자인리뷰리포트.md` — 수정요청/질문/제안 + 심각도 + 근거 인용
- `_검증체크리스트.md` / (옵트인) Notion 공유 페이지

> **대조 결과는 후보 목록이지 판정이 아닙니다.** 의도적 디자인 변경은 "질문"으로 옮겨 전달하세요.
> **마크다운 = SSOT.** Notion은 옵트인 공유본.

## 2. 설치
```bash
mkdir -p ~/.claude/skills/design-review
cp SKILL.md ~/.claude/skills/design-review/SKILL.md
```
설치 후 `디자인 리뷰 해줘` / `시안이 기획서와 맞는지 봐줘`로 트리거된다.

## 3. 입력 준비
- **필수** — 시안(Figma 링크 또는 09/11 HTML) + 10 화면설계서(`화면설계서/*.md` **+ `10-예외처리_점검.md`**).
- **권장** — 12 기능명세(인라인 검증 UI·용어) / 06 정책(문구·정책 용어).
- 시안 소스: **디자이너 Figma 시안이면 Figma read가 1급**, HTML 파이프라인이면 09/11 HTML이 1급(택1).

## 4. 사람 개입 게이트 (2곳, 스킵 불가)
1. **리뷰 범위(프레임 4~6장) + 시안 소스 확정** — Figma면 리뷰 프레임 nodeId 확정.
2. **리포트 검토 + 수정요청/질문 재분류(의도적 변경) + 용어 결정** — 리포트 초안 뒤. 해소 전 Notion 차단.

## 5. 변경 포인트
| 무엇 | 어디 | 바꾸는 법 |
|---|---|---|
| **출력 루트** | 변경포인트 1 / `## 출력 위치` | `design-review-output/<주제>` → 원하는 폴더 |
| **기준 문서 경로 + ID** | 변경포인트 2 / `## 입력` | 10/12/06 폴더가 다르면 수정. ID는 감지·계승(리터럴 금지) |
| **시안 소스** | 변경포인트 3 | Figma 1급 / HTML 1급 (수신자 시안에 따라 택1) |
| **Notion** | 변경포인트 4 / Stage 5 | 옵트인. 미사용이면 스킵(마크다운 SSOT) |
| **get_variable_defs** | 변경포인트 5 | 보조·선택만. 토큰 미준수 지적은 월권 |
| **문구 검수 한계** | 변경포인트 6 | 약관/결제/법적 고지는 screenshot+사람 |

## 6. degrade / 중단 / 게이트 블로킹
- **중단** — 시안 부재 / 10 부재.
- **degrade** — Figma 미인증→HTML(또는 사람-개입) / 12 부재→상태커버리지 축소+⚠️ / 06 부재→권장안 빈도만 / Notion 미사용→마크다운 SSOT. **10만 있으면 13-1 정합성만으로 완성.**
- **게이트 블로킹** — 게이트2 Notion 차단 / [확인 필요] 미해소.

## 7. 주의
- **후보지 판정 아님** — 의도적 변경은 질문으로. 시각 품질·디자인 토큰은 기획자 영역 아님(월권 금지).
- **다층 충돌 양방향** — 기준이 미정이면 질문. 디스크립션이 단언해도 06-3 ⚠️미정이면 확정 베이스 금지.
- **약관/결제/법적 고지** — 자동 대조 금지, screenshot+사람.
- **리포트 전달이 관계를 좌우** — 하 항목 묶음, 잘된 점은 기획자가 직접. 리포트는 도구, 합의는 사람.
- **민감정보** — Notion/외부 공유 전 더미.
- 확정 용어집은 14(핸드오프)·15(QA) 기준 문서 — 함부로 바꾸지 마라.
