# 개선·고도화 기획 (Improvement Planning)

배포가 끝이 아니다. 17이 "무엇이 일어났는가"(지표)면 18은 "그래서 다음에 무엇을 만들까"를 정한다. VOC(고객의
소리)와 지표를 교차해 **개선 가설 백로그**를 만들고, 영향이 크고 불확실한 것은 **A/B 테스트**로 검증을 설계하며,
**스프린트 회고(KPT)·차기 로드맵**으로 다음 사이클에 인계한다. **이 단계의 끝은 새 사이클의 시작** — "신규 기능·
신규 시장" 항목은 `[1단계 리서치 회귀]`로 01(시장 리서치)에 되돌린다(기획은 직선이 아니라 루프).

**AI는 VOC 분류·가설 초안·RICE 초안·표본 계산 스크립트·회고 정리. 의사결정(우선순위 확정·인과 판단·실험 집행·
Effort 산정)은 사람.**

**2층 구조**: (A) **설계 산출물**(VOC 분류·가설 백로그·A/B 설계서·회고/로드맵) = 데이터/스크래퍼 불요·**항상
생성**. (B) **실수집·실험집행·외부동기화**(스크래핑·실험 플랫폼·Notion·NotebookLM) = 도구/데이터 의존·**옵트인 +
degrade**(템플릿/골격은 항상, 실행은 가용 시).

## 핵심 원칙

- **계승(재발명 금지)**: 가설 근거 풀 = **17 지표리포트**(NSM·AARRR·가드레일·미해결) + **04 KR** + **02
  페인포인트** + **15-2 명세누락** + **16-3 CS 정책미정**. **근거 없는 가설 금지**(모든 가설에 출처 ID 명시).
- **소스 dedup 선행(빈도 왜곡 차단)**: 상류 산출물은 서로 **흡수 관계**일 수 있다(예: CS 정책미정 풀이 QA
  명세누락의 상위집합). **dedup 없이 병렬 합산하면 동일 항목이 빈도표에서 2~3중 계상**되어 RICE Reach·우선순위를
  왜곡한다(아래 "VOC 빈도≠우선순위" 자기위반). **Stage1 분류 전에 단일 정규화 ID로 cross-ref → distinct 집합을
  python3 차집합으로 인쇄한 뒤에만** 빈도표·백로그에 투입. 흡수된 풀의 고유 기여분(예: 처리 채널 분류)만 별도 표기.
- **(family 18판) 가설은 "검증 대상"이지 단정 아님**: 형식 = "**[근거] 때문에 [변경]하면 [지표]가 [방향]
  변할 것이다**" = 인과 **가설**(17 캐논 계승: 상관≠인과). 백로그 어디서도 "이렇게 하면 오른다"로 단정 금지.
  - **가설↔근거 양방향 차집합 기계검증**: Stage2에서 python3로 **(가설 출처 ID 집합 − dedup distinct 근거 풀
    집합) = ∅(날조 근거 0)** AND **(근거 풀 − 한 번이라도 인용된 집합) = 누락 목록** 을 **둘 다 stdout 인쇄해야만
    ✓**. 출처 셀이 빈 가설은 `[근거 미상·확인 필요]` 강등. **산문 근거는 출처 칼럼에 등재되기 전까지 인정 안 됨.**
  - **RICE는 추천 초안**(확정 순위 위장 금지): Effort는 **AI 추정 근거 0** → **t셔츠 S/M/L 초안값 + 전 항목
    `[개발 확인 필요]`**, 백로그 상단에 **"순위 잠정(확정 아님)"** 헤더. "내림차순 확정 순위" 단정 금지. RICE 4요소
    (Reach/Impact/Confidence/Effort) **모두 출처·근거 라벨**, 데이터 미가용 요소는 `[추정·확인 필요]`. Confidence는
    근거 성숙도 기반 정성 등급(실측=상향, 미실측 가설=하향).
  - **인용은 원문에서만**(다듬기·창작 금지 = 환각). 출처 성격 2분기(아래).
  - **VOC 빈도 ≠ 전체 우선순위**: 앱스토어 리뷰는 극단 경험 편향 → **17 지표와 교차 강제**(18-2에 VOC↔17지표
    교차표, 어떤 지표 행과 대조했는지 1:1 기재).
- **(family 18판) 미해결 상태 전파**: 상류 항목 마커(⚠️/🔴/[확인 필요]/미해결/가설)를 가설 행에 **그대로 전파** +
  **Confidence 하향·`[선행 확정 필요]`**. 미정 항목(예: 위약금율 🔴)은 "**VOC 신호**"로만 쓰고 정량 [근거 수치]로
  단정 금지. **"17 존재 ≠ 정량 근거 확보"**(17 NSM·재구매 등은 보통 내부 DB 미실측 가설).
- **(family 18판) 인용 환각 방지 + 출처 2분기**: (a) **실수집 텍스트**(인터뷰/리뷰/CS 티켓/설문) = 원문 **행번호
  인용 + 감성·심각도 분류** 허용 — 단 **원문 발화(따옴표 verbatim)가 실재하는 레코드만**. verbatim 없는 합성·요약
  서술(기획팀 인사이트 리포트의 함의 문장 등)은 (b)로 강등(감성/심각도 N/A). (b) **내부 프록시**(15-2/16-3/04/17 = 기획팀 작성·미수집) = 감성/대표인용
  **N/A**, "내부 결함/추정 출처(파일·#n)"로만 표기 + 18-1·18-2에 **"프록시 = 사용자 발화 아님" 워터마크**. 인용
  키: 실수집 = 행/레코드 번호(편집 시 깨짐 주의), 프록시 = **안정 항목 ID**(15-2 #n·16-3 #n·17 미해결 항목·KR번호).
- **(family 18판) 표본미달 가드**(17 "N<임계 결론 격상 금지" 전역 적용): VOC "**기타 20% 초과→카테고리 재설계**"
  신호는 **총 분류 N ≥ `[[임계값:합의]]`(예 30~50)일 때만** 결론; 미달이면 빈도표 `[참고용·결론 제외]`로 강등하고
  재설계 신호 끔. **A/B 표본 미달 시 "그냥 배포·전후 비교" degrade** 셀에 **"교란 통제 불가·인과 단정 금지·관측
  변화만 기록"** 경고 의무 + 결과는 "신호"로만 + 다음 사이클 재검증 + **되돌리기 쉬운 작은 변경에 한정**.
- **A/B 표본 계산 = 스크립트(05 캐논)**: python3 **stdlib(math)**·z 상수 **정확값**(z(0.025)=1.959964, 검정력 80%
  z=0.841621)·**stdout이 진실**(암산·채팅추정·재반올림 금지). **첨부 스크립트는 보여준 stdout을 그대로 재현해야
  함** — print문·sanity 호출·dry-run 분기를 스크립트에 포함(함수 정의만 붙이고 stdout을 산문으로 옮기는 것 금지·
  복붙 실행=동일 stdout). 일트래픽·baseline·MDE는 **외부 파라미터 필수**(`[[일트래픽:합의]]`·`[[baseline:합의]]`),
  미입력 시 **"A/B 가부 미정([데이터 확인 필요])"** degrade. **AI 임의 추정 판정 금지.** `mode=absolute|relative`
  필수 인자·stdout 역표기("p1=10% → p2=12%(상대+20%)"). **주지표 측정가능성 선결**(17-1 "실측 가능" 지표만 주지표
  허용). **17 가드레일 자동 상속**(가드레일 악화 시 "배포 불가"). **주지표와 가드레일이 동일 지표면 금지** — 별도
  행동 지표로 분리하거나 가드레일에 상한 임계 명시(방향 자가상충 차단).
- **족보 정합(N-way)**: Stage0 주제명 정합을 **근거 풀 전 출처(17·04·05·02·15-2·16-3) 헤더 N-way 대조**로 확장,
  불일치 시 게이트1 사용자 정본 확정(임의 일반화·슬러그 임의 선택 금지)·패키지 "⚠️ 상류 주제명 상이" 블록.
- **VOC 전수 커버리지**: 프록시 모드는 근거 풀 ID **전건의 카테고리 귀속을 매핑 인쇄(미귀속=0)**. 실수집 CSV
  모드만 표본·기타비율 휴리스틱 적용(분기). **AI 분류는 표본 검증 필수**(카테고리별 10~20건 원문 대조).
- **외부 액션 옵트인**: 스크래핑실행·실험집행·Notion·NotebookLM = 게이트2 승인 후. PII/민감정보 더미체크.
  write-back은 사용자 확인 후 append·**작업 폴더 한정**.

### Stage 1 — VOC 분류·분석 → 18-1

- **출처 2분기**: 실수집 텍스트 = 카테고리·감성·심각도·**원문 행번호 인용** / 내부 프록시 = 카테고리·**안정 ID**·

- 카테고리(예: 버그/성능·UX 불편·기능 요청·결제/환불·콘텐츠·기타). **직전 분기 비교**(있을 때). **기타 비율**.

### Stage 2 — 개선 가설 백로그 → 18-2
- 가설 형식 = "**[근거 ID] 때문에 [변경]을 하면 [지표]가 [방향]으로 변할 것이다**". **각 가설 출처 ID 칼럼 필수.**
- **가설↔근거 양방향 차집합 python3 인쇄**: (가설 출처 − distinct 근거 풀)=∅(날조 0) AND (근거 풀 − 인용)=누락
  목록. 둘 다 인쇄해야 ✓. 매칭 실패 가설 = `[근거 미상·확인 필요]`.
- **미해결 전파**: 상류 ⚠️/🔴/미해결 마커를 가설 행에 전파·Confidence 하향·`[선행 확정 필요]`.
- **RICE 초안**: Reach(월 영향 사용자)·Impact(0.25~3)·Confidence(정성 등급·근거 성숙도)·Effort(**t셔츠 S/M/L +
  `[개발 확인 필요]`**). 4요소 출처/근거 라벨. **백로그 상단 "순위 잠정(확정 아님)" 헤더.** Effort 비수치(t셔츠)면
  **정렬 기준 명시**(정렬키=Confidence×Impact 정성 등) — **A/B 적합성(어느 것을 먼저 실험)은 우선순위와 분리**(selection ≠ priority).
- **VOC↔17지표 교차표**: 각 가설이 어떤 17 지표(단계+지표명·가드레일·미해결)와 대조됐는지 1:1.
- **상위 5 A/B 필요여부 판정**(가설 부족 시 전수 + 사유): 되돌리기 쉬운 작은 변경=그냥 배포 / 영향 크고 불확실=A/B.
  목표치이지 강제 아님(근거 없는 항목으로 개수 채우기 금지).

### Stage 3 — A/B 테스트 설계 → 18-3 (1순위 필수·2순위 옵션)

  소스는 `[측정 파이프라인 선행 필요]`)·**보조 지표**·**가드레일 지표(17 가드레일 자동 상속)**.
- **표본 계산 스크립트(python3.9 stdlib math)**: 일트래픽·baseline·MDE 외부 파라미터 + `mode=absolute|relative`.
  정규근사 2비율 공식, z 정확값. **stdout이 진실**·역표기·자가 sanity(p1=10%·MDE 2%p→3841 인쇄). 미입력 시 가부 미정.
  Evan Miller 교차검증 안내(웹·수동).
- **분기/제외 조건·조기 종료 금지 원칙**. 예상 실험 기간(일트래픽 합의 시).
- **표본미달 degrade**: "A/B 불가→그냥 배포·전후 비교" — **교란 통제 불가·인과 단정 금지·관측 변화만 기록** 경고,

## 도구 정확성
- **node v24+/npm** = google-play-scraper·app-store-scraper 설치 가능하나 **가상/미출시 서비스는 0건·무관**(설치

- **python3 3.9 stdlib**(math/csv/collections) = 표본 계산·VOC 빈도. **scipy/pandas 불요.** match문·PEP604
  `int|None` 금지(3.9 SyntaxError)·`typing.Optional/List` 사용. 골격 상단 `# python3.9+ stdlib only` 주석.
- **A/B 표본 공식**(2비율 정규근사): n = (z_{α/2}·√(2·p̄·(1−p̄)) + z_β·√(p1(1−p1)+p2(1−p2)))² / (p2−p1)².
  양측 α=0.05→z_{α/2}=1.959964, 검정력 80%→z_β=0.841621(단측). p1=10%·MDE 2%p→그룹당 **3841**(Evan Miller 일치).
- **Notion MCP**(no-op 옵트인) / **NotebookLM 2서버**(`notebooklm-mcp`·`notebooklm` — `get_health` 인증 게이트·
  비동기 인덱싱 5~30초) / **superpowers:brainstorming**(플러그인·가용 시 발산·부재 시 degrade) / **Evan Miller**
  (웹 JS·자동 불가·수동 교차).

## 주의
- **가설은 단정 아님** — "이렇게 하면 오른다"가 아니라 "변할 것이다(검증 대상)". 인과는 실험/사람이 판단.
- **RICE는 초안** — 특히 Effort는 AI 근거 0. 확정 순위처럼 공유 금지.
- **인용 환각** — AI가 리뷰 문장을 매끄럽게 다듬는다. 실수집은 원문 행번호로 한 번 더 확인.
- **목소리 큰 VOC 편향** — 빈도 높다고 전체 우선순위 아님. 지표와 반드시 교차.
- **모든 걸 A/B 하지 마라** — 트래픽 적으면 표본 안 모임. 작은 변경은 그냥 배포·전후 비교(단 인과 단정 금지).
- **샘플 사이즈 함정** — ① MDE 비현실적 ② 절대%p vs 상대% 혼동 ③ 조기 종료. 스크립트 stdout·외부 계산기 교차·
  데이터 담당자 리뷰.
- 가설·지표·이벤트명은 17 산출물과 **동일** 사용. 차기 사이클은 `-v2` 슬러그로 분리(덮어쓰기 금지).
