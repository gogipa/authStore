# 개선·고도화 기획 (Improvement Planning) 스킬

배포가 끝이 아니다. 17이 "무엇이 일어났는가"라면 18은 "그래서 다음에 무엇을 만들까"를 정한다. **VOC(고객의
소리)와 지표(17)를 교차해 개선 가설 백로그·A/B 설계·회고/로드맵을 만들고, 신규 항목은 1단계 리서치로 회귀**
(루프 마감). AI는 VOC 분류·가설/RICE 초안·표본 계산 스크립트·회고 정리, 의사결정(우선순위·인과·실험 집행)은 사람.

> **2층**: 설계(VOC 분류·가설 백로그·A/B 설계서·회고/로드맵)는 데이터 불요·**항상 생성** / 실수집·실험집행·외부동기화는 도구·데이터 의존·**옵트인+degrade**.

## 1. 무엇을 만드나
- `18-1_VOC분류·분석.md` — 소스 dedup(distinct 차집합 인쇄)·출처 2분기(실수집=감성/행번호 vs 내부 프록시=안정ID·"발화 아님" 워터마크)·빈도표(N가드)·전수 귀속(미귀속 0)
- `18-2_개선가설백로그.md` — 가설("[근거]→[변경]→[지표][방향]")·출처 ID 강제+양방향 차집합 ✓·미해결 전파·RICE 초안(t셔츠 Effort·**순위 잠정**)·VOC↔17지표 교차표
- `18-3_AB테스트설계.md` — 1순위 설계서(귀무/대립·주/보조/가드레일 자동상속·python3 표본 stdout·조기종료 금지)·표본미달 전후비교 degrade(인과 경고)
- `18-4_회고·로드맵.md`(KPT·액션 추적표·Now/Next/Later·`[1단계 리서치 회귀]`·다음 01 입력 카드) / `18-개선고도화패키지.md`(인덱스) / `_검증체크리스트.md` / (옵트인) Notion

> **가설은 "검증 대상"이지 단정 아님**(상관≠인과). **RICE는 추천 초안·순위 잠정**(Effort는 AI 근거 0→[개발 확인 필요]).
> **인용은 원문에서만**(다듬기·창작 금지). **VOC 빈도≠우선순위**(17 지표 교차 강제). **마크다운 = SSOT.**

## 2. 설치
```bash
mkdir -p ~/.claude/skills/improvement-planning
cp SKILL.md ~/.claude/skills/improvement-planning/SKILL.md
```
설치 후 `개선 가설 백로그 만들어줘` / `A/B 테스트 설계해줘` / `VOC 분석해줘` / `스프린트 회고 정리해줘`로 트리거.

(선택) 외부 연동 — 모두 옵트인·probe:
- 앱스토어 스크래핑 `npm i google-play-scraper app-store-scraper`(실서비스 식별자 있을 때만) / Notion MCP(백로그 DB)
- NotebookLM MCP(VOC 원문 적재·인증 전제) / superpowers:brainstorming(가설 발산) / Evan Miller 계산기(표본 수동 교차)
- **표본 계산은 python3 stdlib만**(scipy/pandas 불요).

## 3. 입력 준비 (계승 우선 — OR 게이트)
- **필수(둘 중 1 이상)** — ① 17 지표분석(NSM·AARRR·가드레일·미해결) **OR** ② 프록시 VOC(15-2 명세누락·16-3 CS 정책미정·02 사용자리서치·04 KR 중 1).
- **둘 다 없으면 중단.** 17 없으면 정성 VOC만으로 진행, 정량 목표는 `[데이터 확인 필요]` 강등.
- 실수집(앱스토어/CS/설문 CSV)이 없으면 **내부 산출물 프록시 모드**가 기본(가상/미출시 서비스는 실스크래핑 함정).

## 4. 사람 개입 게이트 (2곳, 스킵 불가)
1. **VOC 근거 소스 목록 + 분류 체계 + 소스 전략(프록시/실수집) + 정본 주제명(N-way 정합)** — 가설별 출처 추적은 여기 아님.
2. **가설별 출처 1:1 추적(차집합 ✓·날조 0·근거 미상 강등) + RICE 추천·순위 잠정 + A/B 대상/주지표 측정가능성/가드레일 + 회귀 라벨 + (옵트인) 스크래핑/실험집행/Notion** — 해소 전 외부액션 차단.

## 6. degrade / 중단 / 게이트 블로킹
- **중단** — 17·프록시 VOC 둘 다 부재.
- **degrade** — 산출물×입력상태 2차원(SKILL 매트릭스): 17만→정량 `[데이터 확인 필요]` / 프록시만→미해결 전파 / **A/B 표본 미달→전후 비교(교란 통제 불가·인과 단정 금지·관측 변화만)** / node 미설치→스크립트 골격 / Notion→마크다운 / NotebookLM 미인증→적재 차단 / brainstorming 부재→내장 발산.
- **게이트 블로킹** — 게이트2 차집합 미검증·출처 미상·🔴 미확정·옵트인 미승인 → 외부액션(스크래핑/실험/Notion) 차단.

## 7. 주의
- **가설은 단정 아님** — "변할 것이다(검증 대상)". 인과는 실험/사람이 판단.
- **RICE는 초안** — 특히 Effort는 AI 근거 0. 확정 순위처럼 공유 금지.
- **인용 환각** — AI가 리뷰 문장을 매끄럽게 다듬는다. 실수집은 원문 행번호로 재확인.
- **목소리 큰 VOC 편향** — 빈도 높다고 전체 우선순위 아님. 17 지표와 반드시 교차.
- **모든 걸 A/B 하지 마라** — 트래픽 적으면 표본 안 모임. 작은 변경은 그냥 배포·전후 비교(인과 단정 금지).
- **샘플 사이즈 함정** — ① MDE 비현실적 ② 절대%p vs 상대% 혼동 ③ 조기 종료. 스크립트 stdout·외부 계산기 교차·데이터 담당자 리뷰.
- **이 단계는 루프 시작점** — 신규 기능·시장은 01로 회귀(다음 01 입력 카드). 차기 사이클은 `-v2` 슬러그로 분리(덮어쓰기 금지).
