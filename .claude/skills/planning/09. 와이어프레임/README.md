# 와이어프레임 (Wireframe) 스킬

유저 플로우 + IA + 정책 → **low-fi 와이어프레임 세트**(화면 목록·화면별 프롬프트·실제 와이어프레임·세트 정리)를 자동 생성하는 Claude Code 스킬. 와이어 = 빨리 만들고 빨리 버리는 초안 — 기획자는 **그리는 사람이 아니라 고르고 고치는 사람**.

## 1. 무엇을 만드나
- `09-1_화면목록.md` — 화면명·진입경로·핵심요소·상태변형(empty/error/loading)·우선순위 + 누락 점검
- `09-2_화면프롬프트.md` — 화면별 와이어 프롬프트(grayscale low-fi, 06 정책 주입) — Stitch·Figma 공용
- `wireframes/*.html` — (HTML 경로) grayscale low-fi 와이어 / 또는 Figma 프레임 / 또는 프롬프트
- `09-3_와이어프레임세트.md` — 화면별 링크 + 배치 결정 + 점검 → 10 화면설계서 입력
- `_검증체크리스트.md`

> **09-1·09-2는 도구가 하나도 없어도 항상 완성**됩니다. 시각 산출물(Stage 3)은 부가물.

## 2. 설치
```bash
mkdir -p ~/.claude/skills/wireframe-design
cp SKILL.md ~/.claude/skills/wireframe-design/SKILL.md
```
설치 후 `와이어프레임 만들어줘` / `화면 목록 뽑아줘`로 트리거된다.

## 3. 입력 준비
- **필수** — 08 유저플로우(08-3 플로우차트 + 08-1 과업). 화면 = 플로우 노드.
- **권장** — 07 IA(정보 위계·화면명·empty-state) / 06 정책(화면 제약·엣지). 없으면 degrade(⚠️IA미반영 / ⚠️정책 미주입).
- **선택** — 03(요소 우선순위).

## 4. 사람 개입 게이트 (2곳)
1. **화면 목록·상태변형·우선순위 확정** — 08 플로우에서 추출 + 누락 점검(권한 요청·확인 모달).
2. **생성 경로·충실도 확정** — 보유 도구 probe 후 가능한 경로만 제시(use_figma / HTML / Stitch). grayscale low-fi.

## 5. 변경 포인트
| 무엇 | 어디 | 바꾸는 법 |
|---|---|---|
| **생성 경로 디폴트** | 게이트2 주석 | 회사가 Figma 표준이면 use_figma 우선 고정. 기본은 보유 도구 probe로 중립 |
| **HTML 저장 위치** | Stage 3 주석 | 기본 산출 폴더 내부(자기완결) → 다른 곳에 모으려면 수정 |
| **Figma 팀** | Stage 3 주석 | `whoami`로 edit 권한 팀 planKey 확인 후 생성(view-only 불가) |
| **입력 경로(08/07/06)** | `## 입력` 주석 | 각 산출물이 다른 폴더면 개별 수정 |
| **출력 경로** | `## 출력 위치` 주석 | 기본 `wireframe-design-output/` → 원하는 폴더 |

## 6. degrade 사다리 (도구가 없어도 핵심은 나온다)
- **08 없음** → 화면 흐름 원천이라 위치 묻고 **중단**.
- **생성 경로**: `use_figma → HTML → Stitch 프롬프트 붙여넣기 → (셋 다 불가) 09-2 프롬프트 + 마크다운 화면명세`.
- **07 없음** → 전 화면 `⚠️IA미반영`(정보 위계·empty-state 불가).
- **06 없음** → `⚠️정책 미주입`.

## 7. 주의
- **하이파이의 함정** — AI 시안은 와이어치고 너무 그럴듯하다. grayscale·low-fi 명시 + "오늘은 구조만 본다".
- **정책·엣지는 AI가 모른다** — 06 케이스ID로 화면에 주입하고 생성 후 대조. 차기/Won't 화면은 MVP 와이어에 넣지 마라.
- **화면 간 일관성** — 하나씩 생성하면 버튼·네비가 어긋난다. 같은 세션 + 마지막 점검.
- **Stitch는 외부 웹** — MCP 아님. `stitch-loop` 없으면 09-2 프롬프트를 직접 붙여넣기.
- **frontend-design은 와이어용 아님** — 하이파이 지향이라 09가 직접 grayscale HTML 생성.
- **디테일은 10단계** — 문구·필드·예외 처리는 화면설계서(10). 여기선 구조까지.
- **발견 화면은 환류** — 와이어 그리다 나온 새 화면은 07·08에 역반영.
