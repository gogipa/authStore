# high-level-planning — 상위기획 자동화 스킬

01~03 산출물(시장·사용자·요구사항)을 넣으면 **컨셉 발산 → 수렴(반대 논거 포함) → 원페이저 →
북극성 지표·OKR → 가치제안 캔버스 → 포지셔닝 맵**을 생성하는 Claude Code 스킬입니다.
사람은 **평가 기준 확정 1번 + 컨셉 확정 1번**, 두 번만 개입합니다.

> 기획 프로세스 4단계 "상위기획"을 자동화합니다.
> AI는 발산의 폭을 넓히고 수렴의 논거를 구조화할 뿐 — **컨셉 선택은 사람**.

## 무엇을 만들어 주나

`high-level-planning-output/<주제>/04_상위기획/`에 생성:

| 파일 | 내용 |
|---|---|
| `04-1_컨셉발산.md` | 컨셉 후보 8개+ (평가 없이 발산만) |
| `04-2_컨셉수렴.md` | 채점표 + 상위 2개 **반대 논거 3개씩** + 인용 근거 |
| `04-원페이저.md` | 1페이지 서비스 컨셉 문서 |
| `04-3_지표·OKR.md` | 북극성 지표 후보·추천 + 첫 분기 OKR |
| `04-4_가치제안캔버스.md` | Pains/Gains 매핑(인용 부착) + 포지셔닝 맵 |
| `_검증체크리스트.md` | 사람이 확인할 항목 |

## 준비물 (입력)

1. **02·03 산출물** — `high-level-planning-output/<주제>/`에 `02_사용자리서치/`(페르소나·인사이트), `03_요구사항정의/`(PRD·MoSCoW). 앞 단계 스킬(user-research, requirements-definition) 산출물을 두면 됩니다.
2. **(연결) 01 경쟁사 비교** — `01_시장경쟁사/03-경쟁사-비교.md`가 있으면 포지셔닝 맵 경쟁사 좌표 근거로 씁니다.
3. **대상 한 줄** — "누구의 어떤 문제".

## 사전 요구사항

| 항목 | 필수? | 없으면 |
|---|---|---|
| Claude Code | 필수 | — |
| Figma MCP | 선택 | 2×2 포지셔닝 맵은 mermaid로 작성(기본). Figma 공유 보드를 원하면 `use_figma`용으로 필요 |
| Notion MCP | 선택 | Stage 6 합의(원페이저 업로드) 스킵 |

Figma MCP 설치:

```bash
claude mcp add --transport http figma https://mcp.figma.com/mcp
```

추가 후 첫 사용 시 브라우저로 Figma 로그인(OAuth)을 한 번 거칩니다.

## 사용법

01~03 산출물을 준비한 뒤:

```
01~03 산출물로 상위기획 해줘. 대상은 <누구의 어떤 문제>.
```

1. 컨셉 8개+ **발산** (평가 없이)
2. **평가 기준 확정** → 당신이 OK (개입 1)
3. 채점 + 반대 논거 **수렴**
4. **컨셉 확정** → 당신이 최종 선택 (개입 2)
5. 원페이저 → 지표·OKR → 캔버스 → 포지셔닝 맵 자동

발동 키워드: `상위기획`, `서비스 컨셉`, `컨셉 발산`, `원페이저`, `북극성 지표`, `OKR`, `가치제안 캔버스`, `포지셔닝 맵`

## 주의

- **컨셉 선택을 AI에게 맡기지 마세요.** 채점표는 참고 자료입니다.
- **인용 조작 주의** — 캔버스·수렴 근거 인용은 02 원문과 대조하세요.
- **원페이저는 1장 엄수** — 두 장이 되면 Non-goals부터 압축.
- **발산을 건너뛰지 마세요** — 발산→반론→수렴이 핵심.
- **민감정보**는 Figma/Notion 외부 공유 전 제외.
