# 성과 측정·데이터 분석 (Metrics & Analytics) 스킬

배포 후 "의도대로 작동하는가"를 숫자로 증명한다. **04 상위기획·08 유저플로우에서 지표 정의서 + 분석
산출물을 파생**. AI는 설계 초안·이벤트 누락 점검·SQL/스크립트 생성, 의사결정(측정가능성·수치 해석·인과)은 사람.

> **2층**: 설계(지표 정의서·택소노미)는 데이터 불요·**항상 생성** / 분석 실행(SQL·CSV·리포트)은 도구·데이터 의존·**옵트인+degrade**.

```bash

cp SKILL.md ~/.claude/skills/metrics-analytics/SKILL.md
```
설치 후 `지표 정의서 만들어줘` / `이벤트 택소노미 설계해줘` / `주간 리포트 템플릿 만들어줘`로 트리거.

(선택) 분석 실행 도구 — 모두 옵트인·probe:
- Google Analytics MCP(GA4 읽기전용) / BigQuery `bq`·`gcloud`(GA4 export·인증 전제) / Amplitude(MCP 없음→CSV export)
- `python3 -m pip install --user pandas matplotlib`(CSV 분석) / Notion MCP(발행) / frontend-design(대시보드 HTML)

- **필수** — 04 상위기획(NSM/OKR — `NSM/북극성/지표·OKR` 키워드 서브파일) + 08 유저플로우(택소노미 원천).
- **권장** — 05 비즈니스모델(Revenue KPI·확정분만) / 03 / 06.
- NSM은 **04 추천 계승**(재발명 금지). 04 NSM 미검출 시 게이트1에서 직접 입력(임의 재설계 금지).

## 4. 사람 개입 게이트 (2곳, 스킵 불가)
1. **NSM 후보 계승(04 추천)+미검증 ⚠️ 보존 + 데이터 스택 + 네이밍 컨벤션** — 측정가능성 확정·5단계 내용은 여기 아님.
2. **지표↔이벤트 1:1 + NSM 측정가능성·왜곡위험 확정 + 택소노미 분석가/개발자 리뷰 + 🔴 PII + (옵트인) 분석 실행/Notion/리포트 발송** — 해소 전 차단.

- **중단** — 04·08 둘 다 부재.
- **degrade** — 산출물×스택 2차원(SKILL 매트릭스: GA4·Amplitude·자체DB·없음) / 05 미확정→Revenue 가설 / bq 미인증→템플릿만 / pandas 미설치→설치 시도 후 중단(암산 금지) / Notion→마크다운 / frontend-design→명세만.
- **게이트 블로킹** — 게이트2 매핑 미검증·🔴 PII 미확인 → 분석 실행/Notion/발송 차단.

## 7. 주의
- **AI SQL은 그럴듯하게 틀린다** — 없는 컬럼·조인·UNNEST 오류. 검증 쿼리·dry-run 필수.
- **수치 해석은 사람** — 상관을 인과로 단정 금지. 표본 수 병기·작은 표본 결론 제외.
- **🔴 PII** — 추출 비식별(user_id 해시)만. 이메일·이름 원본 분석 금지.
- **택소노미는 배포 후 바꾸기 어렵다** — 이벤트명 변경=과거 데이터 단절. 분석가/개발자 리뷰 + 15 QA 발화 검증 권고.
- **자동 리포트 초안 발송 금지** — 헤드리스 결과는 사람 검토.
- NSM·지표명·이벤트명을 04·08·15와 **동일** 사용. 04 NSM·OKR과 추적 유지.
