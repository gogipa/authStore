# 성과 측정·데이터 분석 (Metrics & Analytics)

배포 후 "의도대로 작동하는가"를 숫자로 증명하는 단계. 산출물 = ① **지표 정의서**(북극성 지표 NSM +
AARRR 퍼널 + 이벤트 택소노미) ② **분석 리포트**(SQL·CSV·주간 리포트·대시보드 기획). **AI는 설계 초안·
이벤트 누락 점검·SQL/스크립트 생성·포맷팅, 의사결정(지표 측정가능성·수치 해석·인과 판단)은 사람.**

**2층 구조**: (A) **설계 산출물**(지표 정의서·택소노미) = 데이터 불요·**항상 생성**. (B) **분석 실행**
(SQL·CSV·리포트) = 데이터·도구 의존·**옵트인 + degrade**(템플릿/스크립트는 항상, 실행은 가용 시).

## 핵심 원칙

- **계승(재발명 금지)**: **04 북극성 지표·OKR·허영 지표 제외를 계승** — 단 **04 NSM은 보통 "추천"이라
  측정가능성·왜곡위험 검증이 17로 이관됨**. 그 **미검증 플래그(⚠️)를 함께 계승**해 게이트2에서 사람
  확정(임의 확정·재설계 금지). 05 수익 KPI는 Revenue 단계 출처(확정분만), 08 플로우는 택소노미 원천.
- **(family 17판) 데이터 해석은 "관측 사실(수치)"만 단정**. 원인·인과·전망은 단정 금지 → **가설(사람
  검증)로 분리**, 근거 수치 병기. **reverse-trap 2범주**(층위 분리):
  - **생성층 정확성(SQL/쿼리)**: AI SQL은 **실제 스키마에 1:1 근거** — 없는 컬럼·잘못된 조인·GA4
    export `event_params` UNNEST 오류 금지(환각). **검증 쿼리(알려진 수치 대조)+dry-run 필수**.
  - **해석층 절제(결과)**: ① **상관을 인과로 단정 금지**(전환율 하락은 사실, 원인은 가설). ② **작은
    표본(N<임계) 비교를 결론으로 격상 금지**(표본 수 병기·N<임계 행은 [참고용·결론 제외]).
- **추적성 1:1**: **지표 정의서 "측정 이벤트" ↔ 이벤트 택소노미 1:1 매핑**(기계검증 — 둘 다 17 생성=
  안정 키). **양방향**(지표→이벤트 누락 0 AND 이벤트→소비 지표 없는 고아 이벤트 0). 단 **클라이언트
  이벤트 소스 지표에만** 적용(서버/PG/DB 소스는 제외, 아래 측정 소스 분리).
- **측정 소스 분리**: 측정 이벤트 칸에 **소스 축**{클라이언트 이벤트(GA4/Amplitude) / 서버·PG·Stripe /
  내부 DB·로깅} 명시. **GA4 export(events_*)에는 구독상태·결제정산·재구매회차 같은 트랜잭션이 없다** —
  그런 지표(예: NSM이 구독 유지·재구매 회차 같은 트랜잭션 상태면)는 **내부 DB 소스**로, GA4 SQL/택소노미 1:1 강제 대상 아님.
- **이벤트 택소노미 규격**: GA4+Amplitude 겸용, snake_case "목적어_동사". GA4 사용 시 제약(아래 도구
  정확성). **user property vs event property 구분**.
- **택소노미는 배포 후 변경 어려움**(이벤트명 변경=과거 데이터 단절): **분석가/개발자 리뷰 게이트** +
  **17이 자체 QA 발화 검증 체크리스트 생성**(이벤트×트리거×기대 발화·필수 속성). 15 QA 수행 시 이
  체크리스트를 TC로 편입하도록 **forward 권고**(15에 항목이 없을 수 있음 — 17 자체로 자족).
- **🔴 PII**: CSV/SQL 추출은 **비식별(user_id 해시 등) 컬럼만**. 이메일·이름 등 PII 원본 분석 금지.
- **허영 지표 경계**: vanity metric 위험 항목 표시(04 제외 리스트 계승 — 누적 가입자·다운로드·PV류).
- **분석 안전**: BigQuery **dry-run(스캔 비용)·검증 쿼리** 필수. **자동 리포트 초안 그대로 발송 금지**
  (사람 검토). 표본 임계 N은 사용자 외부 파라미터 `[[임계값:합의]]`(스킬 임의 단정 금지).

### Stage 1 — 지표 정의서 → 17-1
- **NSM = 04 추천 계승**(재발명 금지) + 미검증 ⚠️(측정가능성·해지 마찰 다크패턴류 왜곡위험 보존). NSM이
  속한 AARRR 단계 라벨(보통 Retention).
- **AARRR 5단계 전수**(Acquisition/Activation/Retention/Revenue/Referral) 각 선행지표 2~3개. **04 KR→단계
  1:1 귀속**(예: 획득=신규 KR / 유지=재구매 KR·NSM / 추천=추천 KR / 수익=05 확정 KPI).
- **5열 표**[지표명|정의(분자/분모)|측정 이벤트(+소스: 클라이언트/서버·PG/내부 DB)|목표값(**가설**)|확인 주기].
- **허영 지표** 위험 항목 표시(04 제외 계승). **측정가능성 2단**: 데이터 가용 시 실측 / 부재 시 스택 기준
  가설(⚠️ 실측 미확인 — 17-3 실행 후 재확정).
- **NSM 가드레일 지표(왜곡 견제)**: NSM 왜곡위험이 식별되면 **견제용 가드레일 지표를 5열 표에 정식 행으로
  등재**(정의 분자/분모·측정 이벤트+소스 포함). **산문 한 줄 언급은 소비처로 인정 안 됨**(아래 1:1 매핑에서
  고아 이벤트를 못 막음 — 가드레일도 행으로 등재해야 cancel류 이벤트가 소비됨).
- **선행지표 2~3개**가 원칙이나 **원천(08 등)이 미작성인 단계는 1개+⚠️ 허용**(개수 면제 — 단 사유를 단계
  헤더/비고에 명시·08 작성 시 보강).

### Stage 2 — 이벤트 택소노미 → 17-2
- **08 노드 3분기 매핑**: (a) 사용자 인터랙션 이벤트 → 08 **시나리오 단계·AC추적표**를 1차 원천 휴리스틱

  04 NSM/KR 근거, **"08 노드 아님"** 라벨. (c) 08 미작성 플로우 → **⚠️(KR 근거·08 미작성)** 추적.
- snake_case "목적어_동사". GA4 제약(도구 정확성 참조). **user property vs event property 구분**.
- **08 정책미정 노드 파생 이벤트**(`[정책미정→06 환류]`·`[법정기준 placeholder]`)는 **트리거 조건 단정
  금지 → `[트리거 정책미정]` 표기·06/15 환류**(reverse-trap).
- **자체 QA 발화 체크리스트**(이벤트명×트리거 노드×기대 발화 조건·필수 속성) — 15 QA forward 권고.
- **지표↔이벤트 1:1 매핑 검증**(양방향·고아 이벤트 0·클라이언트 이벤트 소스 한정). **python3가 "클라이언트
  이벤트 집합 − 지표 소비(5열 표 행) 집합" 차집합(=고아 목록)을 실제 인쇄** — 차집합이 비어야만 "고아 0".
  **산문 언급 지표는 5열 표 행으로 등재되기 전까지 소비처로 인정 안 됨**(✓ 단정 전 차집합 출력 강제).

### Stage 3 — 분석 쿼리·스크립트·리포트 템플릿 → 17-3
- **SQL 골격 3분기**(데이터 스택): (a) GA4 export BigQuery(`event_params` UNNEST·`_TABLE_SUFFIX` 날짜
  가드·dry-run) (b) Amplitude(MCP 없음 → CSV export 입력) (c) 자체 DB(컬럼 placeholder). **검증 쿼리·
  dry-run은 권장 아닌 강제 게이트**. GA4 표준 컬럼 주석으로 환각 컬럼 차단.
- **CSV 분석 스크립트**(pandas): 의존성 체크 → 미설치면 `pip install --user pandas matplotlib` 시도 →
  **실패 시 수치 분석 중단**(암산·채팅 추정 금지). **스크립트 stdout/png가 진실의 기준**(재계산 금지).
- **주간 리포트 템플릿**: 요약 3줄 / 지표 테이블 / 특이사항 / 확인 필요. **해석 문장은 관측 사실만·인과

## 도구 정확성
- **Google Analytics MCP**(GA4 읽기전용) = ToolSearch 존재로 가용 판별(없으면 미연결). 미연결→bq/CSV 경로.

  **SQL은 템플릿+dry-run 지시문만**(자동 실행 금지). 인증·데이터셋(옵트인) 시 dry-run 후 실행.

  회피. **수치는 ⚠️ 제출 직전 콘솔·360 여부로 재확인**(단정 회피).

## 주의
- **AI SQL은 그럴듯하게 틀린다** — 없는 컬럼·조인·UNNEST 오류. 검증 쿼리·dry-run으로 신뢰 확보.
- **수치 해석은 사람** — 상관을 인과로 단정 금지. 리포트 "특이사항"이 오독 위험 1순위.
- **표본 수 함정** — 잘게 쪼갠 작은 표본 비교는 착시. 표본 수 병기·N<임계 결론 제외.
- **🔴 PII** — 추출 단계 비식별 컬럼만. 이메일·이름 원본 분석 금지.
- **택소노미는 배포 후 바꾸기 어렵다** — 이벤트명 변경=과거 데이터 단절. 분석가/개발자 리뷰·15 QA 발화 검증.
- **자동 리포트 초안 그대로 발송 금지** — 헤드리스 결과는 사람 검토 후 공유.
- NSM·지표명·이벤트명은 정의서·택소노미·SQL·리포트에서 **동일** 사용.
