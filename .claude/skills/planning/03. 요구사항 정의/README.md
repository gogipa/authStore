# requirements-definition — 요구사항 정의 자동화 스킬

원천자료(회의록·슬랙·인터뷰)를 넣으면 요구사항 추출 → 유저스토리 → MoSCoW 우선순위 →
PRD 초안을 생성하는 Claude Code 스킬입니다. 사람은 **MoSCoW 평가 기준 확정 1번**만 개입합니다.

> 기획 프로세스 3단계 "요구사항 정의"를 자동화합니다.
> 역할 분담: AI는 빠짐없이 추출, **스코프 확정은 사람**.

## 무엇을 만들어 주나

`requirements-output/<주제>/03_요구사항정의/`에 생성:

| 파일 | 내용 |
|---|---|
| `03-1_요구사항추출.md` | 출처 달린 요구사항 표 (명시/암묵, 기능/비기능) |
| `03-2_유저스토리.md` | As a/I want/So that + 인수조건 |
| `03-3_moscow.md` | MoSCoW 분류 + 근거 |
| `03-PRD초안.md` | PRD 초안 |
| `_검증체크리스트.md` | 사람이 확인할 항목 |

## 준비물 (입력)

1. **원천자료** — `requirements-output/<주제>/원천자료/`에 회의록·슬랙·인터뷰 md.
   슬랙은 링크가 아니라 **내용을 복사**해 md로 저장.
2. **(연결) 02 페르소나** — `02_사용자리서치/03_페르소나.md`가 있으면 유저스토리에 매핑. 없으면 미매핑 처리.

## 사전 요구사항

| 항목 | 필수? | 없으면 |
|---|---|---|
| Claude Code | 필수 | — |
| Notion MCP | 선택 | Stage 4(DB) 스킵, PRD는 정상 |

## 설치

```bash
mkdir -p ~/.claude/skills/requirements-definition
cp SKILL.md ~/.claude/skills/requirements-definition/SKILL.md
```

## 사용법

원천자료를 준비한 뒤:

```
원천자료 읽고 요구사항 정의해줘
```

1. 추출 → 유저스토리 자동 생성
2. **MoSCoW 평가 기준 확정** → 당신이 OK (유일한 개입)
3. MoSCoW 분류 → (Notion DB) → PRD 초안 자동

발동 키워드: `요구사항 정의`, `요구사항 추출`, `유저스토리`, `PRD`, `MoSCoW`

## 🔧 변경해서 쓰는 법

| 변경 포인트 | SKILL.md 위치 | 어떻게 |
|---|---|---|
| 출력 경로 | `## 출력 위치` | `requirements-output/`를 원하는 경로로 |
| MoSCoW 기본 기준 | `### 🚦 게이트` | 3개 기준을 사업에 맞게 |
| Notion 제거 | `### Stage 4` | MCP 안 쓰면 단락 삭제 |
| 트리거 키워드 | frontmatter `description` | 자기 표현으로 |

## 주의

- **AI는 요구사항을 지어내기도 합니다.** "확인 필요" 태그·어색한 인용은 원문 대조.
- **MoSCoW 초안은 초안.** 이해관계자 리뷰 후에만 확정.
- 이해관계자 충돌은 AI가 해결 못 합니다 — 식별만.
- 슬랙 등 **민감정보**는 Notion 전송 전 제외.
