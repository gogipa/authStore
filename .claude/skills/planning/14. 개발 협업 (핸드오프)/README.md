# 개발 협업 (핸드오프) (Dev Handoff) 스킬

기획서·디자인을 개발팀에 "던지는" 게 아니라 **개발자가 추가 질문 없이 구현을 시작할 수 있는
상태**를 만든다. 12 기능명세 + 13 용어집 + 06 정책 + 10 화면설계서를 받아 **핸드오프 패키지**를 생성.

## 1. 무엇을 만드나
- `14-1_엣지케이스QA.md` — 개발자 관점 질문(답있음/기획결정필요 + 담당자·기한). 12 미정 계승
- `14-2_티켓.md` — FE/BE/공통 작업 분해(우선순위 12 계승·AC·빈/에러/로딩 화면 별도)
- `14-3_API명세초안.yaml` — OpenAPI 3.1(12-3 구조 변환·에러코드+사용자 문구·"백엔드 검토 후 확정")
- `14-4_용어집.md` — 한국어·영문/코드명·혼동주의(12 자체추출+13-3 보강)
- `14-핸드오프-패키지.md`(인덱스) / `_검증체크리스트.md` / (옵트인) Notion·Jira

> **AI는 질문 생성·분해·포맷팅, 판단(정책·우선순위)은 기획자.** **마크다운 = SSOT.**

## 2. 설치
```bash
mkdir -p ~/.claude/skills/dev-handoff
cp SKILL.md ~/.claude/skills/dev-handoff/SKILL.md
```
설치 후 `핸드오프 패키지 만들어줘` / `개발자 넘길 준비해줘`로 트리거된다.

## 3. 입력 준비 (계승 우선 — 재발명 금지)
- **필수** — 12 기능명세(원천: 기능목록·예외6종·12-2 상태정의·12-3 API초안).
- **권장** — 13-3 용어집(미확정 도착 가능) / 06 정책(🔴·기획 결정) / 10 화면설계서(+10-예외처리: 상태화면 티켓) / 03(우선순위).
- 12-3 API·13-3 용어·12 미정은 **계승**(재생성 금지). 13-3 미확정이면 14-4는 12 자체추출.

## 4. 사람 개입 게이트 (2곳, 스킵 불가)
1. **티켓 분해단위 + 우선순위 체계 확정** — 팀 P체계·1티켓 작업량(기획결정 답변은 여기 아님).
2. **기획결정 답변 + 티켓 승인 + API 검토 + 🔴 전수확정 + 구성요소 확정** — 해소 전 Notion/Jira 쓰기 차단.

## 5. 변경 포인트
| 무엇 | 어디 | 바꾸는 법 |
|---|---|---|
| **티켓 외부발행** | 변경포인트 1 / Stage 5 | Jira=Atlassian MCP(probe) / Notion=Notion MCP / 둘 다 없음=마크다운 |
| **계승 출처** | 변경포인트 2 / `## 입력` | 12/13/06/10 경로를 본인 폴더로 |
| **출력 루트** | 변경포인트 3 | `dev-handoff-output/<주제>` → 원하는 폴더 |
| **OpenAPI 버전** | 변경포인트 4 / Stage 3 | 기본 3.1. 팀이 3.0이면 nullable 등 교체 |
| **우선순위 필드** | ID·우선순위 절 | 12 P0~P2 1:1 계승. 팀 체계 다르면 게이트1 변환표 |

## 6. degrade / 중단 / 게이트 블로킹
- **중단** — 12 부재(원천).
- **degrade** — 13-3 미확정→14-4 자체추출+⚠️ / 06 부재→정책근거 ⚠️·🔴 보류 / 10 부재→상태화면 티켓 강제 해제 / 12-3 부재→엔드포인트 추정 또는 14-3 생략 / Notion·Jira 둘다 부재→마크다운 SSOT / pyyaml 부재→정적 체크리스트.
- **게이트 블로킹** — 게이트2 Notion/Jira 차단 / 기획결정·🔴 미해소.

## 7. 주의
- **AI 추천 정책 그대로 확정 금지** — 환불 기한·동시성은 06/법무 아는 사람이.
- **API 초안 = 논의용·백엔드 검토 필수** — 인증·멱등성·페이지네이션은 팀 표준(임의 확정 금지).
- **Notion/Jira 일괄쓰기 승인 게이트 필수** — 잘못 분해된 티켓 삭제가 생성보다 오래 걸린다.
- **Figma write 금지** — Code Connect는 FE/디자인시스템 인프라(기획자는 컴포넌트 출처 표기만).
- **민감정보** — Notion/Jira 전 결제 금액·실 엔드포인트·키 더미 치환.
- 상태명·기능ID는 명세·티켓·API에서 **동일** 사용. 13 용어집·14 용어집은 15(QA)에서도 재사용.
