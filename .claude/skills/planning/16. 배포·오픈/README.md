# 배포·오픈 (Launch Package) 스킬

QA 통과 제품을 출시하며 흩어진 비개발 업무(법무·CS·마케팅·운영)를 총괄한다. **12 기능명세·06 정책에서
런칭 패키지 4종을 4관점으로 파생**. AI는 초안·누락 방지·포맷팅, 의사결정(완료 확인·롤백 합의·법무 검토)은 사람.

## 1. 무엇을 만드나
- `16-1_출시체크리스트.md` — 4관점(법무/CS/마케팅/운영) [ ]+담당+기한(D-7/D-3/D-1/D-Day). 운영 시드·법무 검토의뢰·🔴
- `16-2_릴리즈노트·공지·스토어문구.md` — 사내 릴리즈노트·사용자 공지(300자)·스토어(App 프로모션텍스트 170/Play 변경사항 500, 각 2안+글자수)
- `16-3_CS_FAQ·매크로.md` — FAQ(12 범위×06 조항근거)·매크로(장애 필수)·**정책 미정 분리**(14-1/15-2 dedup)
- `16-4_롤백기준.md` — 심각도 3단계 결정트리·`[[임계값:합의]]`·"개발·인프라 합의" 체크리스트
- `16-런칭패키지.md`(인덱스+표기 범례) / `_검증체크리스트.md` / (옵트인) Notion

> **파생은 변환이지 창작이 아니다.** 모든 문구는 12 명세·06 정책에 1:1 근거. **출시 범위 = 12 기능 집합**
> (06엔 있으나 12 밖 정책은 공지/FAQ에 쓰지 말 것 — "없는 기능 공지" 환각). **확정분만 단정, 미정은 분리.** **마크다운 = SSOT.**

## 2. 설치
```bash
mkdir -p ~/.claude/skills/launch-package
cp SKILL.md ~/.claude/skills/launch-package/SKILL.md
```
설치 후 `런칭 패키지 만들어줘` / `출시 체크리스트 뽑아줘` / `릴리즈 노트 써줘`로 트리거된다.

(선택) 외부 보강 — 모두 옵트인:
- Notion MCP: 체크리스트 DB·페이지 발행 — `claude mcp add --transport http notion https://mcp.notion.com/mcp`
- NotebookLM MCP: FAQ 정책 grounding(조항 위치 찾기 보조)
- deep-research(번들 스킬): 스토어 심사 가이드라인 최신 확인 — `/deep-research`

## 3. 입력 준비 (파생 우선 — 재발명 금지)
- **필수** — 12 기능명세(릴리즈노트·스토어 파생·출시 범위) + 06 정책(FAQ·매크로 근거).
- **권장** — 15-2 명세누락·14-1 엣지케이스QA(정책 미정 dedup) / 03(범위) / 05(가격 교차).
- **출시 메타**(버전/출시일/가격) — 사용자 입력(게이트1), 미입력 시 `{{플레이스홀더}}`.

## 4. 사람 개입 게이트 (2곳, 스킵 불가)
1. **출시 메타 SSOT + 출시 범위(=12 기능) + 채널 글자수 확정** — 4관점 항목·D-day 구체는 여기 아님.
2. **생성물 검수(환각축+확정축) + 정책 미정 답변 + 🔴 법무 검토 의뢰 + 체크리스트 완료 확인 + 롤백 합의 + (옵트인) Notion/deep-research** — 해소 전 Notion 발행 차단.

## 5. 변경 포인트
| 무엇 | 어디 | 바꾸는 법 |
|---|---|---|
| **외부발행·보강** | 변경포인트 1 / Stage 5 | Notion·NotebookLM(MCP no-op probe)·deep-research(번들) 옵트인 / 없음=마크다운 |
| **계승 출처** | 변경포인트 2 / `## 입력` | 12/06/15-2/14-1/05 경로를 본인 폴더로 |
| **출력 루트** | 변경포인트 3 | `launch-package-output/<주제>` → 원하는 폴더 |
| **출시 메타** | 변경포인트 4 / 게이트1 | 버전/출시일/가격 사용자 입력, 미입력 시 placeholder |
| **스토어 글자수** | 변경포인트 5 / Stage 2 | App 170·Play 500은 예시 — 팀 정책 교체 + 제출 직전 콘솔 재확인 |

## 6. degrade / 중단 / 게이트 블로킹
- **중단** — 12·06 둘 다 부재.
- **degrade** — 산출물×입력 매트릭스(SKILL 참조: 12만→릴리즈/스토어 골격·FAQ 약화 / 06만→FAQ·법무 위주·스토어 불가) / 14-1·15-2 부재→06 마커 직접 분리 / 메타 미입력→placeholder / Notion→마크다운 / NotebookLM→in-context / deep-research 옵트아웃→정적+콘솔.
- **게이트 블로킹** — 게이트2 정책미정 미답·🔴 법무 미검토·환각 미검수 → Notion 발행 차단.

## 7. 주의
- **법무 검토는 AI 대체 불가** — 법무 항목 = 검토 의뢰 목록(결과 아님). 개인정보·약관 고지는 법무 확정.
- **환각: 없는 기능 공지** — 12 범위 밖 기능·임의 버전/날짜/가격 금지. 최종본 12 대조.
- **스토어 가이드라인 변함** — 글자수·금지 표현 제출 직전 콘솔·최신 가이드라인 재확인(거부 다발: 외부결제 유도·금지 키워드).
- **FAQ 근거 추적** — 06 조항번호 없는 답변은 정책 미정으로(지어내기 금지).
- **롤백 임계값·실행 절차는 개발·인프라 소관** — 기획은 뼈대만, 수치·기술 가능성은 개발 합의.
- **흔한 실수**: 발행 후 상태 미갱신 — D-7/D-3/D-1 리뷰 미팅으로 살아있는 문서 유지.
- 12 명세·06 정책·15-2/14-1과 기능명·조항번호를 **동일** 사용.
