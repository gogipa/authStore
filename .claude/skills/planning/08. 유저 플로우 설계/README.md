# 유저 플로우 설계 (User Flow) 스킬

IA 트리 + 요구사항 + 정책 → **핵심 과업별 유저 플로우**(시나리오·해피패스 차트·예외 전수표·최종 차트)를 자동 생성하는 Claude Code 스킬. 난이도는 해피패스가 아니라 **예외 플로우**에 있고 — 예외 도출을 "발상"이 아니라 카테고리×노드 **순회**로 바꾼다.

## 1. 무엇을 만드나
- `08-1_핵심과업_시나리오.md` — 과업 목록 + 시작/종착 + 산문 시나리오 + **AC 추적표**
- `08-2_예외케이스표.md` — 카테고리 ①~⑦ × 노드 곱집합 전수 + 06 케이스ID 출처 + 정책 플래그 2종 (**15.QA 테스트케이스 자산**)
- `08-3_플로우차트.md` — 과업별 mermaid flowchart(해피패스+채택 예외) + 차트 외 예외 표
- `_검증체크리스트.md`

## 2. 설치
```bash
mkdir -p ~/.claude/skills/user-flow-design
cp SKILL.md ~/.claude/skills/user-flow-design/SKILL.md
```
설치 후 `유저 플로우 그려줘` / `플로우차트 만들어줘`로 트리거된다.

## 3. 입력 준비
- **필수** — 07 정보구조(IA 트리). 플로우 노드의 화면명·ID 원천.
- **권장** — 03 요구사항(유저스토리·AC). 없으면 시나리오를 '과업 골격만'으로 degrade + 경고.
- **권장** — 06 정책. 예외 "시스템 동작"의 근거. 없으면 예외표 전 행을 '정책 필요'로 강제.
- **선택** — 04(과업 우선순위) / 01·경쟁사(플로우 역해석).

## 4. 사람 개입 게이트 (2곳)
1. **핵심 과업 확정** — AI 추천 과업목록·시작/종착 택1 + **07의 ⚠️정책파생·미배치·Won't 화면 채택/보류/제외**.
2. **예외 채택 선별** — 빈도·영향도로 차트행 vs 표유지 vs 정책필요 백로그. "검토 후 제외" 목록도 보존.

## 5. 변경 포인트
| 무엇 | 어디 | 바꾸는 법 |
|---|---|---|
| **예외 카테고리** | Stage 4 주석 | ①~⑦ 표준을 도메인에 맞게 교체(B2B "권한 위임·승인 대기", 오프라인 "디바이스 오프라인" 등) |
| **입력 경로(07/03/06)** | `## 입력` 3개 주석 | 각 산출물이 다른 폴더/Notion DB면 개별 수정 |
| **출력 경로** | `## 출력 위치` 주석 | 기본 `user-flow-design-output/` → 원하는 폴더(예: Obsidian 볼트) |
| **시작점(온보딩/empty-state)** | Stage 1 | 과업 시작점을 서비스 진입 구조에 맞게(가입·온보딩·구독0건 등) |
| **Figma 팀** | Stage 5 주석 | `whoami`로 edit 권한 팀 확인 후 생성 |
| **ID 계승** | (자동) | 07/03 ID를 감지·계승 — 보통 손댈 필요 없음 |

## 6. degrade 규칙 (없어도 핵심 산출물은 나온다)
- **07 없음** → 화면 원천이라 위치 묻고 **중단**.
- **03 없음** → 시나리오 '과업 골격만(AC 미반영)' + 경고 배너.
- **06 없음** → 예외표 시스템동작 전 행 '정책 필요' 강제.
- **01 없음** → 경쟁사 플로우 역해석 생략.
- **Figma 미인증** → FigJam 스킵(mermaid 원본이라 무방).

## 7. 주의
- **AI는 정책을 지어낸다** — "시스템 동작"은 일반론. 06과 대조, 단정 불가는 `[정책미정→06 환류]`로 표면화(= 06으로 보낼 백로그).
- **예외 전부 채택 금지** — 발생 확률 극히 낮은 것까지 망라된다. 빈도·영향도로 거르고, 거른 결과도 남겨라.
- **Mermaid 한계 40~50** — 노드 ≥25 또는 분기 ≥6이면 과업 단위 분리. 화면 내부 인터랙션은 **10단계(화면설계서)**로.
- **FigJam은 공유 스냅샷** — 원본은 mermaid. 라벨 누락·화살표 방향·레이아웃 육안 검수, 수정분은 08-3에 수동 역반영.
- **플로우는 IA와 함께 움직인다** — 없던 화면 발견 시 07에 즉시 역반영.
