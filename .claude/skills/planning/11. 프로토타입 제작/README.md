# 프로토타입 제작 (Interactive Prototype) 스킬

화면설계서에 **동작을 입히는** 단계. 10 화면설계서 + 08 리스크 플로우 + 06 정책 + 09 와이어를
받아 **클릭 가능한 인터랙티브 프로토타입** + **사용성 테스트 시나리오**를 만든다. 목적은
완성품이 아니라 **개발 전에 플로우·인터랙션·정책 허점을 싸게 찾는 것**.

## 1. 무엇을 만드나
- `prototype/index.html` — 단일 HTML+JS, 빌드 없이 열리는 인터랙티브 프로토타입
- `11-1_사용성테스트_시나리오.md` — 참가자·과업·성공기준·관찰포인트·SUS + 과업↔화면↔케이스ID 매핑표
- `11-2_자가점검_리포트.md` — 정적 점검 + 06 임의구현 대조 + 정량 커버리지 표
- (선택) `외부도구_프롬프트.md` — v0/Stitch/Figma Make 붙여넣기용(마스킹+경고)
- `_검증체크리스트.md`

> **프로토타입은 throwaway**입니다. 검증된 플로우·발견 문제만 12로, **코드는 버립니다.**

## 2. 설치
```bash
mkdir -p ~/.claude/skills/prototype-design
cp SKILL.md ~/.claude/skills/prototype-design/SKILL.md
```
설치 후 `프로토타입 만들어줘` / `사용성 테스트 시나리오 짜줘`로 트리거된다.

## 3. 입력 준비 (입력 소스 3분기)
- **필수** — 10 화면설계서 마크다운(`화면설계서/*.md` + `_템플릿`). **마크다운이 1차 소스.**
- **권장** — 08-2 예외표(리스크 플로우) / 06-3 매트릭스 **+ 06-운영정책_약관초안**(엣지케이스) /
  09 `wireframes/*.html`(시각 베이스) / 07-1(화면ID).
- 09가 HTML이든 Figma 링크든 마크다운이든 **1차 소스는 10 마크다운**. Figma면 figma 스킬이
  read 인증 후 구조를 읽어 보강(없으면 마크다운만으로 생성).

## 4. 사람 개입 게이트 (2곳, 스킵 불가)
1. **검증범위(핵심 플로우 1~2개) + 도구경로 확정** — 기본은 08 최고 리스크 플로우 + 직접 HTML.
2. **미정값 해소 + 과업 유도성 검수** — 과업 설계 뒤에 둔다(검수 대상이 존재해야). 해소 전 완료/공유 차단.

## 5. 변경 포인트
| 무엇 | 어디 | 바꾸는 법 |
|---|---|---|
| **입출력 경로** | 상단 변경포인트 1 / `## 입력`·`## 출력 위치` 주석 | 기본 `prototype-design-output/<주제>` → 원하는 폴더. 10이 다른 폴더/Figma면 입력 수정 |
| **생성 엔진** | 변경포인트 2 / Stage 1 | 기본=직접 HTML Write. 하이파이 필요 시 게이트1에서 frontend-design 옵트인 |
| **코드 위치** | 변경포인트 3 | 동기화 볼트면 `prototype/`을 `~/prototypes/<주제>/` 등 볼트 밖에 두는 것 권장 |
| **도구(Playwright·유료시트)** | 변경포인트 4 / 도구 정확성 | 있으면 활용, 없어도 정적 점검·직접 HTML이 기본 |

## 6. degrade / 중단 / 게이트 블로킹
- **중단** — 10 부재 / 10·08·06 동시 부재.
- **degrade** — Figma 미인증→마크다운 / 09 HTML 없음→09-1 인덱스 / Playwright 없음→정적 점검 /
  06·08·07 개별 부재→⚠️플래그 / 환류 대상 부재→백로그.
- **게이트 블로킹** — 미정값. 06 없으면 게이트2에서 명시 승인 시 `[정책가정]`으로 해제(미승인 시 과업 범위 제외).

## 7. 수신자 환경별 (4분기)
- **10이 Figma 기반** — figma 스킬 read로 구조 읽어 보강. write 도구는 기본 금지(오염·민감정보).
- **유료 시트 없음(v0/Figma Make)** — 외부도구는 옵션. 직접 HTML이 기본이라 손실 없음.
- **Playwright 없음** — 정적 grep 점검 + 수동 클릭 체크리스트가 기본.
- **동기화 볼트** — throwaway 코드는 볼트 밖 권장(지식베이스 오염 방지).

## 8. 주의
- **개발 산출물 아님** — 접근성·보안·성능 미검증. 전달은 동작 영상·링크 + 검증된 요구사항.
- **정책 수치는 09에서 읽지 말 것** — 09는 시각 베이스. 미정값은 placeholder+주석(확정 구현 금지).
- **비유도형 과업** — "~버튼을 누르세요" 금칙. 사람 최종 검수.
- **민감정보** — 더미만. 외부 웹 붙여넣기는 스킬 통제 밖(프롬프트 마스킹 필수).
- **고충실도의 함정** — 검증에 필요한 만큼만. 참가자에게 "미완성"임을 고지, 공유 시 "출시 일정 아님".
- 화면ID·구성요소 번호는 **12 기능명세 참조 키**. 함부로 바꾸지 마라.
