# user-research — 사용자 리서치 분석 자동화 스킬

수집한 인터뷰 녹취록·설문 데이터를 넣으면 질적 코딩 → 어피니티 → 페르소나 → 설문 분석 →
인사이트 리포트를 생성하는 Claude Code 스킬입니다. 사람은 **코딩 프레임 확정 1번**만 개입합니다.

> 기획 프로세스 2단계 "사용자 리서치"를 자동화합니다.
> ⚠️ 외부에서 데이터를 수집하지 않습니다. **당신이 모은 데이터를 분석**합니다.

## 무엇을 만들어 주나

실행하면 `user-research-output/<주제-슬러그>/`에 파일이 생깁니다:

| 파일 | 내용 |
|---|---|
| `02_어피니티_분석.md` | 질적 코딩 + 어피니티 그룹 + 대표 인용문(P번호) |
| `03_페르소나.md` | 페르소나 2~3개 + JTBD |
| `04_설문_분석.md` | 설문 교차분석 (CSV 있을 때) |
| `05_notebooklm-아카이브.md` | NotebookLM 출처 기반 Q&A (인증되면) |
| `06_인사이트_리포트.md` | 종합 인사이트 |
| `_검증체크리스트.md` | 사람이 확인할 항목 |

## 준비물 (입력)

1. **녹취록** — `user-research-output/<주제>/녹취록/`에 `P1.md`, `P2.md`… 로 저장.
   각 파일 첫머리에 참가자 메타(직군·연차·모집 경로).
   - 전사는 직접: [클로바노트](https://clovanote.naver.com)(한국어 정확) 또는 Whisper(로컬).
2. **(선택) 설문** — 같은 폴더에 `설문_결과.csv`.

## 사전 요구사항

| 항목 | 필수? | 없으면 |
|---|---|---|
| Claude Code | 필수 | — |
| pandas | 설문 분석 시 | `pip install pandas` |
| NotebookLM MCP | 선택 | Stage 4 자동 스킵 |

## 설치

```bash
mkdir -p ~/.claude/skills/user-research
cp SKILL.md ~/.claude/skills/user-research/SKILL.md
```

## 사용법

녹취록을 준비한 뒤 대화창에 말합니다:

```
리서치 녹취록 분석해서 페르소나 만들어줘
```

1. 스킬이 녹취록을 훑어 **코딩 프레임을 제안** → 당신이 확정 (유일한 개입)
2. 어피니티 → 페르소나 → (설문 있으면)설문 → 인사이트 자동 생성

발동 키워드: `사용자 리서치`, `인터뷰 분석`, `녹취록 분석`, `페르소나`, `user research`

## 🔧 변경해서 쓰는 법

| 변경 포인트 | SKILL.md 위치 | 어떻게 |
|---|---|---|
| 출력 경로 | `## 출력 위치` | `user-research-output/`를 원하는 경로로 (예: Obsidian 볼트 폴더) |
| 코딩 프레임 기본값 | `### Stage 0` | 5개 대분류를 자기 도메인에 맞게 |
| NotebookLM 제거 | `### Stage 4` | MCP 안 쓰면 단락 삭제 |
| 트리거 키워드 | frontmatter `description` | 자기 표현으로 |

## 주의

- **개인정보가 최우선 리스크.** 녹취록엔 실명·연락처가 있습니다. 외부 업로드 전 비식별화하세요.
- 인용문은 **원문 대조** 필수 (AI가 미묘하게 합성할 수 있음).
- 설문 수치는 스크립트 실행 결과 — 의심되면 `scripts/` 검토.
- 페르소나는 **가설**입니다. "데이터 부족" 표시를 지우지 마세요.
