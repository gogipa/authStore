# business-model-design — 비즈니스 모델 설계 자동화 스킬

04 상위기획(원페이저)을 넣으면 **BM 캔버스 9블록 → 경쟁사 가격정책 → 수익 시뮬레이션(xlsx) →
단위경제(CAC/LTV)**를 생성하는 Claude Code 스킬입니다. 사람은 **수익원 확정 1번 + 가정값 확정 1번**,
두 번 개입합니다.

> 기획 프로세스 5단계 "비즈니스 모델 설계"를 자동화합니다.
> **숫자는 전부 Python 스크립트로만 계산** — LLM 암산을 쓰지 않습니다. AI는 계산 코드를 쓸 뿐, 가정 판단은 사람.

## 무엇을 만들어 주나

`business-model-design-output/<주제>/05_비즈니스모델/`에 생성:

| 파일 | 내용 |
|---|---|
| `05-1_BM캔버스.md` | 9블록(출처 표기, 추정 ⚠️), 수익원 3옵션 |
| `05-2_경쟁사가격정책.md` | 고정 컬럼 가격표(출처·날짜) + paywall 섹션 + 가격 3안 |
| `05-3_수익시뮬레이션.md` + `scripts/revenue_sim.py` + `revenue_simulation.xlsx` | 36개월 MRR·누적, 3 시나리오 |
| `05-4_단위경제분석.md` + `scripts/unit_economics.py` | CAC/LTV/회수기간 + 민감도 격자 |
| `_검증체크리스트.md` | 사람이 확인할 항목 |

> `scripts/*.py`·xlsx는 스킬이 **실행 중에 생성**합니다(배송물 아님). 가정을 바꿔 재실행할 수 있게 남깁니다.

## 준비물 (입력)

1. **04 원페이저** (필수) — `…/04_상위기획/04-원페이저.md`. 앞 단계 high-level-planning 산출물.
2. **(연결) 01~03** — `01-가격정책.md`(가격 재사용)·`03-경쟁사-비교.md`, `02 페르소나`(고객 세그먼트), `03 PRD`(스코프). 없으면 해당 블록 약화.
3. **가정값 근거** — 전환율·이탈률·마진의 업계 벤치마크. 없으면 ⚠️추정 표기.

## 주의

- **숫자는 스크립트로만.** 채팅 요약 숫자와 xlsx가 다르면 **xlsx가 기준**입니다. 의존성 미설치 시 암산 md표로 우회하지 않습니다.
- **디폴트 가정값(전환율·이탈률·마진)은 특정 업종 예시**입니다. 자기 사업 벤치마크로 교체하지 않은 결과는 무의미합니다.
- **가격은 출처·날짜 강제** + 핵심 2~3곳 요금 페이지를 직접 대조하세요(유통기한 짧음).
- **LTV는 단순화 모델**(일정 이탈 가정) — 초기 검토용. 출시 후 17단계 실데이터로 갱신.
- **가격·환불·구독 법적 제약**(자동갱신 고지·청약철회 등)은 이 스킬 범위 밖 — **06단계 법무 검토**.
