# fe-design-tokens-components — 디자인 토큰·컴포넌트 설계 자동화 스킬

디자인 시리즈가 **확정한** 디자인 토큰·컴포넌트 사전을 프론트 코드(SSOT)로 옮깁니다. 토큰을 한 글자도
새로 만들지 않고 Tailwind config·CSS 변수(3계층)로 코드화 → 아토믹 컴포넌트 인벤토리 → CVA 변형
스키마 → Figma Code Connect 매핑 → 토큰 드리프트 점검까지 초안을 만듭니다.

> FE 프로세스 4단계 "04. 디자인 토큰·컴포넌트 설계"를 자동화합니다.
> 역할 분담: AI는 변환·회수율(토큰→코드 전개·CVA화·드리프트 스캔), **계층 경계·토큰 매핑 확정은 사람**.

## 무엇을 만들어 주나

`frontend-output/<주제>/04_디자인토큰컴포넌트/`에 생성:

| 파일 | 내용 |
|---|---|
| `04-1_tailwind토큰.md` | `tailwind.config.ts`(v3 `theme.extend`) 또는 v4 `@theme` 블록 초안 — 디자인 가이드 1:1, 신규값 0건 |
| `04-2_css변수.md` | `tokens.css` 초안 — primitive + semantic CSS 변수, 참조 체인·모드 분기 |
| `04-3_컴포넌트계층.md` | 아토믹 인벤토리(계층\|컴포넌트\|Figma명\|코드경로\|상태) + 컴포넌트별 CVA 변형 스키마 초안 |
| `04-4_CodeConnect매핑.md` | Figma 컴포넌트↔코드 매핑 표 + `*.figma.tsx` Code Connect 정의 초안 (확정만 등록) |
| `04-5_토큰이탈리포트.md` | 토큰 외 하드코딩(hex/rgb/임의 px) 발견 위치 + 토큰 후보 (자동 치환 안 함) |
| `_검증체크리스트.md` | 사람이 확인할 항목 |

## 준비물 (입력)

1. **(필수) 디자인 08 토큰 가이드 또는 Figma Variables** — 디자인 시리즈가 정의한 토큰
   (`tokens.css` 후보·토큰 표) 또는 Figma MCP `get_variable_defs`. 토큰 코드화의 원천이며,
   **없으면 중단**합니다(토큰을 지어내지 않습니다).
2. **(권장) 디자인 08 배리언트 매트릭스** — 컴포넌트 인벤토리·CVA의 입력. 없으면 Figma `get_metadata`로 직접 읽거나 ⚠️ 초안.
3. **(권장) 디자인 04 / FE 03 아키텍처** — 토큰 출처 보강 / 컴포넌트 코드 경로 기준(`03_아키텍처/03-2_폴더구조.md`).

> 토큰·컴포넌트의 "정의"·시안 제작은 이 스킬 범위 밖(디자인 04/08). FE는 확정본을 코드로 옮깁니다.

## 사용법

디자인 08 토큰 가이드(또는 Figma 라이브러리)를 준비한 뒤:

```
디자인 08 토큰 가이드 읽고 디자인 토큰·컴포넌트 코드화해줘
```

1. 토큰 → Tailwind config·CSS 변수(3계층) 코드화 → 아토믹 인벤토리 자동 생성
2. **토큰 매핑·컴포넌트 계층 확정** → 당신이 OK/수정 (유일한 게이트)
3. CVA 변형 스키마 → Code Connect 매핑 → 토큰 드리프트 점검 자동

발동 키워드: `디자인 토큰 코드화`, `Tailwind 토큰`, `tokens.css`, `컴포넌트 계층`, `아토믹 디자인`, `CVA 변형`, `Code Connect`, `토큰 드리프트`

## 주의

- **AI는 없는 토큰을 그럴듯하게 채웁니다.** "디자인 확인 필요" 주석·임의 채움값은 디자인 08 가이드/Figma Variables와 직접 대조하세요.
- **Tailwind 버전 문법을 혼동합니다** — v3/v4가 다릅니다. Context7로 프로젝트 버전 확인 후.
- **Code Connect 오연결은 추적성을 망칩니다** — 불확실한 매핑은 등록하지 말고 목록만.
- **아토믹 계층은 정답이 없습니다** — AI 분류는 초안, 도메인 결합 컴포넌트 계층은 사람이.
- **드리프트 자동 치환 금지** — 점검은 자동, 치환은 사람 검토 후.
- **FE가 토큰을 "개선"하지 마세요** — 이름을 바꾸면 Figma·다른 시리즈와 어긋납니다. 개선은 디자인에 역제안.
