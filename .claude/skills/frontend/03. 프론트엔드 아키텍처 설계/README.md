# fe-architecture-design — 프론트엔드 아키텍처 설계 자동화 스킬

01 화면 목록·화면↔API 의존맵과 02 스택 ADR을 넣으면 페이지별 렌더링 전략(CSR/SSR/SSG/ISR)·
feature-based 폴더 구조·모듈 경계 lint 초안·데이터 흐름 규약을 결정·기록하는 Claude Code 스킬입니다.
**AI는 후보를 표로 회수하고 결정을 ADR·lint·다이어그램으로 굳히고, 렌더링 전략·모듈 경계 같은
트레이드오프 판단은 사람**이 합니다(위임하면 우리 제약을 모르는 그럴듯한 구조가 나옵니다).

> FE 프로세스 3단계 "03. 프론트엔드 아키텍처 설계"를 자동화합니다.
> 역할 분담: AI는 회수·기록·코드화, **렌더링 전략·모듈 경계 확정은 사람**.

## 주의

- **렌더링 전략을 AI가 결정하지 않습니다.** AI 출력은 후보 표 — 우리 SEO·트래픽·인증 맥락은 사람이 보고 확정합니다.
- **`'use client'`는 트리로 봅니다.** 페이지 전체가 아니라 인터랙티브 서브트리만 클라이언트로(번들 축소).
- **폴더 과설계 주의.** MVP Must feature부터, 나머지는 규칙만 두고 비워둡니다.
- **모듈 경계 lint는 초안.** 실제 적용은 06 개발 환경 구축에서(지금 머지하면 충돌).
- **여기서 구현 안 합니다.** 디자인 토큰은 04, 라우트 맵은 05, 상태·API 구현은 09·10. 03은 규약 선언까지.
